01

消费文化的对象与课程路线

课程从工作伦理与消费社会进入商品和物的体系，再讨论非物质消费。书目、影片和小组阅读服务于这条问题线索。

课程整体单元划分

  • 课程共分为三个核心单元，分别对应消费研究的三个维度：消费与工作、消费与“物”、消费与文化

各单元核心内容

  • 第一单元：消费与工作（政治经济学维度）
  • 核心理论资源：马克思·韦伯《新教伦理与资本主义精神》中的工作伦理、马克思“异化”理论、西方资本主义“工作伦理”的发展脉络
  • 核心目标：结合劳动异化理论搭建批判视野，从政治经济学角度阐释个体消费、工作等行为
  • 第二单元：消费与“物”（物质消费维度）
  • 核心议题：物的商品化、文化象征过程、符号化过程，讲解客观自然物如何转化为商品体系、建构消费文化体系供人购买使用
  • 涵盖内容：购物与消费、时尚与消费，涉及购物空间、商品展示、品牌、明星/电视剧/小红书/意见领袖等传播渠道，阐释消费文化体系的建构逻辑，以及人在该体系中的选择行为
  • 第三单元：消费与文化（非物质消费/文化消费维度）
  • 核心议题：消费与文化工业、大众文化的反抗、反抗与收编
  • 理论对比：法兰克福学派认为进入消费社会后，文化产品生产从基于艺术家的个体创作转为可广泛复制的产业化生产，批判该类产品被大众消费后对人的影响与塑造，立场相对悲观；国民汉学派认为个体面对流行消费文化产品时仍保有个人力量，能够表现出反抗能力

02

工业生产与大众消费的历史转变

课堂联系现代性、工业生产、福特主义与大众消费，讨论生产积累、消费扩张及新消费者之间的关联。

消费社会的由来

  • 消费社会或社会工业化必然形成商业世界与消费社会
  • 消费社会存在的前提包括现代社会的降临、市场需求的存在
  • 农业社会向工业社会转型带来根本性变化，以去食堂购买商品为例，说明人也被纳入商业世界体系之中
  • 该转型相关的史实包括圈地运动

现代社会思想转变的形式

  • 人与自然的分离
  • 主客之间的二元分裂，核心内涵为认识、征服、利用
  • 世界的祛魅，指个人与超验世界（超世界）的关系脱离，相关著作有《个人与超世界的关系》
  • 世界成为服务于工具理性的生产资料、积累财富的私有化工具
  • 发生人类中心主义的转向，相关代表作品有《红与黑》《卡拉玛佐夫兄弟》《罪与罚》

工业社会转型的多领域变革影响

  • 资本主义兴起带来基础性变革：工业化、商业化、城市化推进，资本与生产通路建立（涵盖生产资料、人的流动，社会进入陌生人社会）；圈地运动推动人口流动，人作为生产力被纳入农业社会向工业社会转型的进程。
  • 人口与社会关系变化：人从农业社会基于地缘建立的稳定社会关系与价值体系中脱离，进入大都市等陌生人社会。
  • 政治领域变革：人民民主与民主意识兴起，旧有神定秩序、贵族世袭秩序被打破，新的平等秩序建立；老师通俗解释民主的实质：旧秩序下底层群体对不平等关系无反抗意识，工业化后秩序流转，底层群体通过经济手段获得地位后，不再心甘情愿接受原有不平等对待，由此催生平等诉求与民主制度。
  • 文化领域变革：个人主义兴起，带来权利意识与个人自由，这是将人从土地束缚中抽离、转化为工业化生产力的前提。

消费社会的阶级区隔与夸饰性消费行为

  • 古典阶级出身差异因民主制度推广被消弭后，消费成为人们实现社会进阶、标榜自身差异性的方式。
  • 大都会的出现推动消费成为生活方式。
  • 当时家庭分工明确：丈夫的职业决定家庭收入及社会地位，妻子负责家中消费，用以彰显家庭的经济能力与生活品质。

消费与民主社会的关联

  • 消费社会所建立的人的区隔方式，与民主社会的兴起存在巨大关联性

前工业社会的消费特征

  • 老师说明使用“前工业/后工业”的划分仅为讲课方便，当前工业已完全退出，社会以图片信息、AI人工智能为核心，物质随信息流动，不再使用该划分
  • 前工业社会消费具备区隔、展示的作用，当前消费行为仍保留该展示性质
  • 古典阶级出身差异因民主制度推广被消弭后，消费成为人们进阶、标榜差异性的方式
  • 大都会的出现促成消费成为生活方式
  • 当时家庭分工明确：丈夫职业决定家庭收入及社会地位，妻子负责家中消费，用以彰显家庭的经济能力与生活品质

福特主义与大众消费的兴起

  • 福特主义起源：福特汽车创始人发现通过机械化、自动化可大幅提升生产力，通过对工人进行精细分工，让每人仅负责流水线上的专属环节，以此提高产品生产能力
  • 福特主义开启劳工阶层的职业分工（李嘉图专业分工）
  • 工人工作时间因自动化、流水线应用被缩短，可支配的时间与收入增加
  • 开启“努力工作、努力购物”的经济模式，推动资本主义发展进入新阶段
  • 伴随经济一体化、全球化，福特主义在二战后得到普及

福特主义与大众消费兴起

  • 福特主义开启劳工阶层的职业分工（李嘉图专业分工）
  • 通过自动化、流水线缩短工人工作时间，增加工人的可支配时间与收入
  • 形成“努力工作-努力购物”的消费闭环：工人购买自身生产的商品，本质是推动资本更快完成财富积累，助力资本主义发展进入新阶段
  • 福特主义起源于美国，二战后伴随经济一体化、全球化在全世界普及

消费社会的形成：从生产积累到消费积累

  • 资本主义进入新阶段，开展全球范围的采购与倾销（典型案例：亚洲四小龙经济腾飞），核心目标是提升资本全球流转的速度，实现财富更快增值
  • 产品生产方向转型：重点发展文化产品、快销品、时尚类商品，同步推进技术创新、企业管理创新、产品创新，催生与之匹配的消费文化形式
  • 消费社会产生的核心前提：社会生产处于物质极大冗余、富裕的状态，而非物质匮乏时期；当生产力远超实际需求（如单个家庭可拥有20辆汽车，但仅需1辆代步）时，需通过赋予商品符号价值（如将汽车从代步工具转化为彰显个人身份的“行走的自我”）刺激额外消费
  • 消费社会的消费行为不再仅满足物质需求，更多转向精神满足、购买快乐，催生围炉、室内冲浪等即时性实践与体验类消费

福特主义的后期影响

  • 形成社会广泛富裕、全民消费的形态，消费主义成为社会性的运行机制
  • 典型案例：英国选举中劳工阶层将票投给保守党而非代表其直接利益的工党，普遍认为原因是消费主义提升了劳工阶层的满意度，使其更倾向于追求收入提升与消费产品丰富，而非权利与尊重

新消费者的出现

  • 背景：灵活的全球化经济模式发展、新经济爆发；后现代性中流动性状态取代先前的稳固团体归属，典型案例：美国女艺术家辛迪·舍曼的摄影系列《一人千面》
  • 出现以消费为生活重心的新型社会团体
  • 新媒体生态下衍生出景观消费、饭圈文化等新消费文化形式
  • 马克思、韦伯关于早期资本主义发展与运作的基础理论著作仍具重要性，为理解资本主义现代社会结构提供基础概念框架

消费社会的转型与消费主义意识形态化

  • 消费社会从商业社会、工业社会转型而来，带来政治领域的变化：西方民主选举中选民的诉求从追求政治平等、公平、正义，转向关注哪个政党上台能改善经济、提高退税、提升日常消费能力与生活体验。
  • 消费主义已从日常生活、商业领域扩展为影响政治的社会机制、意识形态：选民会支持能让自己获得更多收入、更多消费选择与生活体验的政党，而非代表自身直接利益的政党。
  • 典型案例：英国选举中劳工阶层将票投给保守党而非代表其直接利益的工党，原因被认为是消费主义提升了劳工阶层的满意度，使其更追求收入与消费产品的丰富，而非权利与尊重。
  • 消费主义为个体提供丰富的消费符号与体验选择，如戴比尔斯等奢侈品、“行走的自我”等消费概念，满足个体的体验需求。

新消费者的出现与消费社会的体验特征

  • 新消费者不再以工作作为坐标体系建立自身的社会定位与个人价值，而是通过消费实践活动形成新的团体与身份认同，如“买谷子”带来的快乐与身份认同感。
  • 后现代性中的流动性状态已取代先前的稳固团体归属：典型案例为美国女艺术家辛迪·舍曼的摄影系列《一人千面》。
  • 消费社会提供的丰富多元化场景均为即时性体验，不会让人与特定对象建立长久稳定的联系、完成人格的完整建构，仅能提供浅尝辄止的新鲜体验。
  • 消费社会不鼓励个体沉潜下来与对象建立稳定关系以建构人格，而是推动个体不停切换各类场景，耗费行动、实践与生命，体验由欲望驱动，具有随时流转变动、无确定性的特征。
  • 消费社会下个体的身份不再具有恒定性：如个体可同时是网约车司机、直播带货主播、脱口秀爱好者，身份随消费场景切换而变化。

消费文化研究的理论框架

  • 马克斯·韦伯《资本主义发展与新教伦理》：韦伯的核心问题意识是思考资本主义制度与积累型社会体制为何会在特定国家与文化中产生，而非普遍出现；他从文化、宗教角度分析资本主义的产生原因，聚焦基督教卡尔文教派——该教派是基督教世俗化进程中的分支，主张普通人通过努力工作、克勤克俭履行本分即可侍奉上帝，无需成为教士或修女；新教伦理推动人勤奋工作，且工作积累的财富会再次投入生产而非即时消费，为资本主义财富的持续积累提供了文化动力。
  • 卡尔·马克思《资本论》：围绕商品、资本等核心范畴展开对资本主义的批判，是消费文化研究的重要基础理论著作。

异化、伦理与符号消费

马克思的劳动异化、韦伯的伦理视角和后续消费批判各有问题对象；商品的符号化与审美化提示消费不能只按实用需求解释。

奢侈品牌的符号化消费案例

  • 展示案例：爱马仕特别烧制板材（作用为显门档）、Supreme典藏级口味方便面、克罗心捕鼠夹

韦伯的“世界祛魅”命题与现代性转向

  • 核心引文（出自《学术作为志业》）：
  • 冯克利译，三联书店1998年11月第1版，48页：我们这个时代因独有的理性化、理智化，最主要因世界已被除魅，其命运是终极、最高贵的价值已从公共生活中销声匿迹，或遁入神秘生活的超验领域，或走进个人之间直接的私人交往的友爱之中。
  • [德]韦伯1918年11月《学术作为志业》三讲选录：我们这个时代因固有的客观性、合理性，最本质因世界已被除魅，其命运是最珍贵、最高贵的价值已从公共生活中销声匿迹，或遁入主观生活的超验领域，或走进个人之间纯朴的交往和友谊之中。
  • 祛魅引发的现实转向：自然从被敬畏的对象变成可被认识、掌握、征服、利用的工具理性对象，人类转向人类中心主义；人也被工具化，成为工业化生产中的劳动力。
  • 陀思妥耶夫斯基的创作聚焦祛魅后的社会变化，代表作为《卡拉马佐夫兄弟》《罪与罚》：两部作品均围绕“恶人父亲被杀”的故事展开，核心冲突是理性视角的“除恶”逻辑与超验价值体系的矛盾——理性认为除掉恶人能造福他人，但超验体系里恶人有完整的因果价值链，杀父行为本身是价值体系的巨大灾难，恶人也可能承担磨难或救赎的意义。

工作伦理的引入与马克思、韦伯的资本主义研究视角区分

  • 韦伯从社会文化、宗教角度解释资本主义的诞生
  • 马克思从剩余价值角度解释资本主义财富积累建立在劳动力剥削的基础上
  • 二者研究视角不同无对错，可视为互补关系
  • 引入「工作伦理」概念，该概念在后续消费社会中发挥重要作用，且发生变形与发展

资本主义资本增值的前提与劳动异化的第一层表现：生产与需求分离

  • 金钱变为资本需满足两个条件：一是购买生产资料、机器设备等生产物资，二是投入人的劳动力，将劳动价值商品化以产生剩余价值实现溢价（举例：生产资料与人力投入共5元，商品售出溢价8元，其中3元为资本增值部分）
  • 第一层异化为生产与需求分离：工人生产的产品不属于自身，并非为满足自身生存需求而生产，需将劳动转化为劳动力商品换取工资，再用工资购买他人生产的商品
  • 劳动目的变为维持生存所需，劳动性质被改变为商品化劳动

劳动异化的第二层表现：疏离化

  • 异化劳动本身无法给人带来快乐，以周杰伦执导的自动化工厂题材喜剧电影中的流水线工人为例，产业流水线中的劳动存在多重疏离：工人彼此之间为竞争关系，工人与代理、管理者之间为控制与被控制、管理与被管理的关系
  • 产业流水线不可能产生真实的社会性合作与自我实现经验，劳动者仅在劳动之外才感受到自由与真实
  • 劳动产生的是强迫性劳作，而非真正的劳动
  • 此处提及设计师ALEXANDER MCQUEEN（后续课程将解释关联）

异化劳动与“类存在”的无法实现

  • 马克思对劳动的阐释：劳动兼具满足生存本能的部分，也包含归属于人类社会的公共性特质的「劳动生产力」，是人类共同体创造独立于自然的人类世界的基础（引用《庄子·逍遥游》“朝菌不知晦朔，蟪蛄不知春秋”类比人类生命的有限性，反衬人类通过共同劳动创造人类世界的公共性）
  • 异化劳动导致创造性活动丧失，劳动力与劳动生命力被限制
  • 后续概念发展为「工作与消费的一体化」
  • 马克思指出“异化”是社会与历史的建构物，人类之所以为人类的核心是具有创造性活动的能力，而异化劳动将劳动限制在商品生产的范畴内，使人失去创造性生活的能力，无法实现“类存在”的生存

消费是异化的一部分（人的异化）

  • 马克思认为劳动具有公共性与劳动生产力，极具创造性；当这两点被摒弃，人仅以劳动力为生存方式，是剥夺人成为人的权利
  • 消费社会、商品社会并非天然存在，是人为构造的历史构建物
  • 劳动异化使人无法实现人类的类生存，由此衍生出消费异化：人将自身商品化为劳动力换取报酬，在非劳动时间通过消费活动追求成为人的体验
  • 消费是生产的一个部分，工业社会后工人从土地中被解放，获得业余时间，汽车等科技化消费品的普及推动消费实践活动增多，消费与劳动异化具有一体化关联
  • 消费成为人构建“自由、完整、快乐”自我认知的实践活动，进而正当化资本主义，成为当代人的生活方式意识形态
  • 前文展示的典藏版方便面等扭曲消费现象，是消费异化的具体体现

消费与工作：资本主义伦理价值及其批判

  • 消费与物：物的生产及符号系统
  • 消费活动定义个体概念：物品通过材质、款式完成对人的说明，消费具有被使用者投资的文化特质
  • 物品可被重新融入特定场景，其意义“否认商业的抽象性”，由人的塑造与使用决定
  • 消费行为需要经过现代媒体、影视明星等传播渠道的教育，受众才能识别产品符号价值（案例：巴黎世家限量款鞋售价数万元，若穿着从事农耕等场景则失去符号意义，消费的核心是让他人看懂符号价值）
  • 典型扭曲消费行为举例：为体验“悬崖般透明楼梯”而克服恐高症、将美容太空舱包装为“太空体验+焕肤”产品等，均与消费异化直接相关
  • 消费与文化：大众文化消费与商业收编
  • 消费需求种类与文化因资本驱动分裂且不稳定，人的需求被商业体系驱动的欲望多样化主导，越来越偏离真实需求
  • 人对自身真实需求越来越不关心，反而关注消费行为对自我身份的背书作用
  • 商品交换成为满足人类需求的主要方式，也成为消费社会的主要社会关系
  • 消费品的不断推陈出新不断扩大人类使用对象，加剧资源消耗与环境危机

消费主义的当代性（政治的异化）

  • 作为意识形态，认为生命的意义在于购买东西和成品的经验
  • 消费主义意识形态正当化了资本主义
  • 强化人的异化：只要还有薪水可领，消费品和经验的美梦就是生活的动力
  • 现象运行逻辑：生产体制扩张→媒体教育传播→符号和象征体系构建→驱动欲望，市场的扩大使需求与物品的偏移构成意义和象征

消费主义的当代性

  • 消费行为的价值与意义需要经过意识形态教育才会形成
  • 物品会脱离实际需求，与意义、象征产生勾连（如鞋可象征身价）
  • 消费主义意识形态正当化资本主义，同时加强人的异化：只要拥有薪水，消费品与体验的“美梦”就会成为生活动力

结构主义视角的消费文化分析

  • 本部分提及的三位学者中，马尔库塞不属于结构主义理论体系，仅因契合“消费与意义勾连”的主题被罗列在此；布尔迪厄与鲍德里亚属于后结构主义
  • 将消费及文化的分析放置到社会阶级结构的架构中认识
  • 成为消费者需要学习一套特定的文化象征与价值：广告、影像、文化产品等必须与潜在消费者的生活方式产生共鸣，才能发挥实际影响力；广告与促销触动的欲望可能潜藏在个人或团体的无意识中，不会出现在生活表面
  • 涉及文化资本与符号意义的生产（案例：老钱与新钱）

马尔库塞：由制度形塑的消费

  • 消费经济和资本主义创造了人的“第二天性”
  • 体制与人的本能欲望、占有欲望结合，促成消费社会中的消费欲望
  • 拥有、消费、把持以及持续更新的需要被强加在人们身上
  • “第二天性”阻碍和废除人的真正存在能力，使人将生命力消耗在被异化的生活实践中（举例：脱口秀、室内冲浪、双人跳伞等体验消费是被制造的欲望驱动）

商品的符号化与审美化

  • 符号化的重要手段是提升审美经验与审美体验
  • 消费社会中商品会传递特定信息、具备象征意义，背后有整套教育体系支撑：如无款式红色丝巾仅能满足保暖需求，莫奈主题丝巾会传递“有品位、了解莫奈”的信息，爱马仕丝巾则会传递“有钱”的信息
  • 鲍德里亚在《符号学和物品的消费》中指出：消费并非马克思所说的满足生存之外的物质需求，而是满足个体建构自我身份的精神需求
