# 市场图鉴 Market Atlas

「行业 × 岗位 × 盈利模式」大而全知识库，单文件 HTML，双击即可打开。

## 打开方式

```bash
open index.html
```

无需服务器、无需联网、无外部依赖。所有数据内嵌在 HTML 里。

## 给新手的入口

首页有两个按钮：

**新手导读**——讲清市场怎么运转、四步读法、六个评分维度怎么看、三个必懂的金钱概念（毛利 vs 净利、周转、经常性收入），以及 8 个常见困惑的问答（毛利率高为什么不一定赚钱、资本密集度跟你有什么关系、262 种盈利模式要不要全看等）。

**术语表**——81 条术语的大白话解释，分 9 组（钱的基础、收钱的方式、行业与市场、赚钱的底气、资本与投资、岗位与职场、技术与生产、金融专项、政策与合规），每条配一个生活里的例子。可搜索。

每个详情页还有针对新手的讲解块：行业讲「这个行业在做什么」加新手三问（谁付钱、难在哪、怎么了解）；岗位讲「每天在干什么」加真实状态和最该做的一件事；盈利模式讲「怎么赚钱」加一个比方和最该盯住的指标。

搜索也支持大白话——搜「看天吃饭」能找到种植业，搜「猪周期」能找到畜牧养殖，搜「卖时间」能找到法律服务。

## 内容规模

| 维度 | 数量 | 说明 |
|------|------|------|
| 行业 | 192 | 覆盖 15 个板块，每板块 7–27 个细分行业 |
| 岗位 | 91 | 20 个岗位族，含薪酬带宽、技能、路径、AI 影响判断 |
| 盈利模式 | 262 | 10 个模式族，含公式、毛利空间、利润杠杆、失效条件 |

## 三个视图怎么用

**行业视图**：按板块筛选，按增长前景、毛利、竞争、监管等六维排序。详情页给出价值链、收入来源、主要成本、核心指标、盈利模式、关键岗位、入行入口、风险与趋势。

**岗位视图**：按岗位族筛选。详情页有薪酬带宽图（入门/成熟/资深三档）、技能与工具、考核指标、证书、发展路径，以及对 AI 冲击的判断。

**盈利模式视图**：按模式族筛选。详情页有收入公式、毛利空间、利润杠杆、失效条件、典型风险、代表案例，以及适用该模式的行业列表。

## 交叉跳转

三个视图是打通的。在行业详情页点「盈利模式」或「关键岗位」的标签，会跳到对应详情；反过来在岗位和模式详情页也能跳回行业。

## 搜索

按 `/` 聚焦搜索框。搜索覆盖名称、中英文、描述、收入、成本、指标、技能、风险、趋势、案例等所有文本字段。三个视图共用同一个搜索框。

## 数据来源与时效性

数据分两层，构建时合并：

**基础层**（`data/parts/*.js`、`data/roles.js`、`data/models.js`）描述行业的结构性特征——价值链、收入来源、成本结构、盈利模式、岗位能力要求。这些长期有效。

**时效层**（`data/patch-2026.js`）叠加当期实况，共修正 73 条：价格与增速、盈利状态、政策变化、竞争格局、薪酬数字。每条注明数据时点，通过广泛检索公开报告与行业数据获得。首页显示当期宏观背景，详情页有「当期实况」块标注时点。

主要修正包括：光伏全产业链亏损与能效新规出清、汽车渗透率破 60% 但行业利润率仅 3.6%、创新药上半年 License-out 1100 亿美元、半导体存储超级周期与设备国产化率、银行净息差四年首次环比回升、餐饮闭店率 23.7%、骑手社保落地推高配送成本、SaaS 从按账号收费转向按结果付费、AI 岗位替代率数据等。

薪酬区间为一线城市参考值，非实时报价。数据用于理解商业结构，不构成投资或求职建议。

## 更新时效数据

编辑 `data/patch-2026.js`，在对应 id 下填写要覆盖的字段，然后重新构建：

```bash
node build.js
```

补丁只覆盖指定字段，未提及的字段保留基础层原值。构建时会打印应用了多少条补丁。

## 目录结构

```
market-atlas/
├── index.html              # 唯一交付物，单文件
├── build.js                # 构建脚本：数据分片 → index.html
├── SCHEMA.md               # 数据字段定义
├── data/
│   ├── constants.js        # 板块、岗位族、模式族词表
│   ├── roles.js            # 91 个岗位（基础字段）
│   ├── models.js           # 262 个盈利模式（基础字段）
│   ├── guide.js            # 新手导读
│   ├── glossary.js         # 81 条术语表
│   ├── patch-2026.js       # 2026 时效性补丁
│   ├── industry-plain.js   # 192 个行业的小白讲解
│   ├── role-plain.js       # 91 个岗位的小白讲解
│   ├── model-plain.js      # 262 个盈利模式的小白讲解
│   └── parts/              # 192 个行业基础数据，按板块分 15 个文件
│       ├── 00-fixmap.js    # 悬空引用修正表
│       ├── 01-agri.js
│       └── ...
└── src/                    # HTML/CSS/JS 源文件，构建时内联
```

## 数据分四层

构建时按顺序合并，后一层覆盖前一层：

1. **基础层**（`data/parts/*.js`、`roles.js`、`models.js`）——行业的结构性特征、岗位与盈利模式的核心字段。
2. **修正层**（`data/parts/00-fixmap.js`）——修正早期数据里的悬空引用。
3. **时效层**（`patch-2026.js`）——2026 年当期实况，共修正 73 条。
4. **讲解层**（`guide.js`、`glossary.js`、`*-plain.js`）——让新手能读懂的大白话解释。

## 修改数据后重新构建

```bash
node build.js
```

构建时会打印每层应用了多少条，并校验引用完整性。
