# 第十三章 云端基础设施：一人公司的"虚拟总部"

## 一、从自建机房到Serverless

2005年，一个互联网创业公司需要"买服务器"。

一台Dell PowerEdge服务器，价格三万到五万元。你需要一个机房（或者租一个机柜），需要一个人来维护它（装系统、打补丁、监控温度），需要一个UPS（不间断电源）防止断电，需要一个空调防止过热。

2026年，一个一人公司不需要"买服务器"。

你打开Vercel，点击"Deploy"，你的网站就上线了。你打开Supabase，点击"Create Project"，你的数据库就建好了。你打开Cloudflare，点击"Add Site"，你的CDN就配好了。

从"买服务器"到"点一下按钮"。从"五万元+一个运维工程师"到"零元+零运维"。

这就是"Serverless"（无服务器）的含义：你不需要"拥有"服务器，你只需要"使用"服务器。用多少，付多少。不用，不付。

## 二、全球CDN与边缘计算：一个人如何服务全球用户

2026年，一个在深圳的一人公司创始人，他的网站可以被东京、纽约、伦敦、圣保罗的用户同时访问，而且速度都很快。

这是怎么做到的？答案是**CDN（内容分发网络）**。

CDN的原理很简单：把你的网站内容复制到全球各地的服务器上。当东京的用户访问你的网站时，他从东京的服务器获取内容；当纽约的用户访问时，他从纽约的服务器获取内容。用户不需要"跨越太平洋"去访问你在深圳的服务器。

Cloudflare、Vercel、Netlify——这些平台都提供免费的CDN服务。你不需要"配置"CDN，你只需要"部署"你的网站，CDN自动生效。

**边缘计算（Edge Computing）** 是CDN的进化版。在CDN中，边缘服务器只"缓存"静态内容（图片、CSS、JS）。在边缘计算中，边缘服务器可以"运行代码"——你的API逻辑可以在离用户最近的服务器上执行，而不需要回到你的"主服务器"。

对于一人公司来说，边缘计算意味着：你的"服务器"不是一个物理位置，而是一个**全球分布的网络**。你的"总部"不在深圳，不在东京，不在纽约——它在"云端"，在"边缘"，在离每一个用户最近的地方。

## 三、数据库即服务：Supabase、PlanetScale、Neon

2026年，一人公司不需要"管理数据库"。

**Supabase**：开源的Firebase替代品。提供PostgreSQL数据库+用户认证+文件存储+实时订阅+API自动生成。免费版：500MB数据库、50000月活用户。

**PlanetScale**：基于MySQL的Serverless数据库。自动扩容、自动备份、零运维。免费版：5GB存储。

**Neon**：Serverless PostgreSQL。自动休眠（不用时不收费）、自动扩容、分支功能（像Git一样管理数据库）。免费版：100000活跃用户/月。

这些"数据库即服务"（DBaaS）的共同特征是：**你不需要"管理"数据库。** 不需要安装、不需要配置、不需要打补丁、不需要监控、不需要备份。你只需要"用"。

对于一人公司来说，这意味着：你的"技术栈"中，"数据库运维"这一层被完全消解了。你不需要懂SQL优化，不需要懂索引设计，不需要懂备份策略。你只需要知道"怎么存取数据"。

## 四、支付与合规的自动化：Stripe、Lemon Squeezy

支付是一人公司最头疼的环节之一。不是因为"收钱"难，而是因为"合规"难。

**Stripe**（面向海外市场）：
- 支持全球135+种货币
- 自动处理税务（VAT、GST、Sales Tax）
- 自动处理发票
- 自动处理退款和争议
- 费率：2.9% + $0.30/笔

**Lemon Squeezy**（面向数字产品）：
- 专门为数字产品（SaaS、课程、电子书）设计
- 自动处理全球税务（包括欧盟VAT）
- 自动处理发票
- 费率：5% + $0.50/笔

**国内支付**（面向国内市场）：
- 微信支付 + 支付宝：需要企业资质（个体工商户即可）
- 费率：0.6%
- 需要ICP备案

这些支付平台的意义在于：**你不需要"懂税务"。** 你不需要知道日本的消费税是多少、欧盟的VAT怎么计算、美国的Sales Tax在哪个州征收。平台帮你处理一切。你只需要"收钱"。

## 五、安全与隐私：一人公司的最小安全架构

一人公司没有IT安全团队。但你仍然需要一套"最小安全架构"。

**1. 密码管理**
- 使用密码管理器（1Password、Bitwarden）
- 所有账号使用不同的强密码
- 开启双因素认证（2FA）

**2. 数据备份**
- 代码：推送到GitHub（自动版本控制）
- 数据库：Supabase/Neon自动备份
- 文件：同步到云盘（Google Drive、iCloud）
- 关键数据：每周手动备份到本地硬盘

**3. 访问控制**
- 最小权限原则：只给必要的工具必要的权限
- 定期审查：每月检查哪些工具有你的数据访问权限
- API密钥：不要硬编码在代码中，使用环境变量

**4. 隐私合规**
- 如果你收集用户数据，必须有隐私政策
- 如果面向欧盟用户，必须符合GDPR
- 如果面向中国用户，必须符合《个人信息保护法》

这套"最小安全架构"不需要专业知识，不需要额外成本。它只需要**纪律**——定期做、认真做、不偷懒。

## 六、成本建模：月活10万用户的一人公司基础设施成本

让我做一个极端的成本建模：如果你的产品有10万月活用户，你的基础设施成本是多少？

| 组件 | 工具 | 月成本 |
|------|------|--------|
| 前端部署 | Vercel Pro | $20（143元） |
| 数据库 | Supabase Pro | $25（179元） |
| CDN | Cloudflare（免费版） | 0元 |
| AI API | OpenAI（按用量） | $200-500（1430-3570元） |
| 支付 | Stripe（按交易） | 交易额的2.9% |
| 邮件 | Resend Pro | $20（143元） |
| 监控 | PostHog Cloud | 0元（免费版） |
| 域名 | Cloudflare | 10元 |
| **月总成本** | | **约2000-4000元** |

月活10万用户，基础设施成本2000-4000元。

对比：2015年，服务10万月活用户需要：3台服务器（18000元/月）+ 1个运维工程师（20000元/月）+ CDN（5000元/月）= 43000元/月。

从43000元到3000元。降幅：**93%。**

这就是"云端基础设施"对一人公司的意义：它让"规模"不再是成本的决定因素。10万用户和1000用户的基础设施成本，可能只差几百块钱。
