# 第十八章 一人公司的增长飞轮：从0到100万的完整路径

## 一、阿弹幕的四个阶段

2024年3月，阿弹幕在Steam上发布了他的第一款弹幕游戏。定价28元。第一个月，卖了47份。收入1,316元。

他花了三个月做这款游戏。代码是Cursor写的，美术是Midjourney生成的，音乐是Suno生成的，关卡设计是他自己做的。总成本：AI工具订阅费约600元，加上三个月的生活费。

47份。1,316元。这个数字意味着什么？意味着他的"时薪"大约是两块钱。

但他没有放弃。他分析了数据：47个买家中，有31个来自日本，8个来自美国，8个来自中国。日本玩家给了平均4.7分的评价（满分5分），美国玩家给了3.9分。

"日本玩家喜欢我的游戏，"他告诉我，"那我就做给日本玩家。"

2024年6月，他发布了第二款游戏。这次他针对日本市场做了调整：增加了日文界面，调整了难度曲线，加入了日本玩家喜欢的"弹幕美学"（密集的、对称的、像烟花一样的弹幕图案）。

第二款游戏，第一个月卖了312份。收入8,736元。

2024年9月，第三款。第一个月卖了1,847份。收入51,716元。

2025年全年，他发布了六款游戏。总流水接近2000万元。个人到手80到100万元。

从47份到2000万。从1,316元到100万。这不是"运气"，这是一个**增长飞轮**的完整运转。

## 二、增长的四个阶段

阿弹幕的经历，精确地对应了一人公司增长的四个阶段。

**阶段一：验证（0-1万/月）。** 第一款游戏，47份，1,316元。目标不是"赚钱"，是"证明有人愿意付钱"。47个人愿意花28块钱买一个独立开发者做的弹幕游戏，这就够了。验证通过。

这个阶段的核心动作是：用最小成本做一个"实验"，找到10个愿意付钱的人。如果他们付了，继续。如果没有，转向。

常见错误：花三个月"打磨产品"，然后发现没有人要。阿弹幕没有犯这个错误。他的第一款游戏很粗糙，但它验证了需求。

**阶段二：产品化（1万-5万/月）。** 第二、三款游戏。从47份到1,847份。关键变化：他找到了"日本弹幕游戏玩家"这个精确的利基市场，并针对这个市场做了产品调整。

这个阶段的核心动作是：把"实验"变成"产品"。建立标准化的开发流程（用AI加速），优化定价，建立基本的营销渠道（Steam社区、Twitter、日本弹幕游戏论坛）。

**阶段三：自动化（5万-20万/月）。** 第四、五款游戏。阿弹幕把开发流程中的80%交给了AI：代码生成、美术生成、音乐生成、测试。他自己只做关卡设计和最终审核。开发周期从三个月压缩到了三周。

这个阶段的核心动作是：用AI和自动化替代"执行"工作，让自己专注于"设计"。

**阶段四：规模化（20万-100万/月）。** 第六款游戏，加上前五款的长尾销售。阿弹幕没有"招人"，没有"融资"。他只是增加了"产量"：从一年两款到一年六款。每款游戏的开发成本几乎为零（AI工具订阅费），但每款游戏都在持续产生收入。

这个阶段的核心动作是：在不增加"人力"的情况下，增加"产量"。一人公司的"规模化"不是"做大"，是"做多"。

## 三、内容飞轮：一个人如何建立持续的内容生产系统

阿弹幕的增长飞轮有一个核心引擎：**内容。**

每发布一款新游戏，他会在Twitter和日本的弹幕游戏论坛上发布开发日志、游戏截图、弹幕图案设计过程。这些内容吸引了新玩家，新玩家买了游戏，买了游戏的人会写评价、发推文、做视频，这些用户生成的内容又吸引了更多新玩家。

```
发布游戏 → 发布开发日志 → 吸引关注 → 玩家购买 → 玩家写评价/发推文 → 吸引更多关注 → 下一款游戏发布 → ...
```

这个飞轮一旦转起来，就会自我加速。每一款新游戏都在为下一款游戏"蓄能"。

对于非游戏类的一人公司，"内容飞轮"同样适用。一个做AI教育课程的一人公司创始人，她的飞轮是：

```
发布免费教程 → 吸引流量 → 建立信任 → 转化付费课程 → 学员分享学习成果 → 吸引更多流量 → 发布新教程 → ...
```

一人公司的内容生产系统：AI生成初稿，你做深度修改和审核，AI自动分发到多个平台。每周投入约十五小时，产出三到五篇高质量内容。

## 四、SEO与有机增长：一人公司的流量获取策略

一人公司没有"营销预算"。你不能投广告、不能请KOL、不能做大型活动。

你的流量获取策略必须是有机的：不花钱，但花时间。

SEO（搜索引擎优化）是一人公司最核心的流量策略。为什么？因为SEO是"一次投入，持续收益"。你写一篇文章，它可以在搜索引擎上排名好几年，持续为你带来流量。而广告是"一次投入，一次收益"，你停止付费，流量就消失。

一人公司的SEO策略：

竞争长尾关键词。不要竞争"AI工具"这样的大词，竞争"2026年最好用的AI翻译工具对比"这样的长尾词。竞争小，转化高。

建立内容集群。围绕一个主题，写十到二十篇相关文章，形成"内容集群"。搜索引擎会把你的网站视为这个主题的"权威"。

AI辅助但人类主导。用AI生成初稿、优化标题、生成meta description。但核心观点和经验必须是你的。AI生成的"通用内容"在搜索引擎上越来越没有竞争力。

## 五、定价策略：从按小时到按价值

一人公司的定价革命：不要按"时间"定价，要按"价值"定价。

按时间定价："我的咨询费是500元/小时。"你的收入上限是"你的时间"。一天最多工作十二小时，收入上限就是六千元。

按价值定价："我帮你解决的问题值五万元，我收五千元。"你的收入上限是"你创造的价值"。如果你帮一个企业节省了百万元的成本，你收十万元是合理的，即使你只花了两个小时。

阿弹幕的定价策略也经历了这个转变。第一款游戏定价28元（"我觉得值这个价"）。第三款游戏定价48元（"日本玩家愿意为高质量弹幕游戏付更多"）。第六款游戏定价68元，加上DLC和原声音乐包，客单价达到了120元。

他没有"降价促销"。他"涨价提质"。

## 六、客户成功自动化：一个人如何服务1000个客户

当你有1000个客户时，你不可能"手动"服务每一个人。

阿弹幕的"客户成功"是这样运作的：

新玩家购买游戏后，自动收到一封欢迎邮件（包含游戏攻略链接、社区入口、反馈渠道）。如果玩家遇到问题，AI客服Agent会自动回复（基于游戏FAQ知识库）。如果AI无法解决，问题会被标记并转发给阿弹幕。每周，AI自动生成一份"玩家反馈报告"，阿弹幕花三十分钟浏览，决定是否需要更新游戏。

这套系统让他可以用"一个人"服务"数万个玩家"，同时保持"个性化"的体验。

## 七、何时该"不增长"：一人公司的反规模哲学

阿弹幕在2025年底做了一个决定：不再增加产量。

"我一年做六款游戏，已经很累了，"他说，"我可以做十二款，但质量会下降。我不想为了'增长'而牺牲质量。"

他选择停在"一年六款"。不是因为"不能做更多"，是因为"不想做更多"。

这就是一人公司的"反规模哲学"：找到一个"足够好"的规模，然后停在那里。

"足够好"的定义因人而异。对阿弹幕来说，年入80到100万，一年做六款游戏，每天工作六小时，剩下的时间打游戏、看动画、散步。这就是"足够好"。

一人公司与传统企业的根本区别在这里：传统企业追求"无限增长"，一人公司追求"有限自由"。

Pieter Levels（Nomad List创始人）在2026年的年收入超过200万美金。他的"团队"是他自己加几个AI工具。他拒绝了所有投资、所有收购要约。有人问他："你为什么不做大？"他说："因为我不想管理任何人。我想要的不是'更大的公司'，是'更多的自由'。"

这种选择，在"增长至上"的商业文化中，是一种安静的反抗。
