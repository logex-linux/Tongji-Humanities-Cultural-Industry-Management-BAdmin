## 二、唐宋古文运动——扫荡七百年骈文

### 2.1 骈文的问题

骈文不是不好——**骈文很美**，几乎很难有人从骈文的"美文坑"里出来。但发展到魏晋南北朝，美丽的语言形式已经严重制约了文章**传情达义**的功能——"为了说漂亮话，你都不知所云"。

**庾信的例子**——一篇描写灯赋中的句子：

> 九龙将暝，三爵行栖。琼钩半上，若木全低。窗藏明于粉壁，柳助暗于兰闺。

解读："九龙"是太阳、"三爵"是太阳、"琼钩"是月亮、"若木"是太阳→**太阳下去了，月亮上来了**。"窗藏明于粉壁"→窗外有白墙，将黑未黑；"柳助暗于兰闺"→窗外有棵柳树，使其更暗。全句的意思其实就是三个字：**天黑了**。

> "这一句有很多典故——骈文不但美，还雅。雅怎么造成的？用典故。典故了自然就雅了……意义却非常孱弱。你偶尔看一下还行，但如果所有文章都是这个调调，信息探索的过程就曲折太久。"

**骈文的定义**：并驾齐驱的两匹马——每个意义、每种情感都以**双句**形式出现。所有意义都要 double 一下，好处是加深印象，坏处是"有一把是废话"。

**"文质"这个词**："文"是漂亮华丽，"质"是功能性。"文质很好"实际上是**功能性兼审美性**。但我们现在把"文质很好"看作"文采很好"——只有文好，没有质好。六朝理论上是文质并重，但实践上没有做到。

### 2.2 韩愈——古文概念的提出者

- 唐代两个（韩愈、柳宗元），宋代六个，共同扫荡骈文
- 韩愈针对骈文（当时的"时文"）提出了"**古文**"概念
- 古文特点：**单行散句**，不再成双成对出现，一个意思一句话表达清楚即可，没有固定格式

**历史轮回**：唐末又回归骈文（五代江南艺术气息太重）→宋代再来一波古文运动→欧阳修牵头。赵匡胤"兵子出身"，治国理念"文治武功"与唐代不同——希望文章恢复到实用功能。

> "诗歌主要承载情志，但文章有一大部分是应用文。你给老师写请假条，只要说因训练/因感冒，不需要写一篇记叙文阐述病的前因后果……文章不大可能是纯审美的，功能性运作如果摆脱不了形式主义，作用就大大降低了。"

**宋祁与欧阳修**：欧阳修之前文坛领袖是宋祁（"红杏枝头春意闹"），出身好起点高又是宰相。宋祁与哥哥同科——本应弟弟中状元（年龄偏小），但放榜前做了调整：哥哥改状元，弟弟往后挪很多名→"名义上的状元和实际上的状元，叫双状元。"

## 三、韩愈——经典儒生的教科书

### 3.1 名字即命运

- **名"愈"**：往前走一小步
- **字"退之"**：往后退一步
- →"一看就知道这是奉行中庸之道的儒家家族文化——求如此之中正平和。往前走一步，我的字就得往后退一步，达到一种平衡和中庸。"

**名字对照**：
- 李白字太白→"地极"——不中庸（李白不是儒生）
- 杜甫字子美→甫=一开始，子美=小宝宝好，赤子之美——"从最初就是美的，不忘初心"；"既儒又红"

### 3.2 出身与早年

- 三岁丧父，长兄韩会（长兄如父）承担启蒙教育。韩会早逝后，寡嫂继续照顾。
- "穷不自存"——穷到没法存在
- 写字"没有纸和笔"，拿树枝在沙地上写
- **幸在唐代**：若早生一百年在魏晋南北朝世族时代，根本没有上升渠道

> "科举考试恰恰是开了寒门之路——打开了中国的国家之门。过去两千年间，寒门取士这条路给了这个民族源源不断的新鲜血液。放到今天，高考制度依然是广开不论出处——一张卷子定终生，虽然残酷，但公平。"

### 3.3 仕途坎坷

| 年龄 | 事件 |
|------|------|
| 7岁 | 开始读书作文 |
| 13岁 | "能文"（古人"能文"标准远高于现在） |
| 20岁 | 入京师参加科考→**三败**→第四回才中进士（唐代"六十少进士"，26岁已属年轻） |
| 26岁 | 中进士，但"无官可作"→十年求官 |
| 36岁 | 国子监博士（无实权文化官员） |
| 37岁 | 监察御史（清差大臣，朝廷三品重臣）→上任仅**三个月** |

**《御史台上天旱人饥状》**：田野考察发现天旱人饥到处灾情→写奏章→"皇帝不是不愿意听到，而是你把状况描述得好像我无德似的"→**贬为山阳令**（从三品贬为七品芝麻官）

> "十年谋官，上台不到三个月就已经被贬了。对于他的仕途是重大挫折，但对于他的创作是良好的契机——他所有好文章几乎都写作于贬谪时期。"

**《论佛骨表》**：西域来了一批舍利子→宪宗皇帝（好佛）想动用国库建塔供奉→韩愈怒了→"一封朝奏西贬潮阳"——早上递奏章，晚上就让滚到潮阳去，而且"**即日出京，不许带行李**。"

> "可见皇帝生气到什么程度。"

韩愈有一个特点：**非常善于反思**。上次被贬后给皇帝写了反思信→宪宗原谅了他。这次一上路就开始反思，还没到目的地信已经到了→皇帝后悔→韩愈又回去了。**"从此再也没有写过针砭时弊的文章，一直留在长安城到老死。"**

> "他们一直开玩笑说：韩愈如果长期被贬，文学成就远不止于此。但这样对个人命运太残酷了——他醒悟得太早，整个晚年没有任何代表作。"

### 3.4 韩愈的文学思想

**"慈必己出，陈言务去"**——教师要用来作期末考题标准：不能抄，要有自己读到的东西。

**韩愈的散文贡献**：苏轼评"**文起八代之衰**"。苏洵评：文章"**如长江大河，浑浩流转**"。杜牧评："**杜诗韩笔**"——用的是"笔"，强调文章的功能性，不是一味追求审美。

## 四、《送孟东野序》——"不平则鸣"

### 4.1 文章结构

一篇标准的"高考作文"——如果不看最后对孟郊的安慰，就是一篇非常完整的文章。

**核心命题**：不要因为被贬就以为时代抛弃了你。贬到任何地方都应该努力发出声音。声音足够宏大，一定能传播得远。

> 开篇即点题——"**大凡物不得其平则鸣。**"

### 4.2 自然界的"不平则鸣"

| 被激发物 | 激发力 | 声音 |
|------|------|------|
| 草木（无声） | 风挠之 | 发出声 |
| 水（无声） | 风荡之 | 滔天水声 |
| 水之腾跃 | 有物阻遏（石头） | 受激扬 |
| 水之湍急 | 狭窄阻塞 | 水流加快 |
| 水之沸腾 | 底下加火 | 沸腾 |
| 金石（无声） | 敲击之 | 发出声音 |

> "人之于言也亦然——有不得已者而言。人最初的语言是怎么产生的？如果你养宠物，狗和猫着急的时候，就差一点就能说人话了。人大概也是被逼出来的语言。"

**汉民族的语言独大**：言之不尽→可以用歌舞来加持→其他民族在语言和歌舞之间找到平衡。汉民族语言独大→大到歌舞都没有存在空间了。"我们激动的时候不是去唱去跳，而是'你听我讲'。酒过三巡之后，汉族人是'你听我讲'——开始聊自己的光荣往事，全部是语言。"

> "语言的尽头是音乐……但我们的语言太发达了，导致没有尽头。你终其一生都可以找到合适的语言来表达。"

### 4.3 四时各有其声

- 雷声→夏天
- 虫声→秋天
- 风声→冬天
- "四时之相推夺，其必有不得其平者乎。"

### 4.4 历代善鸣者谱系（全文最核心段落）

韩愈列举了从上古到唐代的所有"善鸣者"：

| 时代 | 善鸣者 | 鸣的形式 |
|------|------|------|
| 唐虞 | 皋陶、禹 | 为时代发声 |
| 夏 | 夔 | 韶乐（孔子推崇的中正雅乐） |
| 夏末 | 五子（太康五弟） | 悲歌 |
| 商 | 伊尹 | 贤臣劝诫 |
| 周初 | 周公 | 明周 |
| 周末（春秋） | **孔子之徒** | "声大而远"→天以夫子为木铎 |
| 战国末 | 庄周 | "荒唐之词"（汪洋自恣，崇尚自由） |
| 楚 | 屈原 | 为楚王而鸣 |
| 战国 | 孟轲、荀卿 | 以道鸣（学术、学说） |
| 战国 | 杨朱、墨翟、管夷吾、晏婴、老聃、申不害、韩非、慎到、田骈、邹衍、尸佼、孙武、张仪、苏秦 | 皆以其术鸣（策略、谋略） |
| 秦 | 李斯 | 法家——效率 |
| 汉 | 司马迁、司马相如、扬雄 | 最善鸣者 |
| 魏晋 | （有善鸣者但）"其声轻以浮""其辞淫以哀""其志弛以肆""杂乱而无章" | 失落的三百年 |
| 唐 | 陈子昂、苏源明、元结、李白、杜甫、李观 | 皆以其所能鸣 |
| 唐（当世） | **孟郊** | 以诗鸣 |

> "魏晋明者不及于古……其辞淫以哀，其志弛以肆，其为言杂乱而无章——这不就是说的嵇康吗？"

对孟郊的评价："高出魏晋，不懈而及于古"——水平比魏晋人高多了，已快接近古代的高度。"越古越好，古道先秦诸子散文就是最高级的。"

### 4.5 结尾——对孟郊的安慰

> "三子者之命，则悬乎天矣。其在上也奚以喜，其在下也奚以悲。"

儒家一贯讲的"不以物喜，不以己悲"——你去了溧阳（今天目湖一带，苏浙皖三省交汇处）又怎么着？过一千年你来看——这是最好的江南。

> "不管在哪里，只要你实际地发出声音，时代就会选择把你的声音留下来。再朝再野，再京再江南。"

## 五、柳宗元——接地气的"寓言大师"

### 5.1 永州八记

永州（80%是山区，经济发展受限）→柳宗元被贬到此→开创了中国山水游记的重要里程碑。

**《小石潭记》**：清幽冷绝——表面写清幽冷绝之处，实则**自喻**：被贬到永州就像小石潭，清冽寒冷、无人知晓，却独自散发着人格魅力。

**《钴鉧潭记》**：一座主人废弃不要的水潭→花很便宜的价格买下来→喜欢它的清幽冷静→又被朝廷抛弃了，但"在这地方其实我是有我的美的，只无人知晓"。

### 5.2 三戒（寓言三篇）

| 篇名 | 寓意 |
|------|------|
| **《黔之驴》** | 驴虚张声势（叫声吓老虎、踢腿）→最终被老虎识破吃掉。**不要虚张声势——终有高人把你识破。** |
| **《临江之麋》** | 猎人把小鹿抱回家养→狗在主人面前假装爱鹿→麋鹿以为狗是朋友→出门遇群犬→被吃掉至死不知为什么。**不要因为养尊处优而关闭了你看世界的窗口。** |
| **《永某氏之鼠》** | 某人属鼠（生肖），不许家人灭鼠→鼠害成灾→此人搬走后新主人灭鼠（猫+开水灌洞）→死鼠堆成山丘。**不要以为人类是你的朋友——不要习以为常，忘却本性。** |

### 5.3 《捕蛇者说》

永州产毒蛇→捕蛇可以抵税→宁愿去捕蛇（被咬一口就命没了）也要抵税→**"苛政猛于虎"**——税比生命还重。

## 七、本讲小结

1. **古文运动**的核心是扫荡骈文的"美文"传统——让文章回归传情达义的功能
2. **韩愈一生**是经典儒生的教科书：穷不自存→三败四中→十年求官→上任三月即贬→论佛骨表→朝奏夕贬→终于"醒悟"，但文学也就此止步
3. **《送孟东野序》**以"不平则鸣"立论，从草木→金石→人→天→历代善鸣者谱系，层层递进，是韩愈"文起八代之衰"的典范之作
4. **柳宗元**的永州八记和三戒——以山水自喻、以寓言刺世，"骂人都不带脏字"
5. **AI是这个时代最响的"鸣者"**：各AI工具已分化出不同人格——从逻辑到情绪、从学术到公文、从多模态到脱敏
