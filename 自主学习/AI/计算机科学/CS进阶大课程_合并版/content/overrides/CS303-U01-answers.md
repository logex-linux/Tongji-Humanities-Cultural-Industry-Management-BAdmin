## F1（10分）

题面：图边 S-A=2、S-B=5、A-G=4、B-G=1。状态只为当前位置，列出两条路径代价并判断哪条最优。

答案：S-A-G 代价6；S-B-G代价6，二者并列最优。若把步数当代价则两条也都是2步，但必须说明代价定义。

计分：结论4分；中间推导4分；前提/边界2分。

## F2（10分）

题面要求分别判断q/r合法性，并只列合法后继。

答案：q 合法，后继 (1,{p,q})；r 不合法，因为3<4，没有 r 后继。

计分：计算或状态4分；机制依据3分；边界2分；表达1分。

## F3（10分）

题面：传感器只返回 {B,C}，动作 move(B,D) 只在真实位置B合法。若状态只写‘可能在B或C’，说明为何不能执行该动作，并给出最小信念状态表示。

答案：不能安全执行：真实位置可能是C。应保留信念集合 {B,C}，并把动作结果定义为对集合的更新或先采取能区分位置的观测。

计分：分类/结论4分；理由3分；修复或限制2分；证据1分。

## I1（20分）

S可表示为{A,K,D,G}×{0,1}，q表示是否持有许可证；这是一个覆盖全部可达状态的表示，不要求每个笛卡尔积元素都实际可达。初始(A,0)，目标谓词为位置等于G。动作仅沿题设有向边；D→G还要求q=1。到达K令q'=1，其他移动令q'=q；c取给定边权。

直达：(A,0,g=0)→(G,0,g=8)。持证路线：(A,0,0)→(K,1,1)→(A,1,2)→(D,1,4)→(G,1,5)。到A的两段历史不能合并：证件影响后续D→G的合法性。若只保留“第一次到A且代价0”，会丢弃已经领证的A状态，进而漏掉合法的5代价方案。

计分：模型五要素6分；两条完整状态/代价轨迹6分；不能合并的因果反例6分；说明边方向和固定假设2分。本题不给UCS队列或算法名额外分。

## I2（20分）

一个足够的后继生成器如下，未实现搜索算法：

```python
EDGES = {"A": [("K", 1), ("D", 2), ("G", 8)],
         "K": [("A", 1)], "D": [("G", 1)], "G": []}

def successors(state):
    position, permit = state
    result = []
    for target, cost in EDGES[position]:
        if position == "D" and target == "G" and not permit:
            continue
        next_permit = permit or target == "K"
        result.append(((target, next_permit), cost))
    return result
```

(A,0)有(K,1)/1、(D,0)/2、(G,0)/8；(A,1)有(K,1)/1、(D,1)/2、(G,1)/8；(D,0)没有后继；(D,1)有(G,1)/1。只有两段历史的未来动作、转移和代价等任务相关信息都等价时，才可合并。位置相同不是充分条件。

计分：边与前提处理8分；四个状态的后继6分；证件更新与历史等价说明4分；方向及非法边边界2分。

## T1（20分）

状态用(位置,r)，r∈{0,1,2}。移动前D→G要求r>0；移动到K重置r'=2，否则r'=max(r-1,0)。起点(A,0)。

原路线变为(A,0,0)→(K,2,1)→(A,1,2)→(D,0,4)，到D时已经过期，不能再走D→G；“到过K所以一直有证”失效。直达A→G不要求许可证，仍合法，代价8。在给定图中每次从K到门前D都需两次移动，所以重复领证也无法走过D→G；剩下的合法到达方案以直达边收尾，非负绕行只会增加代价，最小为8。

计分：剩余步数模型与前提6分；新状态轨迹6分；合法方案及失效解释6分；不能把永久证件布尔更新照搬2分。

## D1（10分）

状态为(位置,是否有卡)，卡在本图中不会变化。初始有卡时P→Q→R合法、代价6，比直达9小；无卡时Q→R不合法，只能直达，代价9。两种P状态位置相同却不能在不知道卡状态时混为一谈；目标只检查位置R，动作合法性仍需卡变量。
