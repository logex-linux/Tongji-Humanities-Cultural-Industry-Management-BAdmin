2.1 矩阵是什么？——数字的表格

直觉：矩阵就是一个"数字表格"

如果你用过 Excel 表格，那你已经理解矩阵了。矩阵就是把数字排成一个 m 行 n 列的表格：

📌 核心概念：矩阵

矩阵是一个 m×n 的数字表格（m 行 n 列）。用大写字母表示，如 A、W。

矩阵中第 i 行第 j 列的数字记作 A[i,j] 或 aᵢⱼ。

上面的矩阵：A[1,1]=1, A[1,3]=3, A[2,4]=8

Python 中的矩阵

import numpy as np

# 创建一个 2×4 矩阵
A = np.array([
    [1, 2, 3, 4],   # 第1行
    [5, 6, 7, 8]    # 第2行
])

print(A.shape)   # (2, 4) → 2行4列
print(A[0, 0])   # 1（第1行第1列，注意从0开始数）
print(A[1, 3])   # 8（第2行第4列）
print(A[0])      # [1 2 3 4]（取第1行）
print(A[:, 2])   # [3 7]（取第3列）

为什么 AI 需要矩阵？

回忆第1章：向量表示数据。那矩阵表示什么？

矩阵表示"变换规则"——它定义了一种把输入向量变成输出向量的操作。

类比：向量是"食材"，矩阵是"菜谱"（加工规则），输出是"做好的菜"。

2.2 矩阵 × 向量——变换的机器

核心操作：矩阵乘以向量

这是 AI 中最最重要的运算。神经网络每一层的核心计算就是"矩阵 × 向量"。

📌 计算规则

一个 m×n 矩阵 乘以一个 n 维向量，得到一个 m 维向量。

方法：矩阵的每一行和向量做点积，得到输出向量的一个分量。

输出的第 i 个分量 = 矩阵第 i 行 · 输入向量
🌉 直觉桥梁：连接第1章

还记得第1章学的点积吗？矩阵×向量其实就是多次点积：

矩阵的每一行和向量做一次点积，得到输出的一个分量。2×3 矩阵 × 3维向量 = 做 2 次点积 → 得到 2 维输出。

所以你已经会了！矩阵乘法不是新运算，只是"批量点积"。

一步一步计算

✏️ 例题 2.1：手算矩阵×向量

计算：

[2 1 0] [1] [?] [0 3 1] × [2] = [?] [3]
第1步：第1行 · 向量 = 2×1 + 1×2 + 0×3 = 2 + 2 + 0 = 4
第2步：第2行 · 向量 = 0×1 + 3×2 + 1×3 = 0 + 6 + 3 = 9
结果：输出向量 = (4, 9)

注意：3×3 矩阵 × 3维向量 = 3维向量（输入输出维度相同）

✏️ 例题 2.2：维度变化

计算： 一个 2×3 矩阵乘以 3 维向量

[1 0 2] [1] [?] [3 1 0] × [2] = [?] [1]
第1行 · 向量 = 1×1 + 0×2 + 2×1 = 1 + 0 + 2 = 3
第2行 · 向量 = 3×1 + 1×2 + 0×1 = 3 + 2 + 0 = 5
结果：输出 = (3, 5) ← 从3维变成了2维！

💡 关键认知：矩阵可以改变向量的维度！m×n 矩阵把 n 维向量变成 m 维向量。

👇 动画：矩阵的每一行依次和向量做点积，得到输出的一个分量

Python 实现

import numpy as np

# 矩阵 × 向量
W = np.array([[1, 0, 2],
              [3, 1, 0]])   # 2×3 矩阵
x = np.array([1, 2, 1])     # 3维向量

y = W @ x  # @ 是矩阵乘法运算符
print(y)   # [3 5]

# 也可以用 np.dot
y2 = np.dot(W, x)
print(y2)  # [3 5]（结果一样）

# 手动实现（理解原理）
def mat_vec_mul(W, x):
    """矩阵W的每一行和向量x做点积"""
    result = []
    for row in W:
        dot = sum(row[j] * x[j] for j in range(len(x)))
        result.append(dot)
    return result

print(mat_vec_mul([[1,0,2],[3,1,0]], [1,2,1]))  # [3, 5]
📌 维度匹配规则（必须记住！）

(m × n) 矩阵 × (n 维向量) = (m 维向量)

矩阵的列数必须等于向量的维度，否则无法相乘！

例：2×3 矩阵 × 3维向量 ✓（列数3 = 向量维度3）

例：2×3 矩阵 × 2维向量 ✗（列数3 ≠ 向量维度2，报错！）

2.3 几何直觉——旋转、拉伸、投影

矩阵乘以向量，在几何上就是对向量做"变换"。不同的矩阵产生不同的效果：

变换1：拉伸

变换2：旋转

📌 核心认知

矩阵 = 一种线性变换。它把输入向量"变换"成输出向量。

不同的矩阵实现不同的变换：旋转、拉伸、翻转、投影……

在神经网络中，每一层的权重矩阵 W 就是一种"学到的变换"——它学会了如何把输入数据变换成对任务有用的表示。

2.4 矩阵 × 矩阵——变换的叠加

为什么需要矩阵乘矩阵？

如果矩阵 A 是一种变换，矩阵 B 是另一种变换，那么"先做 A 变换，再做 B 变换"就等于 B × A（注意顺序！）。

神经网络有很多层，每层是一个矩阵。多层网络 = 多个矩阵连续相乘 = 多个变换叠加。

计算规则

📌 矩阵乘法规则

(m × n) × (n × p) = (m × p)

结果矩阵的第 i 行第 j 列 = 左矩阵第 i 行 · 右矩阵第 j 列

⚠️ 左矩阵的列数必须等于右矩阵的行数！

✏️ 例题 2.3：矩阵乘法

计算 (2×3) × (3×2)：

[1 2 3] [7 8] [? ?] [4 5 6] × [9 10] = [? ?] [11 12]
结果[1,1] = 第1行·第1列 = 1×7 + 2×9 + 3×11 = 7+18+33 = 58
结果[1,2] = 第1行·第2列 = 1×8 + 2×10 + 3×12 = 8+20+36 = 64
结果[2,1] = 第2行·第1列 = 4×7 + 5×9 + 6×11 = 28+45+66 = 139
结果[2,2] = 第2行·第2列 = 4×8 + 5×10 + 6×12 = 32+50+72 = 154
结果 = [[58, 64], [139, 154]]（2×2 矩阵）
A = np.array([[1, 2, 3],
              [4, 5, 6]])       # 2×3
B = np.array([[7, 8],
              [9, 10],
              [11, 12]])        # 3×2

C = A @ B
print(C)       # [[ 58  64]
               #  [139 154]]
print(C.shape) # (2, 2)
⚠️ 矩阵乘法不满足交换律！

A × B ≠ B × A（通常不相等，甚至可能维度不匹配无法计算）

直觉：先旋转再拉伸 ≠ 先拉伸再旋转

2.5 特殊矩阵

单位矩阵 I——"什么都不做"的变换

I = [1 0] I × v = v（任何向量乘以单位矩阵不变） [0 1]

类比：数字 1 在乘法中的角色。a × 1 = a，向量 × I = 向量。

零矩阵——"全部归零"的变换

0 = [0 0] 0 × v = 0（任何向量乘以零矩阵变成零向量） [0 0] 
I = np.eye(3)  # 3×3 单位矩阵
print(I)
# [[1. 0. 0.]
#  [0. 1. 0.]
#  [0. 0. 1.]]

v = np.array([5, 3, 7])
print(I @ v)  # [5 3 7]（不变！）

2.6 转置——行列互换

把矩阵的行变成列、列变成行：

A = [1 2 3] Aᵀ = [1 4] [4 5 6] [2 5] [3 6] (2×3 变成 3×2) 
A = np.array([[1, 2, 3], [4, 5, 6]])
print(A.T)  # 转置
# [[1 4]
#  [2 5]
#  [3 6]]

转置在 AI 中很常见，比如计算注意力机制时需要把 K 矩阵转置：Q × Kᵀ。

2.7 神经网络中的矩阵——线性层

一层神经网络 = 一次矩阵运算

📌 神经网络的核心公式
y = W × x + b

其中：

  • x：输入向量（n 维）
  • W：权重矩阵（m×n）——这是网络要"学习"的参数
  • b：偏置向量（m 维）——也是学习的参数
  • y：输出向量（m 维）

训练神经网络 = 找到合适的 W 和 b，让输出 y 尽可能接近正确答案。

✏️ 例题 2.4：模拟一个神经网络层

假设输入 x = (1, 2)，权重 W = [[1, 0], [0, 1], [1, 1]]，偏置 b = (0, 0, 1)

第1步：W × x = [1×1+0×2, 0×1+1×2, 1×1+1×2] = [1, 2, 3]
第2步：加上偏置 b：[1+0, 2+0, 3+1] = [1, 2, 4]
输出 y = (1, 2, 4)（从2维变成了3维）
# 用 PyTorch 实现一个线性层
import torch
import torch.nn as nn

# 创建一个线性层：输入2维，输出3维
layer = nn.Linear(in_features=2, out_features=3)

# 查看参数
print(layer.weight.shape)  # torch.Size([3, 2]) ← 权重矩阵 3×2
print(layer.bias.shape)    # torch.Size([3])    ← 偏置向量 3维

# 前向计算
x = torch.tensor([1.0, 2.0])
y = layer(x)
print(y)  # 输出3维向量

# 手动验证：y = W @ x + b
y_manual = layer.weight @ x + layer.bias
print(y_manual)  # 和上面结果一样！

2.8 批量处理——一次处理多个样本

实际问题

训练时我们不是一个个样本处理的，而是一批（batch）一起处理。如果有 100 个样本，每个 784 维，怎么一次全算？

解决方案：数据矩阵

把 100 个样本排成一个 100×784 的矩阵 X，然后：

Y = X × Wᵀ + b (100×784) × (784×256) = (100×256) 100个样本，每个从784维变成256维 
# 批量处理示例
batch_size = 100
input_dim = 784
output_dim = 256

# 100个样本，每个784维
X = np.random.randn(batch_size, input_dim)  # shape: (100, 784)

# 权重矩阵
W = np.random.randn(output_dim, input_dim)  # shape: (256, 784)
b = np.zeros(output_dim)                     # shape: (256,)

# 一次计算所有样本的输出
Y = X @ W.T + b  # shape: (100, 256)
print(Y.shape)   # (100, 256) ← 100个样本，每个256维

# 这就是为什么 GPU 快：矩阵乘法可以高度并行！
📌 维度总结（AI 中最常见的形状）
数据形状含义
一个样本(784,)784维向量
一批样本(batch, 784)batch个784维向量
权重矩阵(output, input)线性变换的参数
输出(batch, output)batch个output维向量
⚠️ 常见误区
✗ "矩阵乘法满足交换律：A×B = B×A"
✗ 矩阵乘法不满足交换律！A×B 和 B×A 通常不相等，甚至可能维度不匹配无法计算。直觉：先旋转再拉伸 ≠ 先拉伸再旋转。
✗ "矩阵就是一个数字表格"
✓ 矩阵是一种线性变换。表格只是存储形式。矩阵的本质是"把输入向量变换成输出向量"的规则。神经网络每层的权重矩阵就是一种学到的变换。
✗ "矩阵越大，网络越强"
✓ 参数量要和数据量匹配。参数太多、数据太少 → 过拟合（背答案）。参数太少、数据很多 → 欠拟合（学不够）。

# 题10
def mat_vec_mul(W, x):
    result = []
    for row in W:
        s = sum(row[j] * x[j] for j in range(len(x)))
        result.append(s)
    return result

# 题12：3层网络前向传播
import numpy as np
np.random.seed(42)

x = np.random.randn(4)          # 输入 4维
W1 = np.random.randn(8, 4)     # 第1层权重
b1 = np.zeros(8)
W2 = np.random.randn(6, 8)     # 第2层权重
b2 = np.zeros(6)
W3 = np.random.randn(2, 6)     # 第3层权重
b3 = np.zeros(2)

# 前向传播（暂不加激活函数）
h1 = W1 @ x + b1   # 8维
h2 = W2 @ h1 + b2  # 6维
y  = W3 @ h2 + b3  # 2维
print(f"输入: {x.shape} → h1: {h1.shape} → h2: {h2.shape} → 输出: {y.shape}")
