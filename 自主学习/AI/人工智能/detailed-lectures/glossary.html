第1章 · 向量
向量Vector
一组有序的数字。在 AI 中用来表示数据（图片、文字、用户特征）。
第1章
点积Dot Product
对应分量相乘再求和。衡量两个向量的相似程度：正=相似，0=无关，负=相反。
第1章
余弦相似度Cosine Similarity
点积除以两个向量的长度。只看方向不看大小，范围 [-1, 1]。AI 搜索和推荐的核心。
第1章
范数 / 归一化Norm / Normalize
向量的"长度"（√各分量平方和）。归一化 = 除以长度，得到长度为 1 的单位向量。
第1章
第2章 · 矩阵
矩阵Matrix
m行n列的数字表格。在 AI 中表示"变换规则"——把输入向量变成输出向量。
第2章
线性变换Linear Transform
矩阵×向量。把输入空间中的点"变换"到输出空间。旋转、拉伸、投影都是线性变换。
第2章
权重 / 参数Weight / Parameter
神经网络中需要学习的数字。训练就是调整这些数字让预测更准确。
第2章
偏置Bias
加在加权求和后面的常数。让模型能拟合不过原点的关系。y = Wx + b。
第2章
第3章 · 梯度下降
损失函数Loss Function
衡量预测值和真实值差距的公式。越小越好。常用 MSE（均方误差）和交叉熵。
第3章
梯度Gradient
损失对参数的导数。指向损失增大最快的方向。沿负梯度走 = 下坡 = 损失减小。
第3章
学习率Learning Rate (η)
每步走多远。太大→震荡发散；太小→收敛极慢。常用 0.001。
第3章
Epoch / BatchEpoch / Batch
Epoch = 所有数据过一遍。Batch = 每次用的一小批数据（如 32 个样本）。
第3章
第4章 · 神经网络
神经元Neuron
网络的基本单元。做两步：加权求和 → 激活函数。y = f(W·x + b)。
第4章
激活函数Activation Function
引入非线性的函数。没有它，100 层网络 = 1 层。ReLU 是默认选择。
第4章
前向传播Forward Pass
数据从输入层逐层流到输出层，得到预测值。就是"用模型做预测"。
第4章
过拟合 / 欠拟合Overfit / Underfit
过拟合：训练好但测试差（背答案）。欠拟合：训练和测试都差（学不够）。
第4章
第5章 · 反向传播
反向传播Backpropagation
从输出往回逐层用链式法则计算梯度。一次前向+一次反向算出所有参数的梯度。
第5章
链式法则Chain Rule
复合函数求导：dy/dx = (dy/du)×(du/dx)。反向传播的数学基础。
第5章
梯度消失Vanishing Gradient
深层网络中梯度逐层相乘变得越来越小，前面的层学不动。用 ReLU、残差连接解决。
第5章
第6章 · CNN
卷积Convolution
小窗口在输入上滑动，每个位置做点积。检测局部特征（边缘、纹理）。
第6章
卷积核Kernel / Filter
一个小矩阵（如 3×3），是"特征检测器"。权重通过训练学出来。
第6章
池化Pooling
在小窗口内取最大值（或平均值），降低分辨率。提供平移不变性。
第6章
残差连接Residual Connection
output = F(x) + x。让梯度可以"跳过"层传播，使训练 100+ 层成为可能。
第6章
第7章 · Transformer
注意力机制Attention
让每个词"看到"所有其他词，计算相关度，加权融合信息。
第7章
Q / K / VQuery / Key / Value
同一个词的三种投影。Q=我在找什么，K=我能提供什么，V=我的实际内容。
第7章
多头注意力Multi-Head Attention
多个注意力头并行，各自关注不同关系（语法、指代、修饰），最后拼接。
第7章
位置编码Positional Encoding
告诉模型词的顺序。自注意力本身不知道顺序，必须额外注入。
第7章
第8章 · 大语言模型
TokenToken
文本的最小处理单位（子词级别）。英文约 1 token ≈ 0.75 词，中文约 1 字 ≈ 1-2 token。
第8章
预训练Pre-training
在海量文本上训练"预测下一个词"。学到语言能力和世界知识。
第8章
SFT / 对齐SFT / Alignment
SFT：用指令-回答对学会遵循指令。对齐（DPO/RLHF）：让回答有帮助、诚实、无害。
第8章
PromptPrompt
给模型的输入文本。好的 Prompt = 角色 + 任务 + 约束 + 格式 + 示例。
第8章
思维链 (CoT)Chain of Thought
让模型"一步步思考"再给答案。显著提高数学和逻辑推理的准确率。
第8章
LoRALow-Rank Adaptation
只训练一个小的"增量"（0.1% 参数），不动原始权重。单卡就能微调 7B 模型。
第8章
幻觉Hallucination
模型编造不存在的事实（假论文、假引用）。RAG 是主要缓解手段。
第8章
第9章 · RAG 与 Agent
RAGRetrieval-Augmented Generation
先检索相关文档，再让 LLM 基于文档回答。减少幻觉，利用私有数据。
第9章
EmbeddingEmbedding
把文本变成向量。含义相近的文本 → 向量相近。是语义搜索的基础。
第9章
向量数据库Vector Database
专门存储和检索向量的数据库。能在百万向量中毫秒级找到最相似的 Top-K。
第9章
AgentAgent / 智能体
LLM + 工具调用 + 规划。能"做事"（搜索、计算、执行代码），不只是"说话"。
第9章
Function CallingFunction Calling
LLM 决定调用什么工具、传什么参数。开发者实现工具函数，LLM 负责决策。
第9章
第10章 · 部署与 MLOps
DockerDocker
把整个运行环境打包成"镜像"，任何机器都能一致运行。解决"在我机器上能跑"。
第10章
量化Quantization
减少每个参数的位数（如 FP32→INT4）。体积缩小 8 倍，精度损失 < 2%。
第10章
推理Inference
用训练好的模型做预测。和"训练"相对。vLLM、Ollama 是推理引擎。
第10章
数据漂移Data Drift
线上数据分布和训练时不同，导致模型性能悄悄下降。需要持续监控。
