5.1 问题：如何计算每个参数的梯度？

困境

一个神经网络可能有百万甚至亿级参数。梯度下降需要知道"每个参数应该怎么调"，也就是需要计算损失 L 对每个参数的偏导数：

∂L/∂w₁, ∂L/∂w₂, ∂L/∂w₃, ..., ∂L/∂w₁₀₀₀₀₀₀

如果用"数值方法"（每个参数微调一点，看损失变化多少），100 万个参数就要前向计算 100 万次——太慢了！

反向传播的妙处：只需要一次前向 + 一次反向，就能同时算出所有参数的梯度。

📌 反向传播的核心思想

利用链式法则，从输出层往回逐层计算梯度。

每一层只需要知道"后面传来的梯度"和"本层的局部导数"，相乘就得到本层的梯度。

类比：公司出了问题（损失），从最上层（输出）开始追责，一层层往下传递"责任"（梯度）。

5.2 链式法则——复合函数求导

回顾：什么是链式法则？

如果 y = f(g(x))（复合函数），那么：

dy/dx = (dy/dg) × (dg/dx)

"外层的导数 × 内层的导数"

✏️ 例题 5.1：链式法则基础

求 y = (3x + 2)² 的导数：

分解：令 u = 3x + 2（内层），y = u²（外层）
外层导数：dy/du = 2u
内层导数：du/dx = 3
链式法则：dy/dx = 2u × 3 = 2(3x+2) × 3 = 6(3x+2)

多层复合

如果 y = f(g(h(x)))（三层复合）：

dy/dx = (dy/df) × (df/dg) × (dg/dh) × (dh/dx)

就是"一路乘下去"。神经网络有很多层，反向传播就是把每层的"局部导数"一路乘回去。

✏️ 例题 5.2：三层复合

已知：x → [×3] → a → [平方] → b → [+1] → y

即：a = 3x, b = a², y = b + 1

求 dy/dx（在 x=2 处）：

dy/db = 1（y = b+1 的导数）
db/da = 2a（b = a² 的导数）
da/dx = 3（a = 3x 的导数）
dy/dx = 1 × 2a × 3 = 6a
在 x=2 处：a = 3×2 = 6，所以 dy/dx = 6×6 = 36

📌 反向传播 = 在计算图上反向走

前向传播：从输入到输出，计算每一步的结果（得到预测值和损失）

反向传播：从输出到输入，用链式法则计算每一步的梯度

每个节点只需要知道两件事：

  1. 从后面传来的梯度（"我对损失的影响有多大"）
  2. 本节点的局部导数（"我的输入变化时，输出怎么变"）

两者相乘 → 传给前面的节点

反向传播不是新算法，它只是第3章梯度下降的"计算梯度的方法"。

第3章你学了"参数 = 参数 - 学习率 × 梯度"，但没讲梯度怎么算。

反向传播就是回答"梯度怎么算"——用第4章网络的结构，从后往前逐层用链式法则。

5.4 反向传播——从输出往回算

常用激活函数的导数

激活函数公式导数
ReLUmax(0, x)x>0 时为 1，x≤0 时为 0
Sigmoidσ(x) = 1/(1+e⁻ˣ)σ(x) × (1 - σ(x))
Tanhtanh(x)1 - tanh²(x)
✏️ 例题 5.3：Sigmoid 的导数

σ(x) 的导数 = σ(x) × (1 - σ(x))

在 x=0 处：σ(0) = 0.5，导数 = 0.5 × 0.5 = 0.25

在 x=5 处：σ(5) ≈ 0.993，导数 = 0.993 × 0.007 ≈ 0.007（很小！）

💡 这就是"梯度消失"的根源：Sigmoid 两端的导数接近 0。

5.5 完整手算：一个两层网络的反向传播

✏️ 例题 5.4：完整反向传播（最重要的例题！）

网络：输入 x=2 → 第1层(w₁=0.5, b₁=0, ReLU) → 第2层(w₂=1, b₂=0) → 输出 ŷ

真实值：y = 5

损失：L = (ŷ - y)²

第一步：前向传播（从左到右）

z₁ = w₁ × x + b₁ = 0.5 × 2 + 0 = 1
h = ReLU(z₁) = max(0, 1) = 1
z₂ = w₂ × h + b₂ = 1 × 1 + 0 = 1
ŷ = z₂ = 1（输出层无激活）
L = (1 - 5)² = 16

第二步：反向传播（从右到左）

① 损失对输出的梯度：

∂L/∂ŷ = 2(ŷ - y) = 2(1 - 5) = -8

② 输出层参数 w₂ 的梯度：

ŷ = w₂ × h，所以 ∂ŷ/∂w₂ = h = 1
∂L/∂w₂ = ∂L/∂ŷ × ∂ŷ/∂w₂ = (-8) × 1 = -8

③ 梯度继续往回传（到隐藏层）：

∂ŷ/∂h = w₂ = 1
∂L/∂h = ∂L/∂ŷ × ∂ŷ/∂h = (-8) × 1 = -8

④ 通过 ReLU：

∂h/∂z₁ = ReLU'(z₁) = 1（因为 z₁=1 > 0）
∂L/∂z₁ = ∂L/∂h × ∂h/∂z₁ = (-8) × 1 = -8

⑤ 第1层参数 w₁ 的梯度：

z₁ = w₁ × x，所以 ∂z₁/∂w₁ = x = 2
∂L/∂w₁ = ∂L/∂z₁ × ∂z₁/∂w₁ = (-8) × 2 = -16

第三步：更新参数（η = 0.01）

w₂_new = 1 - 0.01×(-8) = 1 + 0.08 = 1.08
w₁_new = 0.5 - 0.01×(-16) = 0.5 + 0.16 = 0.66

💡 两个参数都增大了（因为梯度为负，说明增大参数能减小损失）。

验证：新的预测 = 0.66 × 2 × 1.08 = 1.425（比之前的 1 更接近目标 5 了！）

✏️ 例题 5.5：ReLU "杀死"梯度的情况

同样的网络，但输入 x = -2：

z₁ = 0.5 × (-2) + 0 = -1
h = ReLU(-1) = max(0, -1) = 0 ← 被截断了！
ŷ = 1 × 0 = 0
L = (0 - 5)² = 25

反向传播：

∂L/∂ŷ = 2(0-5) = -10
∂L/∂h = -10 × w₂ = -10 × 1 = -10
∂L/∂z₁ = -10 × ReLU'(-1) = -10 × 0 = 0 ← 梯度为 0！
∂L/∂w₁ = 0 × x = 0 ← w₁ 不会更新！

💡 这就是"死神经元"问题：当 z₁ < 0 时，ReLU 的导数为 0，梯度被完全截断，w₁ 永远无法学习。

解决方案：用 Leaky ReLU（负区间给一个小斜率 0.01）或 ELU。

5.6 矩阵形式的反向传播

实际网络中，每层有多个神经元，用矩阵表示：

📌 矩阵形式的反向传播公式

前向：

z₁ = W₁x + b₁ → h = f(z₁) → z₂ = W₂h + b₂ → ŷ = g(z₂)

反向：

δ₂ = ∂L/∂z₂ = ∂L/∂ŷ ⊙ g'(z₂)
∂L/∂W₂ = δ₂ × hᵀ
∂L/∂b₂ = δ₂

δ₁ = (W₂ᵀ × δ₂) ⊙ f'(z₁)
∂L/∂W₁ = δ₁ × xᵀ
∂L/∂b₁ = δ₁

其中 ⊙ 是逐元素乘法（Hadamard 积）

看起来复杂，但核心模式就是：梯度 = 后面传来的梯度 × 本层的局部导数，一层层往回传。

5.7 PyTorch 的 autograd——自动反向传播

PyTorch 帮你自动完成所有反向传播的计算。你只需要：

  1. 定义前向传播（forward 函数）
  2. 调用 loss.backward()
import torch

# 创建需要梯度的变量
x = torch.tensor(2.0, requires_grad=True)
w1 = torch.tensor(0.5, requires_grad=True)
w2 = torch.tensor(1.0, requires_grad=True)

# 前向传播（PyTorch 自动记录计算图）
z1 = w1 * x          # z1 = 1.0
h = torch.relu(z1)   # h = 1.0
y_pred = w2 * h      # y_pred = 1.0
y_true = torch.tensor(5.0)
loss = (y_pred - y_true) ** 2  # loss = 16.0

# 反向传播（自动计算所有梯度！）
loss.backward()

# 查看梯度
print(f"∂L/∂w1 = {w1.grad}")  # -16.0（和我们手算的一样！）
print(f"∂L/∂w2 = {w2.grad}")  # -8.0（也一样！）
📌 PyTorch autograd 的原理

每次你做运算（+, ×, relu...），PyTorch 在后台记录一个计算图。

调用 .backward() 时，它沿着这个图反向走，用链式法则自动算出所有梯度。

你不需要手动推导任何导数公式！

5.8 梯度消失与梯度爆炸

问题

反向传播是"一路乘回去"。如果每层的导数都小于 1（如 Sigmoid 最大导数 0.25），乘很多层后：

0.25 × 0.25 × 0.25 × ... × 0.25（10层）= 0.25¹⁰ ≈ 0.000001

梯度变得极小 → 前面的层几乎不更新 → 梯度消失

反过来，如果每层导数大于 1，乘很多层后梯度爆炸 → 梯度爆炸

解决方案

问题解决方案
梯度消失用 ReLU（导数为 0 或 1，不会缩小）
梯度消失残差连接（ResNet）：梯度可以"跳过"层
梯度消失BatchNorm / LayerNorm：稳定每层的分布
梯度爆炸梯度裁剪：clip_grad_norm_(params, 1.0)
梯度爆炸合理的权重初始化（Xavier / Kaiming）
# 梯度裁剪示例
import torch.nn as nn

# 训练循环中
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)  # 裁剪
optimizer.step()
⚠️ 常见误区（初学者最容易踩的坑）
✗ "反向传播是一种新的优化算法"
✓ 反向传播只是高效计算梯度的方法。真正的优化算法是梯度下降（第3章）。反向传播解决的是"怎么快速算出每个参数的梯度"，用的是链式法则。
✗ "梯度消失是因为学习率太小"
✓ 梯度消失是因为激活函数和层数。Sigmoid 的导数最大只有 0.25，连乘 10 层就变成 0.25¹⁰ ≈ 0.000001。解决方案：用 ReLU、残差连接、BatchNorm。
✗ "反向传播是从后往前训练参数"
✓ 反向传播是从后往前算梯度，但更新参数仍然是梯度下降。所有参数同时更新，不存在"先训练后面的层，再训练前面的层"。

5.9 本章习题

📝 概念理解题
  1. 反向传播的核心数学工具是什么？
  2. 为什么反向传播比"逐个参数微调"高效？
  3. Sigmoid 在 x=0 处的导数是多少？在 x=10 处呢？这会导致什么问题？
  4. ReLU 在 x=-3 处的导数是多少？这意味着什么？
  5. 什么是梯度消失？用什么方法缓解？
参考答案
  1. 链式法则（复合函数求导）
  2. 一次前向+一次反向就能算出所有参数的梯度（O(n)），而逐个微调需要 O(n) 次前向（n=参数量）
  3. x=0: σ'(0) = 0.5×0.5 = 0.25；x=10: σ(10)≈1, σ'(10)≈0.00005（极小）→ 梯度消失
  4. ReLU'(-3) = 0。意味着这个神经元"死了"——梯度为0，参数不会更新。
  5. 深层网络中梯度逐层相乘变得越来越小，前面的层学不动。解决：ReLU、残差连接、BatchNorm。
📝 手算题
  1. 计算 y = sin(x²) 在 x=1 处的导数（用链式法则）。
  2. 网络：x=3, w₁=2, b₁=1, ReLU, w₂=0.5, b₂=0, 真实值 y=10。
    (a) 前向传播求预测值和损失
    (b) 反向传播求 ∂L/∂w₁ 和 ∂L/∂w₂
  3. 如果上题中 z₁ = w₁×x + b₁ 算出来是负数（比如 -2），ReLU 后的梯度会怎样？
参考答案
  1. 令 u=x², y=sin(u)。dy/dx = cos(u)×2x = cos(x²)×2x。在x=1: cos(1)×2 ≈ 0.54×2 = 1.08
  2. (a) z₁=2×3+1=7, h=ReLU(7)=7, ŷ=0.5×7=3.5, L=(3.5-10)²=42.25
    (b) ∂L/∂ŷ=2(3.5-10)=-13
    ∂L/∂w₂ = -13 × h = -13×7 = -91
    ∂L/∂h = -13 × w₂ = -13×0.5 = -6.5
    ∂L/∂z₁ = -6.5 × ReLU'(7) = -6.5×1 = -6.5
    ∂L/∂w₁ = -6.5 × x = -6.5×3 = -19.5
  3. 如果 z₁=-2，ReLU(-2)=0，且 ReLU'(-2)=0。所以 ∂L/∂z₁ = 后面梯度 × 0 = 0。梯度被"截断"，w₁ 不会更新（"死神经元"问题）。

import torch

x = torch.tensor(2.0)
w1 = torch.tensor(0.5, requires_grad=True)

z1 = w1 * x

本章小结

概念一句话总结
链式法则复合函数的导数 = 各层导数相乘
计算图记录前向计算的依赖关系
反向传播沿计算图反向走，逐层用链式法则算梯度

🎯 本章最重要的认知

反向传播不是什么新算法——它就是链式法则的系统化应用。

理解了"梯度从后往前传，每层乘上局部导数"，你就理解了深度学习的训练核心。

PyTorch 的 .backward() 帮你做了所有脏活，但理解原理能帮你调试（比如梯度消失时知道为什么）。
