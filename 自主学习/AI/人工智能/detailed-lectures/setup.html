Environment Setup

环境准备指南

10 分钟搭好 AI 学习环境 · macOS / Windows / Linux

← 返回教程目录

你需要什么？

本教程的所有代码只需要以下工具：

1

Python 3.10+

编程语言。第1-5章的代码用 Python + NumPy 就能跑。

2

NumPy

数值计算库。向量、矩阵运算全靠它。

3

PyTorch（第4章开始需要）

深度学习框架。搭建和训练神经网络。

4

Jupyter Notebook（推荐）

交互式编程环境。边写代码边看结果，非常适合学习。

安装步骤

🍎 macOS
🪟 Windows
🐧 Linux
1

安装 Homebrew（如果没有）

# 打开"终端"应用，粘贴以下命令
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
2

安装 Python

brew install python@3.12

# 验证安装
python3 --version  # 应显示 Python 3.12.x
3

创建虚拟环境 + 安装库

# 创建项目文件夹
mkdir ~/ai-tutorial && cd ~/ai-tutorial

# 创建虚拟环境（隔离依赖，不污染系统）
python3 -m venv venv
source venv/bin/activate  # 激活后命令行前面会出现 (venv)

# 安装所有需要的库（一条命令搞定）
pip install numpy matplotlib torch torchvision jupyter
💡 Apple Silicon (M1/M2/M3/M4) 用户：PyTorch 自动支持 MPS 加速，无需额外配置。
1

安装 Python

# 方法1：从官网下载安装包
# 访问 https://python.org → Downloads → 下载 Python 3.12
# ⚠️ 安装时勾选 "Add Python to PATH"！

# 方法2：用 winget（Windows 11 自带）
winget install Python.Python.3.12
2

创建虚拟环境 + 安装库

# 打开 PowerShell 或 CMD
mkdir ai-tutorial
cd ai-tutorial

python -m venv venv
venv\Scripts\activate  # 激活虚拟环境

pip install numpy matplotlib torch torchvision jupyter
⚠️ 如果有 NVIDIA 显卡，安装 GPU 版 PyTorch 会更快：
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
1

安装 Python + 依赖

# Ubuntu / Debian
sudo apt update && sudo apt install python3 python3-venv python3-pip

# 创建虚拟环境
mkdir ~/ai-tutorial && cd ~/ai-tutorial
python3 -m venv venv
source venv/bin/activate

pip install numpy matplotlib torch torchvision jupyter

验证安装

在 Python 中运行以下代码，全部通过就说明环境没问题：

# 启动 Python
python3  # 或 python

# 测试 NumPy
>>> import numpy as np
>>> a = np.array([1, 2, 3])
>>> print(a * 2)  # [2 4 6] ✓

# 测试 PyTorch
>>> import torch
>>> print(torch.__version__)  # 2.x.x ✓
>>> x = torch.randn(3, 3)
>>> print(x @ x.T)  # 矩阵乘法 ✓

# 测试 GPU（可选）
>>> print(torch.backends.mps.is_available())  # Mac: True
>>> print(torch.cuda.is_available())  # NVIDIA: True

启动 Jupyter Notebook

# 确保虚拟环境已激活
jupyter notebook

# 浏览器会自动打开 http://localhost:8888
# 点 "New" → "Python 3" 创建新笔记本
# 在单元格中写代码，按 Shift+Enter 运行
💡 推荐用 VS Code 打开 .ipynb 文件，体验更好（自带代码补全和变量查看）。

常见问题

Q: pip install 很慢怎么办？

使用国内镜像源：

pip install numpy -i https://pypi.tuna.tsinghua.edu.cn/simple

Q: 没有 GPU 能学吗？

完全可以！第1-7章的代码在 CPU 上几秒就能跑完。第8章调用 API 不需要本地 GPU。只有训练大模型才需要 GPU。

Q: 虚拟环境怎么退出和重新进入？

deactivate  # 退出虚拟环境
source venv/bin/activate  # Mac/Linux 重新进入
venv\Scripts\activate  # Windows 重新进入
