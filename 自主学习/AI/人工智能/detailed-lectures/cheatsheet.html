第1章 · 向量

点积（内积）

a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ
衡量两个向量的相似程度。正=相似，0=无关，负=相反

向量长度（L2 范数）

||a|| = √(a₁² + a₂² + ... + aₙ²)
勾股定理的推广。二维时就是斜边长度

余弦相似度

cos(θ) = (a · b) / (||a|| × ||b||)
只看方向不看大小。范围 [-1, 1]。AI 搜索/推荐的核心

单位向量（归一化）

â = a / ||a||
长度为 1，只保留方向
第2章 · 矩阵

矩阵 × 向量

(m×n) × (n维) = (m维)
矩阵每行和向量做点积。神经网络一层的核心运算

矩阵 × 矩阵

(m×n) × (n×p) = (m×p)
左列 = 右行才能乘。结果[i,j] = 左第i行 · 右第j列

神经网络线性层

y = W × x + b
W=权重矩阵，b=偏置。训练就是学 W 和 b

参数量计算

Linear(in, out) → in×out + out
权重 + 偏置。如 Linear(784,256) = 200,960 参数
第3章 · 梯度下降

均方误差 (MSE)

L = (1/N) Σ(ŷᵢ - yᵢ)²
预测值和真实值差距的平方平均。越小越好

梯度下降更新

w_new = w_old - η × (∂L/∂w)
η=学习率。沿负梯度方向走一步。所有 AI 训练的核心

线性回归梯度

∂L/∂w = (2/N) Σ(ŷ-y)×x
∂L/∂b = (2/N) Σ(ŷ-y)
MSE 对 w 和 b 的偏导数

学习率选择

常用: 0.01, 0.001, 0.0001
太大→震荡发散；太小→收敛极慢。Adam 默认 0.001
第4章 · 神经网络

神经元计算

y = f(W·x + b)
加权求和 → 激活函数。f 通常是 ReLU

ReLU 激活

ReLU(x) = max(0, x)
负数→0，正数→本身。隐藏层默认选择

Sigmoid

σ(x) = 1 / (1 + e⁻ˣ)
输出 (0,1)，可解释为概率。二分类输出层用

Softmax

softmax(xᵢ) = eˣⁱ / Σⱼ eˣʲ
输出概率分布（和为1）。多分类输出层用

交叉熵损失

L = -Σ yᵢ log(ŷᵢ)
分类任务的标准损失函数
第5章 · 反向传播

链式法则

dy/dx = (dy/du) × (du/dx)
复合函数求导。反向传播的数学基础

反向传播核心

本层梯度 = 后层梯度 × 局部导数
从输出往回逐层乘。一次前向+一次反向算出所有梯度

Sigmoid 导数

σ'(x) = σ(x) × (1 - σ(x))
最大值 0.25（在 x=0 处）。两端趋近 0 → 梯度消失

ReLU 导数

ReLU'(x) = 1 (x>0), 0 (x≤0)
正区间梯度恒为1，缓解梯度消失
第6章 · CNN

卷积操作

输出[i,j] = Σ Σ 输入[i+m,j+n] × 核[m,n]
小窗口滑动做点积。检测局部特征（边缘、纹理）

输出尺寸公式

out = (in + 2×pad - kernel) / stride + 1
pad=1, kernel=3, stride=1 → 输出尺寸不变

卷积层参数量

C_in × K × K × C_out + C_out
如 Conv2d(3,64,3): 3×3×3×64+64 = 1,792

残差连接 (ResNet)

output = F(x) + x
梯度可以"跳过"层传播。解决深层网络训练
第7章 · Transformer

自注意力（核心公式）

Attn(Q,K,V) = softmax(QKᵀ/√d_k) × V
计算相关度 → 归一化 → 加权求和。现代 AI 的基石

Q、K、V 生成

Q = xW_Q, K = xW_K, V = xW_V
三个可学习的投影矩阵

多头注意力

每头维度 = d_model / n_heads
如 512/8=64。多头并行关注不同关系，最后拼接

缩放因子

除以 √d_k
防止点积过大导致 softmax 饱和、梯度消失
第8章 · 大语言模型

LLM 核心任务

P(x_{t+1} | x₁, x₂, ..., x_t)
给定前文，预测下一个 token 的概率分布

训练三阶段

预训练 → SFT → 对齐(DPO/RLHF)
知识 → 遵循指令 → 安全有用

LoRA 微调

W' = W + BA (B∈ℝᵈˣʳ, A∈ℝʳˣᵈ)
r≪d（如16）。只训练 0.1% 参数

Temperature 采样

P(xᵢ) = e^(zᵢ/T) / Σⱼ e^(zⱼ/T)
T→0: 贪心；T=1: 原始分布；T>1: 更随机
第9章 · RAG 与 Agent

RAG 流程

问题 → Embed → 检索TopK → [文档+问题] → LLM
先检索再生成。减少幻觉，利用私有数据

Embedding 相似度

sim = cos(embed(query), embed(doc))
余弦相似度找语义最相关的文档

Agent 循环 (ReAct)

思考 → 行动(工具) → 观察 → 思考 → ...
LLM + 工具调用 + 规划。能"做事"不只是"说话"
