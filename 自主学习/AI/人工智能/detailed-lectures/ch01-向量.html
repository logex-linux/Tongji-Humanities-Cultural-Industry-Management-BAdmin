1.1 向量是什么？——从生活直觉开始

直觉：向量就是一个"有方向的量"

想象你站在原点，朋友告诉你："向东走 3 步，再向北走 4 步。" 这个指令就定义了一个向量——它同时包含了"多远"和"往哪走"两个信息。

上面的蓝色箭头就是向量 (3, 4)。它告诉我们：从原点出发，x 方向走 3，y 方向走 4。

📌 核心概念：向量

向量就是一组有序的数字。在二维空间中，一个向量有 2 个数字 (x, y)；在三维空间中有 3 个数字 (x, y, z)。

在 AI 中，向量的维度可以是几百、几千甚至几万——但本质不变：向量就是一组有顺序的数字。

为什么 AI 需要向量？

计算机不能直接理解"猫"、"开心"、"一张图片"这些概念。我们需要把它们变成数字。向量就是最自然的"数字容器"：

现实事物向量表示维度
一个像素点的位置(x, y)2
RGB 颜色(红, 绿, 蓝) = (255, 128, 0)3
用户画像(年龄, 收入, 消费频率) = (25, 8000, 3.2)3
一张 28×28 灰度图784 个像素值排成一列784
一个单词的含义Word2Vec 向量300

记住这个关键认知：在 AI 中，万物皆可向量。图片、文字、声音、用户行为……全部被编码成向量，然后交给模型处理。

1.2 向量的表示——数字列表

数学写法

向量通常用粗体小写字母或带箭头的字母表示：

a = (3, 4)   或   ā = [3, 4]   或   竖着写：a = |3|
                                            |4|

向量中的每个数字叫做分量（component）。(3, 4) 有两个分量：第一个分量是 3，第二个分量是 4。

Python 中的向量

在 Python 中，我们用最基础的列表就能表示向量：

# 方法1：Python 列表（最基础）
a = [3, 4]
b = [1, 2, 5]  # 三维向量

# 方法2：NumPy 数组（推荐，后面会大量使用）
import numpy as np
a = np.array([3, 4])
b = np.array([1, 2, 5])

print(a)       # [3 4]
print(a[0])    # 3（第一个分量）
print(a[1])    # 4（第二个分量）
print(len(a))  # 2（向量的维度）
📌 核心概念：维度 (Dimension)

向量有几个分量，就是几维。二维向量有 2 个数字，784 维向量有 784 个数字。

维度 = 描述一个事物需要几个数字。

✏️ 例题 1.1

问题：用向量表示以下信息：

  1. 一个学生的三科成绩：数学 90，英语 85，物理 92
  2. 一个像素的颜色：红色通道 200，绿色通道 100，蓝色通道 50

解：

第1步：确定需要几个数字 → 三科成绩需要 3 个数字
第2步：按固定顺序排列 → (数学, 英语, 物理) = (90, 85, 92)

所以：成绩向量 = (90, 85, 92)，颜色向量 = (200, 100, 50)

⚠️ 注意：顺序必须固定！(90, 85, 92) 和 (85, 90, 92) 是不同的向量。

1.3 向量的加法——合并信息

直觉

向量加法就是"先走第一段路，再走第二段路"。如果你先向东走 3 步、向北走 1 步，再向东走 1 步、向北走 2 步，最终效果等于向东走 4 步、向北走 3 步。

👇 动画：先画向量 a，再从 a 的终点画向量 b，最后得到 a+b

计算规则：对应分量相加

(a₁, a₂) + (b₁, b₂) = (a₁+b₁, a₂+b₂)
✏️ 例题 1.2

计算： a = (3, 1)，b = (1, 2)，求 a + b

第1步：第一个分量相加：3 + 1 = 4
第2步：第二个分量相加：1 + 2 = 3
结果：a + b = (4, 3)

Python 实现

import numpy as np

a = np.array([3, 1])
b = np.array([1, 2])

# 方法1：直接加（NumPy 自动逐元素运算）
c = a + b
print(c)  # [4 3]

# 方法2：纯 Python 实现（理解原理）
a_list = [3, 1]
b_list = [1, 2]
c_list = [a_list[i] + b_list[i] for i in range(len(a_list))]
print(c_list)  # [4, 3]
📌 关键规则

向量加法要求两个向量维度相同。(3, 4) + (1, 2) ✓ 可以加；(3, 4) + (1, 2, 5) ✗ 不能加。

1.4 向量的数乘——缩放

直觉

数乘就是"把向量拉长或缩短"。2 × (3, 4) 表示沿着 (3, 4) 的方向走两倍远。

计算规则：每个分量都乘以这个数

k × (a₁, a₂, a₃) = (k×a₁, k×a₂, k×a₃)
✏️ 例题 1.3

计算： 3 × (2, -1, 4)

第1步：3 × 2 = 6
第2步：3 × (-1) = -3
第3步：3 × 4 = 12
结果：3 × (2, -1, 4) = (6, -3, 12)
a = np.array([2, -1, 4])
print(3 * a)    # [ 6 -3 12]
print(0.5 * a)  # [ 1.  -0.5  2. ]
print(-1 * a)   # [-2  1 -4]  ← 反向！

特别注意：乘以 -1 会让向量反向（方向翻转 180°），长度不变。

1.5 向量的长度（范数）——衡量大小

直觉：勾股定理

向量 (3, 4) 的"长度"是多少？想象一个直角三角形：底边 3，高 4，斜边就是向量的长度。

计算公式：L2 范数（欧几里得范数）

||a|| = √(a₁² + a₂² + ... + aₙ²)

就是"每个分量的平方加起来，再开根号"。二维时就是勾股定理。

✏️ 例题 1.4

计算向量 a = (3, 4) 的长度：

第1步：每个分量平方：3² = 9，4² = 16
第2步：求和：9 + 16 = 25
第3步：开根号：√25 = 5
结果：||a|| = 5

计算向量 b = (1, 2, 2) 的长度：

第1步：1² + 2² + 2² = 1 + 4 + 4 = 9
第2步：√9 = 3
结果：||b|| = 3
a = np.array([3, 4])
length = np.linalg.norm(a)
print(length)  # 5.0

b = np.array([1, 2, 2])
print(np.linalg.norm(b))  # 3.0

# 手动实现（理解原理）
def vector_length(v):
    return sum(x**2 for x in v) ** 0.5

print(vector_length([3, 4]))  # 5.0
📌 单位向量（归一化）

把向量除以它的长度，得到单位向量（长度为 1，只保留方向）：

â = a / ||a||

例如：(3, 4) / 5 = (0.6, 0.8)，长度变为 1，方向不变。

这在 AI 中非常重要——很多时候我们只关心"方向"（含义），不关心"大小"。

1.6 点积——衡量相似度

这是本章最重要的概念！

点积（也叫内积）是 AI 中最常用的向量运算。它回答一个核心问题：两个向量有多"相似"？

计算规则：对应分量相乘，再求和

a · b = a₁×b₁ + a₂×b₂ + ... + aₙ×bₙ
✏️ 例题 1.5

计算 a = (1, 2, 3) 和 b = (4, 5, 6) 的点积：

第1步：对应分量相乘：1×4 = 4，2×5 = 10，3×6 = 18
第2步：求和：4 + 10 + 18 = 32
结果：a · b = 32
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# NumPy 点积
print(np.dot(a, b))  # 32

# 手动实现
def dot_product(a, b):
    return sum(x * y for x, y in zip(a, b))

print(dot_product([1,2,3], [4,5,6]))  # 32

点积的几何意义

a · b = ||a|| × ||b|| × cos(θ)

其中 θ 是两个向量之间的夹角。这意味着：

点积结果夹角含义
正数 (> 0)θ < 90°方向大致相同 → 相似
零 (= 0)θ = 90°完全垂直 → 无关
负数 (< 0)θ > 90°方向大致相反 → 不相似
✏️ 例题 1.6：判断相似度

问题：判断以下向量对的相似程度

a = (1, 0)，b = (0, 1)，c = (2, 0)，d = (-1, 0)

a · b = 1×0 + 0×1 = 0 → 垂直，完全无关
a · c = 1×2 + 0×0 = 2 > 0 → 方向相同，很相似
a · d = 1×(-1) + 0×0 = -1 < 0 → 方向相反，不相似

1.7 余弦相似度——只看方向

为什么需要余弦相似度？

点积受向量长度影响。向量 (1, 1) 和 (100, 100) 方向完全相同，但点积 = 200 很大。如果我们只想比较"方向"（含义），需要消除长度的影响。

公式

cos(θ) = (a · b) / (||a|| × ||b||)

结果范围：[-1, 1]

  • 1：方向完全相同（最相似）
  • 0：完全垂直（无关）
  • -1：方向完全相反（最不相似）
✏️ 例题 1.7

计算 a = (1, 2) 和 b = (2, 1) 的余弦相似度：

第1步：计算点积：a·b = 1×2 + 2×1 = 4
第2步：计算 ||a|| = √(1²+2²) = √5 ≈ 2.236
第3步：计算 ||b|| = √(2²+1²) = √5 ≈ 2.236
第4步：cos(θ) = 4 / (2.236 × 2.236) = 4/5 = 0.8
结论：余弦相似度 = 0.8，比较相似（接近1）
from numpy.linalg import norm

def cosine_similarity(a, b):
    return np.dot(a, b) / (norm(a) * norm(b))

a = np.array([1, 2])
b = np.array([2, 1])
print(cosine_similarity(a, b))  # 0.8

# 验证：方向相同的向量，余弦相似度 = 1
c = np.array([1, 1])
d = np.array([100, 100])
print(cosine_similarity(c, d))  # 1.0（方向完全相同）
📌 AI 中的核心应用

搜索引擎：把用户查询和所有文档都变成向量，用余弦相似度排序。

推荐系统：用户向量 · 商品向量 → 预测用户喜好程度。

RAG（检索增强生成）：把问题和知识库文档都编码为向量，找最相似的文档给 LLM 参考。

1.8 向量在 AI 中的应用

应用1：图像 = 向量

一张 28×28 像素的灰度图（如手写数字），每个像素有一个 0-255 的亮度值。把 784 个像素值排成一列，就是一个 784 维向量：

# 模拟一张 28x28 的手写数字图片
import numpy as np

# 每个像素是 0(黑) 到 255(白) 的数字
image = np.random.randint(0, 256, size=(28, 28))

# 展平成向量
image_vector = image.flatten()  # 变成 784 维向量
print(image_vector.shape)       # (784,)
print(image_vector[:10])        # 前10个像素值

应用2：文字 = 向量（词嵌入）

在 NLP 中，每个词被映射为一个向量（词嵌入）。含义相近的词，向量也相近：

# 概念演示（实际用训练好的模型）
# "国王" 的向量 ≈ [0.8, 0.2, 0.9, ...]
# "女王" 的向量 ≈ [0.7, 0.8, 0.9, ...]  ← 和国王很接近
# "香蕉" 的向量 ≈ [0.1, 0.3, 0.0, ...]  ← 和国王很远

# 经典的向量算术：
# king - man + woman ≈ queen
# 这说明向量空间编码了"性别"这个方向

应用3：神经网络中的向量运算

神经网络的一层本质上就是：

输出向量 = 权重矩阵 × 输入向量 + 偏置向量

整个深度学习就是在做大量的向量（和矩阵）运算。这就是为什么 GPU（擅长并行向量运算）对 AI 如此重要。

⚠️ 常见误区
✗ "向量就是有方向的箭头"
✓ 在 AI 中，向量就是一组有序数字。几何箭头只是帮助理解的直觉。一个 784 维的图像向量、一个 300 维的词向量，都没有"方向"可言——但它们都是向量。
✗ "点积大 = 很相似"
✓ 点积受向量长度影响。向量 (100,100) 和 (1,1) 方向完全相同，但点积 = 200 很大。要只比较"方向"，用余弦相似度（除以长度）。
✗ "维度越高越好"
✓ 高维需要更多数据和计算。维度选择要匹配问题复杂度。用 3 维就能描述的颜色，没必要用 1000 维。

1.9 本章习题

📝 基础题（确保理解概念）
  1. 写出向量 a = (5, -2, 3) 的维度，并指出它的第二个分量。
  2. 计算 (2, 3) + (4, -1)。
  3. 计算 3 × (1, -2, 4)。
  4. 计算向量 (5, 12) 的长度。
  5. 计算 (1, 2, 3) · (4, -1, 2)。
参考答案
  1. 维度 = 3，第二个分量 = -2
  2. (2+4, 3+(-1)) = (6, 2)
  3. (3×1, 3×(-2), 3×4) = (3, -6, 12)
  4. √(5²+12²) = √(25+144) = √169 = 13
  5. 1×4 + 2×(-1) + 3×2 = 4 - 2 + 6 = 8
📝 进阶题（加深理解）
  1. 计算 (3, 4) 的单位向量（归一化）。
  2. 计算 (1, 0) 和 (1, 1) 的余弦相似度。它们之间的夹角是多少度？
  3. 判断：向量 (2, 3) 和 (-3, 2) 是否垂直？（提示：垂直 ⟺ 点积=0）
  4. 用 Python 写一个函数 distance(a, b)，计算两个向量之间的欧几里得距离。提示：距离 = ||a - b||。
参考答案
  1. ||(3,4)|| = 5，单位向量 = (3/5, 4/5) = (0.6, 0.8)
  2. cos(θ) = (1×1+0×1)/(1×√2) = 1/√2 ≈ 0.707，θ = 45°
  3. (2,3)·(-3,2) = 2×(-3)+3×2 = -6+6 = 0 → 是，垂直！
  4. def distance(a, b):
    diff = [a[i] - b[i] for i in range(len(a))]
    return sum(x**2 for x in diff) ** 0.5

print(distance([1,2], [4,6]))  # 5.0

本章小结

概念一句话总结AI 中的用途
向量一组有序数字表示数据（图片、文字、用户）
加法对应分量相加合并特征
数乘每个分量乘以常数缩放、反向
长度（范数）√(各分量平方和)衡量大小、归一化
点积对应相乘再求和衡量相似度（核心！）
余弦相似度点积/(长度×长度)只比较方向（搜索、推荐）

💡 关键直觉

向量加法有两种等价的理解方式：

  • "走路"理解：先走 a，再从 a 的终点走 b，最终位置就是 a+b
  • "平行四边形"理解：以 a 和 b 为邻边画平行四边形，对角线就是 a+b

在 AI 中，向量加法 = 合并信息。比如把"用户画像向量"和"商品特征向量"相加，得到"匹配度向量"。
