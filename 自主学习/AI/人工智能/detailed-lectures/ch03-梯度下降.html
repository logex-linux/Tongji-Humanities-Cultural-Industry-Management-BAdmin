3.1 AI 的"学习"到底是什么？

一个直觉类比

想象你蒙着眼睛站在山上，目标是走到最低点（山谷）。你看不见全局地形，只能感受脚下哪个方向是"下坡"。于是你：

  1. 感受脚下的坡度（计算梯度）
  2. 沿着最陡的下坡方向迈一步（更新参数）
  3. 重复，直到走到谷底（损失最小）

👇 动画：观察小球如何一步步"滚"到山谷最低点

📌 AI 学习的本质

学习 = 调整参数，让预测结果越来越接近正确答案。

具体步骤：

  1. 随机初始化参数（w, b）
  2. 用当前参数做预测
  3. 计算预测和真实值的差距（损失）
  4. 计算损失对每个参数的梯度（"下坡方向"）
  5. 沿梯度反方向更新参数（走一步）
  6. 重复 2-5，直到损失足够小

3.2 损失函数——衡量"错得多离谱"

什么是损失函数？

损失函数（Loss Function）就是一个公式，输入是"预测值"和"真实值"，输出是一个数字表示"错了多少"。损失越小，模型越好。

最常用的：均方误差 (MSE)

Loss = (1/N) × Σ(预测值 - 真实值)²

就是"每个样本的误差平方，取平均"。

✏️ 例题 3.1：计算损失

问题：模型预测了 3 个值，真实值如下：

样本预测值 ŷ真实值 y误差 (ŷ-y)误差²
135-24
27611
34400
MSE = (4 + 1 + 0) / 3 = 5/3 ≈ 1.67

如果模型完美预测（误差全为0），MSE = 0。

为什么用平方？

  • 消除正负：误差 +2 和 -2 都变成 4（都是"错了2"）
  • 惩罚大误差：误差 3 → 平方后 9，比误差 1 → 1 惩罚重得多
  • 数学上好处理：平方函数处处可导，方便求梯度
import numpy as np

def mse_loss(y_pred, y_true):
    """均方误差损失函数"""
    errors = y_pred - y_true
    return np.mean(errors ** 2)

# 测试
y_pred = np.array([3, 7, 4])
y_true = np.array([5, 6, 4])
print(mse_loss(y_pred, y_true))  # 1.667

3.3 导数与梯度——找到下降方向

导数：函数的"坡度"

你已经知道导数表示"变化率"。在这里，我们关心的是：当参数 w 变化一点点时，损失 L 变化多少？

dL/dw = "w 变化 1 个单位时，L 变化多少"
📌 梯度的含义

梯度 dL/dw 告诉你：

  • 如果 dL/dw > 0：w 增大会让 L 增大 → 所以应该减小 w
  • 如果 dL/dw < 0：w 增大会让 L 减小 → 所以应该增大 w
  • 如果 dL/dw = 0：已经到最低点了！

总结：参数更新方向 = 梯度的反方向（负梯度方向 = 下坡方向）

多个参数时的梯度

如果模型有两个参数 w 和 b，就需要分别求偏导：

∂L/∂w = "只动 w 时，L 的变化率"
∂L/∂b = "只动 b 时，L 的变化率"

这两个偏导数组成的向量 (∂L/∂w, ∂L/∂b) 就叫梯度向量。

🌉 直觉桥梁：连接第1章

梯度其实就是一个第1章学的向量！

如果模型有 3 个参数 (w₁, w₂, w₃)，梯度就是 (∂L/∂w₁, ∂L/∂w₂, ∂L/∂w₃) —— 一个 3 维向量。

参数更新 w = w - η×梯度，就是第1章的向量减法 + 数乘。

梯度下降的每一步，都是你第1章已经会的向量运算。

3.4 梯度下降算法——一步步走向最优

核心公式（必须记住）

w_new = w_old - η × (∂L/∂w)

b_new = b_old - η × (∂L/∂b)

其中 η（eta）是学习率（learning rate），控制每步走多远。

📌 梯度下降算法（伪代码）
1. 随机初始化 w, b
2. 重复以下步骤（比如 1000 次）：
   a. 用当前 w, b 计算预测值：ŷ = w×x + b
   b. 计算损失：L = mean((ŷ - y)²)
   c. 计算梯度：
      ∂L/∂w = mean(2 × (ŷ - y) × x)
      ∂L/∂b = mean(2 × (ŷ - y))
   d. 更新参数：
      w = w - η × ∂L/∂w
      b = b - η × ∂L/∂b
3. 训练完成！w 和 b 就是学到的参数

3.5 手算例题：用梯度下降拟合直线

✏️ 例题 3.2：完整手算过程

问题：有 2 个数据点：(x=1, y=3) 和 (x=2, y=5)。用梯度下降拟合 y = wx + b。

初始化：w = 0, b = 0, 学习率 η = 0.01

第 1 轮迭代：

a. 预测：
ŷ₁ = 0×1 + 0 = 0
ŷ₂ = 0×2 + 0 = 0
b. 计算损失：
误差₁ = 0 - 3 = -3
误差₂ = 0 - 5 = -5
L = ((-3)² + (-5)²) / 2 = (9 + 25) / 2 = 17
c. 计算梯度：
∂L/∂w = mean(2 × 误差 × x) = (2×(-3)×1 + 2×(-5)×2) / 2 = (-6 + -20) / 2 = -13
∂L/∂b = mean(2 × 误差) = (2×(-3) + 2×(-5)) / 2 = (-6 + -10) / 2 = -8
d. 更新参数：
w_new = 0 - 0.01×(-13) = 0 + 0.13 = 0.13
b_new = 0 - 0.01×(-8) = 0 + 0.08 = 0.08

💡 梯度是负数 → 参数增大（因为真实值比预测大，需要增大 w 和 b）

第 2 轮迭代：

a. 预测：
ŷ₁ = 0.13×1 + 0.08 = 0.21
ŷ₂ = 0.13×2 + 0.08 = 0.34
b. 损失：
误差₁ = 0.21 - 3 = -2.79
误差₂ = 0.34 - 5 = -4.66
L = (2.79² + 4.66²) / 2 = (7.78 + 21.72) / 2 ≈ 14.75（比17小了！在下降！）
c. 梯度：
∂L/∂w = (2×(-2.79)×1 + 2×(-4.66)×2) / 2 = (-5.58 + -18.64) / 2 = -12.11
∂L/∂b = (2×(-2.79) + 2×(-4.66)) / 2 = (-5.58 + -9.32) / 2 = -7.45
d. 更新：
w = 0.13 - 0.01×(-12.11) = 0.13 + 0.1211 = 0.2511
b = 0.08 - 0.01×(-7.45) = 0.08 + 0.0745 = 0.1545

经过很多轮后，w 会趋近 2，b 会趋近 1（因为 y = 2x + 1 完美拟合这两个点）。

多轮迭代：观察参数如何逐步逼近

上面只算了 2 轮。下面展示 10 轮的完整过程，观察 w 和 b 如何逐步接近真实值 (w=2, b=1)：

观察规律：

  • Loss 单调递减：17 → 14.75 → 12.80 → ... → 0.24（每轮都在减小）
  • 梯度越来越小：-13 → -12.1 → ... → -0.1（接近最优时梯度趋近 0）
  • 参数越来越接近真实值：w: 0→1.987（真实=2），b: 0→1.012（真实=1）
  • 越接近最优，步子越小：这就是梯度下降的"自适应"特性

等高线视角：从"山顶"到"山谷"

如果有两个参数 (w, b)，损失函数形成一个"碗"形曲面。梯度下降就是沿着碗壁滑到碗底：

📌 生活类比：蒙眼下山

想象你蒙着眼站在一座山上，目标是走到最低点（山谷）：

  • 感受坡度 = 计算梯度（哪个方向最陡）
  • 迈一步 = 更新参数（沿最陡方向走一小步）
  • 步子大小 = 学习率（太大会跳过谷底，太小走太慢）
  • 到达平地 = 梯度接近 0（收敛了）

梯度下降就是这个过程的数学版本。每一步都"感受坡度，走一小步"，重复几百次就到谷底了。

3.6 学习率——步子太大会摔跤

学习率效果类比
太大 (η=1.0)在最低点两侧来回跳，甚至发散下山时步子太大，跳过谷底
合适 (η=0.01)稳定下降，逐步收敛正常步伐下山
太小 (η=0.0001)下降极慢，可能训练很久还没收敛蚂蚁爬下山
📌 实践建议
  • 常用起始值：0.01, 0.001, 0.0001
  • 如果 loss 变成 NaN 或越来越大 → 学习率太大，减小 10 倍
  • 如果 loss 下降极慢 → 学习率太小，增大 10 倍
  • 现代优化器（Adam）会自适应调整学习率，通常 0.001 就够

3.7 代码实现：从零训练一个线性模型

"""
完整示例：用梯度下降拟合 y = 2x + 1
不使用任何 ML 库，纯 Python + NumPy
"""
import numpy as np

# ===== 1. 准备数据 =====
np.random.seed(42)
x_data = np.linspace(0, 10, 50)           # 50个x值
y_data = 2 * x_data + 1 + np.random.randn(50) * 0.5  # y = 2x+1 + 噪声

# ===== 2. 初始化参数 =====
w = 0.0   # 斜率（随机初始化）
b = 0.0   # 截距
lr = 0.001  # 学习率
epochs = 1000  # 迭代次数

# ===== 3. 训练循环 =====
losses = []
for epoch in range(epochs):
    # a. 前向：计算预测值
    y_pred = w * x_data + b
    
    # b. 计算损失 (MSE)
    errors = y_pred - y_data
    loss = np.mean(errors ** 2)
    losses.append(loss)
    
    # c. 计算梯度
    N = len(x_data)
    dw = (2/N) * np.sum(errors * x_data)  # ∂L/∂w
    db = (2/N) * np.sum(errors)           # ∂L/∂b
    
    # d. 更新参数
    w = w - lr * dw
    b = b - lr * db
    
    # 每100轮打印一次
    if (epoch + 1) % 100 == 0:
        print(f"Epoch {epoch+1}: w={w:.3f}, b={b:.3f}, loss={loss:.4f}")

print(f"\n最终结果: y = {w:.2f}x + {b:.2f}")
print(f"目标:     y = 2.00x + 1.00")

# ===== 4. 可视化 =====
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 4))

plt.subplot(1, 2, 1)
plt.scatter(x_data, y_data, alpha=0.5, label='数据点')
plt.plot(x_data, w * x_data + b, 'r-', linewidth=2, label=f'拟合: y={w:.2f}x+{b:.2f}')
plt.legend()
plt.title('拟合结果')

plt.subplot(1, 2, 2)
plt.plot(losses)
plt.xlabel('Epoch')
plt.ylabel('Loss (MSE)')
plt.title('损失下降曲线')

plt.tight_layout()
plt.savefig('gradient_descent.png', dpi=100)
plt.show()

运行结果（大致）：

Epoch 100: w=1.523, b=0.741, loss=0.2841
Epoch 200: w=1.712, b=0.856, loss=0.2534
...
Epoch 1000: w=1.987, b=1.023, loss=0.2412

最终结果: y = 1.99x + 1.02  ← 非常接近 y = 2x + 1！

3.8 随机梯度下降与小批量

问题：数据量太大

上面的例子每次用全部 50 个数据计算梯度。如果有 100 万个数据呢？每次迭代都要算 100 万个样本的梯度，太慢了！

解决方案

方法每次用多少数据速度稳定性
批量梯度下降 (BGD)全部数据慢最稳定
随机梯度下降 (SGD)1 个样本最快很 noisy
小批量 (Mini-batch)32/64/128 个快较稳定
📌 实践中的选择

Mini-batch 是默认选择（batch_size=32 或 64）。

它兼顾了速度和稳定性，而且能充分利用 GPU 的并行能力。

注意：虽然名字叫"随机梯度下降"，实践中说的 SGD 通常指 mini-batch SGD。

# Mini-batch 梯度下降
batch_size = 16

for epoch in range(100):
    # 打乱数据
    indices = np.random.permutation(len(x_data))
    
    # 分批处理
    for i in range(0, len(x_data), batch_size):
        batch_idx = indices[i:i+batch_size]
        x_batch = x_data[batch_idx]
        y_batch = y_data[batch_idx]
        
        # 在这个小批量上计算梯度
        y_pred = w * x_batch + b
        errors = y_pred - y_batch
        
        dw = (2/batch_size) * np.sum(errors * x_batch)
        db = (2/batch_size) * np.sum(errors)
        
        # 更新
        w -= lr * dw
        b -= lr * db
⚠️ 常见误区（初学者最容易踩的坑）
✗ "梯度就是损失值"
✓ 梯度是损失对参数的导数（变化率），不是损失本身。损失告诉你"错了多少"，梯度告诉你"参数该往哪个方向调、调多少"。
✗ "学习率越小越好"
✓ 学习率太小会导致收敛极慢。比如 η=0.000001 可能需要 100 万次迭代才能收敛，而 η=0.01 只需要 1000 次。关键是找到"刚好"的值。
✗ "梯度下降一定能找到最优解"
✓ 对于非凸函数（如神经网络），梯度下降可能困在局部最优。不过实践中，高维空间的局部最优通常质量也不错。

3.9 本章习题

📝 概念理解题
  1. 用一句话解释：AI 的"学习"本质上在做什么？
  2. 损失函数的作用是什么？如果损失 = 0 意味着什么？
  3. 梯度 dL/dw = -5 是什么意思？参数 w 应该怎么更新？
  4. 学习率太大会怎样？太小会怎样？
  5. Mini-batch 梯度下降相比全批量有什么优势？
参考答案
  1. 不断调整参数，让预测结果和真实值的差距（损失）越来越小。
  2. 衡量模型预测"错了多少"。损失=0 意味着完美预测（所有预测都等于真实值）。
  3. 梯度为负说明增大 w 会让 L 减小。更新：w = w - η×(-5) = w + 5η（w 增大）。
  4. 太大：在最优解附近震荡甚至发散（loss 越来越大）。太小：收敛极慢，可能训练很久还没到最优。
  5. 速度快（不用每次算全部数据的梯度）+ 能利用 GPU 并行 + 引入随机性有助于逃离局部最优。
📝 手算题
  1. 数据点：(x=2, y=4)。当前 w=1, b=0, η=0.1。做一轮梯度下降，求新的 w 和 b。
    （提示：ŷ=wx+b=2, 误差=2-4=-2, ∂L/∂w=2×(-2)×2=-8, ∂L/∂b=2×(-2)=-4）
  2. 如果损失函数 L = (w-3)²，在 w=5 处的梯度是多少？更新后 w 是多少？（η=0.1）
  3. 计算预测 [2, 4, 6] 和真实值 [3, 3, 5] 的 MSE 损失。
参考答案
  1. w_new = 1 - 0.1×(-8) = 1.8；b_new = 0 - 0.1×(-4) = 0.4
  2. dL/dw = 2(w-3) = 2(5-3) = 4。w_new = 5 - 0.1×4 = 4.6（向3靠近了！）
  3. 误差 = [2-3, 4-3, 6-5] = [-1, 1, 1]。MSE = (1+1+1)/3 = 1
📝 编程实践题
  1. 修改本章代码，拟合 y = 3x - 2 + noise，验证梯度下降能学到 w≈3, b≈-2。
  2. 实现一个函数 train_linear(x, y, lr, epochs)，返回训练好的 w, b 和损失历史列表。画出损失曲线。
  3. 对比实验：分别用 lr=0.1, 0.01, 0.001 训练同一个模型，把三条损失曲线画在同一张图上，观察学习率的影响。
  4. 挑战：用梯度下降拟合二次函数 y = x²。提示：把 x² 当作一个新特征，模型变成 y = w₁×x + w₂×x² + b。
参考答案（题9）
import numpy as np

# 题9：拟合 y = 3x - 2
np.random.seed(0)
x = np.linspace(-5, 5, 100)
y = 3 * x - 2 + np.random.randn(100) * 0.3

w, b = 0.0, 0.0
lr = 0.001
for epoch in range(2000):
    y_pred = w * x + b
    errors = y_pred - y
    dw = (2/len(x)) * np.sum(errors * x)
    db = (2/len(x)) * np.sum(errors)
    w -= lr * dw
    b -= lr * db

print(f"学到: y = {w:.2f}x + {b:.2f}")  # ≈ y = 3.00x - 2.00

本章小结

概念一句话总结
损失函数衡量预测和真实值的差距（越小越好）
梯度损失对参数的导数，指示"上坡方向"
梯度下降参数 = 参数 - 学习率 × 梯度（沿下坡走）
学习率每步走多远（太大会震荡，太小会慢）
Mini-batch每次用一小批数据算梯度（速度+稳定性的平衡）
Epoch所有数据过一遍 = 1 个 epoch
🎯 本章最重要的一个认知

所有 AI 模型的训练，本质上都是梯度下降。

不管是线性回归、神经网络、GPT、Stable Diffusion……训练过程都是：计算损失 → 求梯度 → 更新参数 → 重复。

区别只在于：模型结构不同（参数怎么组织）、损失函数不同（怎么衡量错误）。

3.10 交互式练习

🧪 即时测验

📐 详细推导（点击展开）

推导：为什么 MSE 对 w 的梯度是 (2/N)Σ(ŷ-y)×x ？

目标：求 L = (1/N)Σ(ŷᵢ - yᵢ)² 对 w 的偏导数，其中 ŷᵢ = wxᵢ + b

第1步：展开 L = (1/N)Σ(wxᵢ + b - yᵢ)²
第2步：对 w 求导（链式法则）
∂L/∂w = (1/N)Σ 2(wxᵢ + b - yᵢ) × ∂(wxᵢ + b - yᵢ)/∂w
第3步：∂(wxᵢ + b - yᵢ)/∂w = xᵢ（因为对 w 求导时，xᵢ 是常数，b 和 yᵢ 也是常数）
第4步：代入得 ∂L/∂w = (2/N)Σ(ŷᵢ - yᵢ) × xᵢ

💡 直觉：梯度 = "平均误差 × 输入"。误差越大、输入越大，参数需要调整越多。

推导：为什么梯度下降能减小损失？

核心思想：泰勒展开（一阶近似）

L(w + Δw) ≈ L(w) + (∂L/∂w) × Δw
如果我们令 Δw = -η × (∂L/∂w)，代入：
L(w_new) ≈ L(w) + (∂L/∂w) × (-η × ∂L/∂w) = L(w) - η × (∂L/∂w)²
因为 (∂L/∂w)² ≥ 0，所以 L(w_new) ≤ L(w)（损失不增）

💡 只要学习率 η 足够小（让一阶近似有效），每步更新都保证损失不增大。

推导：MSE 对 b 的梯度为什么是 (2/N)Σ(ŷ-y) ？
L = (1/N)Σ(wxᵢ + b - yᵢ)²
∂L/∂b = (1/N)Σ 2(wxᵢ + b - yᵢ) × ∂(wxᵢ + b - yᵢ)/∂b
∂(wxᵢ + b - yᵢ)/∂b = 1（b 的导数是 1）
所以 ∂L/∂b = (2/N)Σ(ŷᵢ - yᵢ)

💡 注意：对 b 的梯度不包含 xᵢ！因为 b 是"截距"，和输入无关。
