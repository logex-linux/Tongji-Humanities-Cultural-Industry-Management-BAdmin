4.1 感知机——最简单的"神经元"

生物神经元的简化模型

1957 年，Rosenblatt 受到生物神经元的启发，提出了"感知机"：

📌 感知机的计算过程
  1. 加权求和：z = w₁x₁ + w₂x₂ + w₃x₃ + b（就是第2章的矩阵×向量！）
  2. 激活函数：y = f(z)（对求和结果做一个非线性变换）

一个神经元 = 一次线性变换 + 一次非线性激活

✏️ 例题 4.1：手算一个神经元

已知：输入 x = (2, 3)，权重 w = (1, -1)，偏置 b = 0.5，激活函数 f(z) = max(0, z)（ReLU）

第1步：加权求和 z = 1×2 + (-1)×3 + 0.5 = 2 - 3 + 0.5 = -0.5
第2步：激活 y = ReLU(-0.5) = max(0, -0.5) = 0

输出为 0（因为 z 是负数，被 ReLU "截断"了）

4.2 激活函数——引入非线性

为什么需要激活函数？

如果没有激活函数，多层线性变换还是线性的：

y = W₂(W₁x + b₁) + b₂ = W₂W₁x + (W₂b₁ + b₂) = W'x + b'

不管堆多少层，等价于一层！加了激活函数才能学习非线性关系。

常见激活函数

激活函数公式输出范围用在哪里
ReLUmax(0, x)[0, +∞)隐藏层（默认选择）
Sigmoid1/(1+e⁻ˣ)(0, 1)二分类输出层
Tanh(eˣ-e⁻ˣ)/(eˣ+e⁻ˣ)(-1, 1)RNN（了解即可）
GELUx·Φ(x)≈[-0.17, +∞)Transformer 中常用
Softmaxeˣⁱ/Σeˣʲ(0,1) 且和为1多分类输出层
import numpy as np

def relu(x):
    return np.maximum(0, x)

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def softmax(x):
    exp_x = np.exp(x - np.max(x))  # 减最大值防溢出
    return exp_x / exp_x.sum()

# 测试
print(relu(np.array([-2, -1, 0, 1, 2])))   # [0 0 0 1 2]
print(sigmoid(np.array([-2, 0, 2])))         # [0.12 0.5 0.88]
print(softmax(np.array([1, 2, 3])))          # [0.09 0.24 0.67]（和为1）
📌 选择激活函数的简单规则
  • 隐藏层：用 ReLU（简单、快、效果好）
  • 二分类输出：用 Sigmoid（输出一个概率）
  • 多分类输出：用 Softmax（输出各类别概率，和为1）
  • 回归输出：不加激活函数（直接输出数值）
🌉 直觉桥梁：连接第2-3章

神经网络的一层 = 第2章的矩阵乘法 + 激活函数：

h = ReLU(W × x + b)   ← W×x 就是第2章学的！

训练网络 = 第3章的梯度下降：计算损失 → 求梯度 → 更新 W 和 b。

所以神经网络 = 你已会的矩阵运算 + 你已会的梯度下降，只是堆了很多层而已。

4.3 多层感知机 (MLP)——堆叠的力量

网络结构

📌 网络结构术语
  • 输入层：接收原始数据（不算"一层"，因为不做计算）
  • 隐藏层：中间的层，做实际的变换（可以有多个）
  • 输出层：产生最终结果
  • 全连接层：上一层的每个神经元和下一层的每个神经元都相连
  • 参数：每条连接有一个权重 w，每个神经元有一个偏置 b

上面的网络：输入3 → 隐藏4 → 隐藏3 → 输出2

参数量 = (3×4+4) + (4×3+3) + (3×2+2) = 16 + 15 + 8 = 39 个参数

👇 动画：数据从输入层 → 隐藏层（加权求和+ReLU）→ 输出层，逐层流动

4.4 前向传播——手算一个完整网络

✏️ 例题 4.2：手算前向传播

网络：输入2 → 隐藏2（ReLU）→ 输出1（无激活）

参数：

  • W₁ = [[1, 0], [0, 1]]，b₁ = [0, 0]（第1层）
  • W₂ = [[1, 1]]，b₂ = [0]（第2层）

输入：x = (2, 3)

第1层计算：

z₁ = W₁ × x + b₁ = [[1,0],[0,1]] × [2,3] + [0,0] = [2, 3]
h = ReLU(z₁) = ReLU([2, 3]) = [2, 3]（都是正数，不变）

第2层计算：

z₂ = W₂ × h + b₂ = [[1,1]] × [2,3] + [0] = [5]
输出 y = 5（无激活函数，直接输出）

验证：这个网络计算的是 x₁ + x₂ = 2 + 3 = 5 ✓

✏️ 例题 4.3：ReLU 的截断效果

同样的网络，输入 x = (-1, 3)：

z₁ = [[1,0],[0,1]] × [-1,3] = [-1, 3]
h = ReLU([-1, 3]) = [0, 3] ← -1 被截断为 0！
z₂ = [[1,1]] × [0, 3] = [3]
输出 y = 3（而不是 -1+3=2）

💡 ReLU 让网络变成了"分段线性"——不同输入区域有不同的行为。

4.5 为什么需要多层？——XOR 问题

单层网络的局限

XOR（异或）问题：两个输入相同时输出 0，不同时输出 1。

单层感知机只能画一条直线（线性分类），无法解决 XOR。但两层网络可以：

📌 万能近似定理

一个有足够多隐藏神经元的单隐藏层网络，可以近似任意连续函数。

但实践中，多层（深）网络比宽而浅的网络更高效——用更少的参数达到同样的效果。

这就是"深度学习"中"深"的意义。

4.6 用 Python 从零实现一个神经网络

"""
从零实现一个 2 层神经网络（不用任何 ML 框架）
任务：学习 XOR 函数
"""
import numpy as np

# ===== 数据 =====
X = np.array([[0,0], [0,1], [1,0], [1,1]])  # 4个样本
y = np.array([[0], [1], [1], [0]])            # XOR 标签

# ===== 初始化参数 =====
np.random.seed(42)
# 第1层：2个输入 → 4个隐藏神经元
W1 = np.random.randn(2, 4) * 0.5
b1 = np.zeros((1, 4))
# 第2层：4个隐藏 → 1个输出
W2 = np.random.randn(4, 1) * 0.5
b2 = np.zeros((1, 1))

lr = 0.5  # 学习率

# ===== 激活函数 =====
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    """sigmoid 的导数：σ(x)(1-σ(x))"""
    s = sigmoid(x)
    return s * (1 - s)

# ===== 训练 =====
for epoch in range(10000):
    # --- 前向传播 ---
    z1 = X @ W1 + b1          # 第1层线性变换
    h1 = sigmoid(z1)           # 第1层激活
    
    z2 = h1 @ W2 + b2         # 第2层线性变换
    y_pred = sigmoid(z2)       # 第2层激活（输出概率）
    
    # --- 计算损失 ---
    loss = np.mean((y_pred - y) ** 2)
    
    # --- 反向传播（第5章会详细讲）---
    # 输出层梯度
    d_output = 2 * (y_pred - y) * sigmoid_derivative(z2)
    
    # 第2层参数梯度
    dW2 = h1.T @ d_output
    db2 = np.sum(d_output, axis=0, keepdims=True)
    
    # 隐藏层梯度
    d_hidden = d_output @ W2.T * sigmoid_derivative(z1)
    
    # 第1层参数梯度
    dW1 = X.T @ d_hidden
    db1 = np.sum(d_hidden, axis=0, keepdims=True)
    
    # --- 更新参数 ---
    W2 -= lr * dW2
    b2 -= lr * db2
    W1 -= lr * dW1
    b1 -= lr * db1
    
    if (epoch + 1) % 2000 == 0:
        print(f"Epoch {epoch+1}: loss = {loss:.4f}")

# ===== 测试 =====
print("\n预测结果：")
z1 = X @ W1 + b1
h1 = sigmoid(z1)
z2 = h1 @ W2 + b2
predictions = sigmoid(z2)
for i in range(4):
    print(f"  {X[i]} → {predictions[i][0]:.3f} (期望: {y[i][0]})")
# [0,0] → 0.012 (期望: 0) ✓
# [0,1] → 0.987 (期望: 1) ✓
# [1,0] → 0.985 (期望: 1) ✓
# [1,1] → 0.015 (期望: 0) ✓

4.7 用 PyTorch 实现（工业标准）

import torch
import torch.nn as nn
import torch.optim as optim

# ===== 定义网络结构 =====
class XORNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(2, 8)   # 输入2 → 隐藏8
        self.layer2 = nn.Linear(8, 4)   # 隐藏8 → 隐藏4
        self.layer3 = nn.Linear(4, 1)   # 隐藏4 → 输出1
        self.relu = nn.ReLU()
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x):
        x = self.relu(self.layer1(x))   # 第1层 + ReLU
        x = self.relu(self.layer2(x))   # 第2层 + ReLU
        x = self.sigmoid(self.layer3(x)) # 输出层 + Sigmoid
        return x

# ===== 准备数据 =====
X = torch.tensor([[0,0], [0,1], [1,0], [1,1]], dtype=torch.float32)
y = torch.tensor([[0], [1], [1], [0]], dtype=torch.float32)

# ===== 训练 =====
model = XORNet()
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters(), lr=0.01)

for epoch in range(1000):
    # 前向
    y_pred = model(X)
    loss = criterion(y_pred, y)
    
    # 反向 + 更新（PyTorch 自动处理！）
    optimizer.zero_grad()
    loss.backward()    # 自动计算所有梯度
    optimizer.step()   # 自动更新所有参数
    
    if (epoch + 1) % 200 == 0:
        print(f"Epoch {epoch+1}: loss = {loss.item():.4f}")

# ===== 查看网络结构 =====
print(model)
print(f"总参数量: {sum(p.numel() for p in model.parameters())}")
📌 对比：从零实现 vs PyTorch
从零实现PyTorch
前向传播手动写矩阵乘法model(x) 一行搞定
反向传播手动推导每个梯度loss.backward() 自动计算
参数更新手动 w -= lr * dwoptimizer.step() 自动更新
适用场景学习原理实际开发

4.8 网络设计的实践指南

参数量计算

一个 Linear(in, out) 层的参数量 = in × out + out（权重 + 偏置）

✏️ 例题 4.4：计算参数量

网络：输入 784 → 隐藏 256 → 隐藏 128 → 输出 10

第1层：784×256 + 256 = 200,960
第2层：256×128 + 128 = 32,896
第3层：128×10 + 10 = 1,290
总计：235,146 个参数（约 23.5 万）

对比：GPT-3 有 1750 亿个参数，是这个网络的 74 万倍！

设计建议

决策建议
层数从 2-3 层隐藏层开始，不够再加
每层宽度逐层递减（如 256→128→64）或相同
激活函数隐藏层用 ReLU，输出层看任务
过拟合了？减少层数/宽度，加 Dropout，加数据
欠拟合了？增加层数/宽度，训练更久
⚠️ 常见误区
✗ "神经网络是在模拟大脑"
✓ 神经网络只是受大脑启发的数学函数。真正的神经元有复杂的生物化学过程。人工"神经元"就是一个加权求和+激活函数，和生物神经元差别极大。
✗ "层数越多越好"
✓ 太深会导致梯度消失和过拟合。实践中 2-5 层隐藏层对大多数任务就够了。ResNet 的残差连接才让 100+ 层成为可能。
✗ "激活函数可选可不选"
✗ 没有激活函数，100 层网络 = 1 层！多层线性变换还是线性的（矩阵乘法的结合律）。激活函数引入非线性，是网络能学习复杂模式的关键。

4.9 本章习题

📝 概念理解题
  1. 一个神经元做了哪两步计算？
  2. 如果没有激活函数，一个 3 层网络等价于什么？
  3. ReLU(-5) = ? ReLU(3) = ? Sigmoid(0) = ?
  4. 一个 Linear(100, 50) 层有多少个参数？
  5. 为什么 XOR 问题需要多层网络？
参考答案
  1. ① 加权求和 z = W·x + b；② 激活 y = f(z)
  2. 等价于一个单层线性变换（多层线性 = 一层线性）
  3. ReLU(-5) = 0；ReLU(3) = 3；Sigmoid(0) = 0.5
  4. 100×50 + 50 = 5,050 个参数
  5. XOR 不是线性可分的，单层只能画一条直线。多层网络通过非线性激活可以学习曲线边界。
📝 手算题
  1. 网络：输入2→隐藏2(Sigmoid)→输出1。W₁=[[0.5, -0.5],[0.5, -0.5]]，b₁=[0,0]，W₂=[[1, 1]]，b₂=[-0.5]。输入 x=(1, 0)，求输出。
  2. 上题中，如果输入改为 x=(1, 1)，输出是多少？
  3. 计算网络 输入3→隐藏4→输出2 的总参数量。
参考答案
  1. z₁ = [0.5×1+(-0.5)×0, 0.5×1+(-0.5)×0] = [0.5, 0.5]
    h = sigmoid([0.5, 0.5]) = [0.622, 0.622]
    z₂ = 1×0.622 + 1×0.622 + (-0.5) = 0.744
    输出 = sigmoid(0.744) ≈ 0.678
  2. z₁ = [0.5-0.5, 0.5-0.5] = [0, 0]，h = [0.5, 0.5]
    z₂ = 0.5+0.5-0.5 = 0.5，输出 = sigmoid(0.5) ≈ 0.622
  3. 第1层：3×4+4=16，第2层：4×2+2=10，总计 26 个参数

import torch, torch.nn as nn, numpy as np
import matplotlib.pyplot as plt

# 数据
x = np.linspace(-6, 6, 200).reshape(-1, 1).astype(np.float32)
y = np.sin(x).astype(np.float32)
X = torch.from_numpy(x)
Y = torch.from_numpy(y)

# 网络
model = nn.Sequential(
    nn.Linear(1, 32), nn.ReLU(),
    nn.Linear(32, 32), nn.ReLU(),
    nn.Linear(32, 1)
)
opt = torch.optim.Adam(model.parameters(), lr=0.005)
loss_fn = nn.MSELoss()

# 训练
for i in range(2000):
    pred = model(X)
    loss = loss_fn(pred, Y)
    opt.zero_grad(); loss.backward(); opt.step()

# 画图
plt.scatter(x, y, alpha=0.3, label='sin(x)')
plt.plot(x, model(X).detach().numpy(), 'r-', label='网络拟合')
plt.legend(); plt.show()
