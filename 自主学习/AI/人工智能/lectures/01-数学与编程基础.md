## 一、线性代数——AI 的语言

### 1.1 为什么 AI 需要线性代数？

深度学习的本质是**大量的矩阵乘法**。一张图片进入神经网络，就是一组数字（像素值）经过一层层矩阵变换，最终变成分类结果。理解线性代数，就是理解 AI 的"语法"。

### 1.2 向量：有方向的数据

**向量**就是一组有序数字。在 AI 中，向量无处不在：

- 一张 28×28 的手写数字图片 → 展平成 784 维向量
- 一个单词的 Word2Vec 表示 → 300 维向量
- 用户的特征（年龄、收入、消费频率）→ 3 维向量

```python
import numpy as np

# 向量就是一个一维数组
word_vector = np.array([0.2, -0.5, 0.8, 0.1])  # 一个词的"含义"
image_vector = np.random.rand(784)               # 一张图片

# 向量的基本操作
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(a + b)        # [5, 7, 9] 逐元素相加
print(a * b)        # [4, 10, 18] 逐元素相乘（Hadamard积）
print(np.dot(a, b)) # 32 点积（内积）
print(np.linalg.norm(a))  # 3.74 向量的"长度"（L2范数）
```

**点积的直觉：** 两个向量的点积衡量它们的"相似程度"。
- 点积大 → 方向相近 → 相似
- 点积为 0 → 正交 → 无关
- 点积为负 → 方向相反

这就是为什么搜索引擎用向量点积（或余弦相似度）来衡量文本相关性。

### 1.3 矩阵：批量变换的工具

**矩阵**是一个二维数字表格。在 AI 中，矩阵代表**线性变换**——把一组输入映射到一组输出。

```python
# 一个 2x3 矩阵：把 3 维输入变成 2 维输出
W = np.array([[1, 0, -1],
              [0, 1,  1]])

x = np.array([2, 3, 1])  # 输入向量（3维）
y = W @ x                 # 输出向量（2维）= [1, 4]
```

**关键理解：** 神经网络的一层就是 `y = W @ x + b`（矩阵乘法加偏置）。一个有 100 万参数的网络，本质上就是一堆矩阵。

### 1.4 矩阵乘法的维度规则

```
(m × n) @ (n × p) = (m × p)
```

左矩阵的列数 = 右矩阵的行数，结果的维度是"左行右列"。

```python
# 批量处理：一次处理多个样本
# X: 100个样本，每个784维 → shape (100, 784)
# W: 权重矩阵 → shape (784, 256)
# 输出: 100个样本，每个256维 → shape (100, 256)
X = np.random.rand(100, 784)
W = np.random.rand(784, 256)
output = X @ W  # shape: (100, 256)
```

这就是为什么 GPU 擅长深度学习——矩阵乘法可以高度并行化。

### 1.5 特征值与特征向量

对于方阵 A，如果存在向量 v 和标量 λ 使得：

$$Av = \lambda v$$

那么 v 是 A 的**特征向量**，λ 是对应的**特征值**。

**直觉：** 特征向量是矩阵变换中"方向不变"的向量，特征值告诉你这个方向被拉伸/压缩了多少倍。

**在 AI 中的应用：**
- **PCA（主成分分析）**：找数据方差最大的方向 → 协方差矩阵的特征向量
- **谱聚类**：利用图拉普拉斯矩阵的特征向量
- **PageRank**：转移矩阵的主特征向量

```python
A = np.array([[2, 1], [1, 2]])
eigenvalues, eigenvectors = np.linalg.eig(A)
print(eigenvalues)   # [3, 1]
print(eigenvectors)  # 对应的特征向量
```

### 1.6 SVD（奇异值分解）

任何矩阵都可以分解为三个矩阵的乘积：

$$A = U \Sigma V^T$$

- U：左奇异向量（输出空间的基）
- Σ：奇异值（每个方向的重要性）
- V：右奇异向量（输入空间的基）

**应用：**
- 数据压缩（只保留前 k 个最大奇异值）
- 推荐系统（低秩近似）
- 图像压缩

```python
# 图像压缩示例
from PIL import Image
import numpy as np

img = np.array(Image.open('photo.jpg').convert('L'))  # 灰度图
U, S, Vt = np.linalg.svd(img, full_matrices=False)

# 只保留前 50 个奇异值
k = 50
compressed = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
# 原始: 512x512 = 262144 个数字
# 压缩: 512*50 + 50 + 50*512 = 51250 个数字（压缩了 5 倍）
```

## 二、微积分——理解"学习"的过程

### 2.1 导数：变化的速率

导数 f'(x) 告诉你：当 x 变化一点点时，f(x) 变化多少。

$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

**在 AI 中的意义：** 我们想知道"损失函数对每个参数的导数"——即每个参数应该怎么调整才能让误差减小。

### 2.2 偏导数与梯度

当函数有多个变量时（神经网络有百万个参数），对每个变量求偏导：

$$\nabla f = \left(\frac{\partial f}{\partial w_1}, \frac{\partial f}{\partial w_2}, ..., \frac{\partial f}{\partial w_n}\right)$$

**梯度**是一个向量，指向函数增长最快的方向。**负梯度方向**就是函数下降最快的方向。

**梯度下降的核心思想：**

$$w_{new} = w_{old} - \eta \cdot \nabla f(w_{old})$$

其中 η 是学习率（步长）。每次沿着负梯度方向走一小步，最终到达损失函数的最低点。

```python
# 最简单的梯度下降：拟合 y = 2x + 1
import numpy as np

# 生成数据
x_data = np.linspace(0, 10, 100)
y_data = 2 * x_data + 1 + np.random.randn(100) * 0.5

# 初始化参数
w = 0.0  # 斜率
b = 0.0  # 截距
lr = 0.001  # 学习率

# 梯度下降
for epoch in range(1000):
    y_pred = w * x_data + b
    error = y_pred - y_data
    
    # 计算梯度（损失对 w 和 b 的偏导）
    dw = 2 * np.mean(error * x_data)
    db = 2 * np.mean(error)
    
    # 更新参数
    w -= lr * dw
    b -= lr * db

print(f"学到: y = {w:.2f}x + {b:.2f}")  # 接近 y = 2x + 1
```

### 2.3 链式法则：反向传播的数学基础

如果 y = f(g(x))，那么：

$$\frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx}$$

**为什么重要？** 神经网络是很多函数的复合：

$$output = f_4(f_3(f_2(f_1(input))))$$

要计算损失对第一层参数的导数，需要把每一层的导数"链式"乘起来。这就是**反向传播（Backpropagation）**。

```python
# 链式法则示例
# y = sin(x^2)
# dy/dx = cos(x^2) * 2x

# 在神经网络中：
# 输入 x → 线性变换 z = Wx+b → 激活 a = sigmoid(z) → 损失 L = (a-y)²
# 
# dL/da = 2(a-y)
# da/dz = sigmoid(z)(1-sigmoid(z))
# dz/dW = x
# 
# 所以 dL/dW = 2(a-y) * sigmoid(z)(1-sigmoid(z)) * x
```

### 2.4 多元函数与雅可比矩阵

当输入和输出都是向量时，导数变成**雅可比矩阵**：

$$J = \begin{pmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{pmatrix}$$

PyTorch 的 `autograd` 自动帮你计算这些，但理解原理能帮你调试梯度消失/爆炸问题。

## 三、概率与统计——处理不确定性

### 3.1 为什么 AI 需要概率？

AI 模型本质上是在做**概率推断**：
- 分类器输出 P(猫|图片) = 0.92 → "这张图有 92% 概率是猫"
- 语言模型输出 P(下一个词|前文) → 生成文本
- 贝叶斯推断 → 根据证据更新信念

### 3.2 贝叶斯定理

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

**直觉：** 
- P(A) = 先验（在看到证据之前，你对 A 的信念）
- P(B|A) = 似然（如果 A 为真，看到 B 的概率）
- P(A|B) = 后验（看到 B 之后，A 为真的概率）

**例子：垃圾邮件过滤**
- P(垃圾邮件) = 0.3（先验：30% 的邮件是垃圾邮件）
- P(含"免费"|垃圾邮件) = 0.8（垃圾邮件中 80% 含"免费"）
- P(含"免费"|正常邮件) = 0.1（正常邮件中 10% 含"免费"）
- P(垃圾邮件|含"免费") = 0.8×0.3 / (0.8×0.3 + 0.1×0.7) = 0.774

### 3.3 常见分布

| 分布 | 用途 | 例子 |
|------|------|------|
| 正态分布 N(μ,σ²) | 自然现象、权重初始化 | 身高、测量误差 |
| 伯努利分布 | 二分类 | 硬币正面/反面 |
| 多项分布 | 多分类 | 骰子、词表上的概率 |
| 均匀分布 | 随机初始化 | 随机数生成 |
| 指数分布 | 时间间隔 | 用户到达间隔 |

### 3.4 最大似然估计（MLE）

**核心思想：** 选择让观测数据出现概率最大的参数。

$$\hat{\theta} = \arg\max_\theta \prod_{i=1}^n P(x_i|\theta)$$

取对数变成求和（对数似然）：

$$\hat{\theta} = \arg\max_\theta \sum_{i=1}^n \log P(x_i|\theta)$$

**在深度学习中：** 训练分类器时用的交叉熵损失，本质就是在做最大似然估计。最小化交叉熵 = 最大化对数似然。

### 3.5 期望、方差与协方差

```python
import numpy as np

mean = np.mean(data)      # 期望：数据的"中心"
var = np.var(data)        # 方差：数据的"分散程度"
std = np.std(data)        # 标准差：方差的平方根

# 协方差矩阵：多维数据各维度之间的相关性
```

## 四、优化理论——让模型"学习"

### 4.1 梯度下降家族

| 方法 | 特点 | 适用场景 |
|------|------|----------|
| 批量梯度下降 (BGD) | 用全部数据算梯度，稳定但慢 | 小数据集 |
| 随机梯度下降 (SGD) | 每次用一个样本，快但噪声大 | 大数据集 |
| 小批量梯度下降 (Mini-batch) | 折中，batch_size=32/64/128 | **最常用** |
| Adam | 自适应学习率，收敛快 | **默认选择** |
| AdamW | Adam + 权重衰减解耦 | 大模型训练 |

### 4.2 学习率：最重要的超参数

```
学习率太大 → 震荡、发散（loss 变成 NaN）
学习率太小 → 收敛极慢、可能困在局部最优
```

**常用策略：**
- Warmup：前几百步从小学习率线性增大
- Cosine Decay：学习率按余弦曲线衰减
- OneCycleLR：先升后降

```python
# PyTorch 中的学习率调度
import torch.optim as optim

optimizer = optim.AdamW(model.parameters(), lr=1e-3)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100)

for epoch in range(100):
    train(model, optimizer)
    scheduler.step()  # 每个 epoch 后更新学习率
```

### 4.3 凸优化 vs 非凸优化

- **凸函数**：只有一个全局最优，梯度下降一定能找到（如线性回归）
- **非凸函数**：有无数局部最优和鞍点（如深度网络）

好消息：研究表明高维空间中，大多数局部最优的质量接近全局最优。深度学习的损失曲面虽然非凸，但实践中梯度下降效果很好。

### 4.4 鞍点问题

在高维空间中，鞍点（某些方向是极大值，某些方向是极小值）比局部最优点多得多。这就是为什么：
- 需要动量（Momentum）帮助逃离鞍点
- Adam 等自适应方法比纯 SGD 更实用
- 随机性（mini-batch 噪声）反而有助于逃离不好的驻点
