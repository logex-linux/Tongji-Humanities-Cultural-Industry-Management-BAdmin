## 一、从模型到应用：为什么需要 RAG 和 Agent？

### 1.1 LLM 的局限

```
问题1: 知识截止
  用户: "2026年最新的AI政策是什么？"
  LLM: "我的训练数据截止到..."（无法回答最新信息）

问题2: 幻觉
  用户: "贵公司2025年Q3营收是多少？"
  LLM: 编造一个数字（没有你的私有数据）

问题3: 无法行动
  用户: "帮我订明天下午3点的会议室"
  LLM: 只能生成文字，不能真的去操作
```

### 1.2 解决方案

| 问题 | 解决方案 | 核心技术 |
|------|----------|----------|
| 知识截止/幻觉 | RAG（检索增强生成） | 向量数据库 + 检索 |
| 无法行动 | Agent（智能体） | 工具调用 + 规划 |
| 私有数据 | RAG + 微调 | 企业知识库 |

## 二、RAG（检索增强生成）

### 2.1 RAG 的核心思想

```
用户提问 → 检索相关文档 → 把文档+问题一起给 LLM → 基于文档回答

对比：
  纯 LLM:  问题 → LLM → 回答（可能编造）
  RAG:     问题 → 检索 → [问题+相关文档] → LLM → 回答（有据可查）
```

### 2.2 完整 RAG 流程

```
┌─────────── 离线索引阶段 ───────────┐
│                                    │
│  文档 → 分块 → Embedding → 向量DB  │
│                                    │
└────────────────────────────────────┘

┌─────────── 在线查询阶段 ───────────┐
│                                    │
│  问题 → Embedding → 向量检索       │
│       → Top-K 文档                 │
│       → [问题 + 文档] → LLM → 回答 │
│                                    │
└────────────────────────────────────┘
```

### 2.3 文档处理与分块

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.document_loaders import PyPDFLoader

# 1. 加载文档
loader = PyPDFLoader("report.pdf")
documents = loader.load()

# 2. 分块（Chunking）——RAG 效果的关键！
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,        # 每块 500 字符
    chunk_overlap=50,      # 块之间重叠 50 字符（保持上下文）
    separators=["\n\n", "\n", "。", "！", "？", " ", ""],
)
chunks = splitter.split_documents(documents)
print(f"文档被分成 {len(chunks)} 个块")
```

**分块策略对比：**

| 策略 | 适用场景 | 优缺点 |
|------|----------|--------|
| 固定大小 | 通用 | 简单，但可能切断语义 |
| 按段落/标题 | 结构化文档 | 保持语义完整 |
| 递归分割 | **最常用** | 多级分隔符，灵活 |
| 语义分块 | 高质量需求 | 按语义相似度切分 |

```python
client = OpenAI()

def rag_answer(question: str, vectorstore, k=4):
    # 1. 检索
    docs = vectorstore.similarity_search(question, k=k)
    context = "\n\n".join([doc.page_content for doc in docs])
    
    # 2. 构建 prompt
    prompt = f"""基于以下参考资料回答问题。如果资料中没有相关信息，请说"根据现有资料无法回答"。

参考资料：
{context}

问题：{question}

回答："""

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        temperature=0,
    )
    return response.choices[0].message.content
```

## 三、AI Agent（智能体）

### 3.1 什么是 Agent？

```
普通 LLM:  输入 → 输出文本（只能"说"）
Agent:     输入 → 思考 → 行动 → 观察 → 思考 → ... → 输出（能"做"）
```

Agent = LLM + 工具 + 记忆 + 规划

### 3.2 ReAct 模式

```
用户: "北京今天天气怎么样？适合穿什么？"

思考(Thought): 我需要查询北京今天的天气
行动(Action): search_weather(city="北京")
观察(Observation): 晴，25°C，微风

思考(Thought): 25度晴天，适合穿轻薄衣物
行动(Action): 无（已有足够信息）
回答(Final Answer): 北京今天晴天，25°C，微风。建议穿短袖或薄长袖，
                   早晚温差大可以带件薄外套。
```

### 3.3 Function Calling（工具调用）

```python
from openai import OpenAI
import json

client = OpenAI()

# 定义工具
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "获取指定城市的当前天气",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {"type": "string", "description": "城市名称"},
                },
                "required": ["city"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "search_web",
            "description": "搜索互联网获取最新信息",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {"type": "string", "description": "搜索关键词"},
                },
                "required": ["query"],
            },
        },
    },
]

# 实际的工具实现
def get_weather(city: str) -> str:
    # 调用天气 API
    return json.dumps({"city": city, "temp": "25°C", "condition": "晴"})

def search_web(query: str) -> str:
    # 调用搜索 API
    return json.dumps({"results": [f"关于'{query}'的搜索结果..."]})

# Agent 循环
def agent_loop(user_message, max_iterations=5):
    messages = [{"role": "user", "content": user_message}]
    
    for _ in range(max_iterations):
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=tools,
            tool_choice="auto",
        )
        
        msg = response.choices[0].message
        messages.append(msg)
        
        # 如果没有工具调用，返回最终回答
        if not msg.tool_calls:
            return msg.content
        
        # 执行工具调用
        for tool_call in msg.tool_calls:
            func_name = tool_call.function.name
            func_args = json.loads(tool_call.function.arguments)
            
            # 调用对应函数
            if func_name == "get_weather":
                result = get_weather(**func_args)
            elif func_name == "search_web":
                result = search_web(**func_args)
            
            # 把结果反馈给模型
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": result,
            })
    
    return "达到最大迭代次数"

# 使用
answer = agent_loop("北京今天天气怎么样？")
print(answer)
```

### 3.6 记忆系统

```python
"""Agent 的记忆架构"""

class AgentMemory:
    def __init__(self):
        self.short_term = []          # 当前对话上下文
        self.long_term = VectorStore() # 向量数据库（长期记忆）
        self.working = {}             # 工作记忆（当前任务状态）
    
    def add_to_short_term(self, message):
        self.short_term.append(message)
        # 超过窗口大小时，摘要压缩
        if len(self.short_term) > 20:
            summary = self.summarize(self.short_term[:10])
            self.short_term = [summary] + self.short_term[10:]
    
    def save_to_long_term(self, key_info):
        """重要信息存入长期记忆"""
        self.long_term.add(key_info)
    
    def recall(self, query, k=5):
        """从长期记忆中检索相关信息"""
        return self.long_term.search(query, k=k)
```

### 4.1 后端：FastAPI + 流式响应

```python
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from pydantic import BaseModel
from openai import OpenAI

app = FastAPI()
client = OpenAI()

class ChatRequest(BaseModel):
    message: str
    history: list = []

@app.post("/chat")
async def chat(req: ChatRequest):
    """流式聊天接口"""
    def generate():
        stream = client.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": req.message}],
            stream=True,
        )
        for chunk in stream:
            if chunk.choices[0].delta.content:
                yield f"data: {chunk.choices[0].delta.content}\n\n"
        yield "data: [DONE]\n\n"
    
    return StreamingResponse(generate(), media_type="text/event-stream")

@app.post("/rag-chat")
async def rag_chat(req: ChatRequest):
    """RAG 聊天接口"""
    # 1. 检索
    docs = vectorstore.similarity_search(req.message, k=4)
    context = "\n".join([d.page_content for d in docs])
    
    # 2. 生成
    prompt = f"参考资料:\n{context}\n\n问题: {req.message}"
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": "基于参考资料回答，不确定时说明。"},
            {"role": "user", "content": prompt},
        ],
    )
    return {"answer": response.choices[0].message.content,
            "sources": [d.metadata for d in docs]}
```

```python
"""
完整项目：上传文档 → 构建索引 → 对话问答
技术栈：LangChain + Chroma + FastAPI + React
"""

# === 后端核心逻辑 ===
import os
from langchain_community.document_loaders import (
    PyPDFLoader, TextLoader, UnstructuredMarkdownLoader
)
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import HuggingFaceEmbeddings

class KnowledgeBase:
    def __init__(self, persist_dir="./chroma_db"):
        self.embeddings = HuggingFaceEmbeddings(model_name="BAAI/bge-small-zh-v1.5")
        self.persist_dir = persist_dir
        self.vectorstore = None
    
    def add_documents(self, file_paths: list):
        """添加文档到知识库"""
        all_chunks = []
        splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
        
        for path in file_paths:
            if path.endswith('.pdf'):
                docs = PyPDFLoader(path).load()
            elif path.endswith('.md'):
                docs = UnstructuredMarkdownLoader(path).load()
            else:
                docs = TextLoader(path).load()
            
            chunks = splitter.split_documents(docs)
            all_chunks.extend(chunks)
        
        if self.vectorstore is None:
            self.vectorstore = Chroma.from_documents(
                all_chunks, self.embeddings, persist_directory=self.persist_dir
            )
        else:
            self.vectorstore.add_documents(all_chunks)
        
        return len(all_chunks)
    
    def query(self, question: str, k: int = 4) -> dict:
        """查询知识库"""
        docs = self.vectorstore.similarity_search(question, k=k)
        context = "\n\n---\n\n".join([d.page_content for d in docs])
        
        # 调用 LLM
        answer = call_llm(question, context)
        
        return {
            "answer": answer,
            "sources": [{"content": d.page_content[:200], 
                        "file": d.metadata.get("source", "unknown")} for d in docs]
        }

# === 使用 ===
kb = KnowledgeBase()
kb.add_documents(["公司手册.pdf", "产品文档.md", "FAQ.txt"])
```
