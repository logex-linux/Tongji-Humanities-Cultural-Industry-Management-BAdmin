## 一、什么是机器学习？

### 1.1 核心定义

机器学习 = **从数据中自动发现规律，并用规律做预测**。

传统编程：人写规则 → 程序执行
机器学习：数据 + 答案 → 程序自动学出规则

```
传统：  规则 + 数据 → 答案
ML：    数据 + 答案 → 规则
```

### 1.2 三大学习范式

| 范式 | 数据特点 | 典型任务 | 例子 |
|------|----------|----------|------|
| 监督学习 | 有标签 (x, y) | 分类、回归 | 垃圾邮件检测、房价预测 |
| 无监督学习 | 无标签 (x) | 聚类、降维 | 客户分群、异常检测 |
| 强化学习 | 奖励信号 | 决策、控制 | 游戏AI、机器人 |

本讲聚焦**监督学习**（最常用）和**无监督学习**基础。

## 二、线性回归——最简单的 ML 模型

### 2.1 模型定义

$$\hat{y} = w_1 x_1 + w_2 x_2 + ... + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b$$

目标：找到 w 和 b，使预测值尽可能接近真实值。

### 2.2 损失函数：均方误差 (MSE)

$$L = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

**为什么用平方？**
- 数学上好处理（可导、凸函数）
- 对大误差惩罚更重（平方放大）
- 等价于假设噪声服从正态分布时的最大似然估计

### 2.3 解析解（正规方程）

对于线性回归，存在闭式解：

$$\mathbf{w} = (X^T X)^{-1} X^T \mathbf{y}$$

```python
import numpy as np

# 生成数据
np.random.seed(42)
X = np.random.rand(100, 1) * 10
y = 2.5 * X.squeeze() + 3 + np.random.randn(100) * 2

# 正规方程求解
X_bias = np.column_stack([X, np.ones(100)])  # 添加偏置列
w = np.linalg.inv(X_bias.T @ X_bias) @ X_bias.T @ y
print(f"w = {w[0]:.2f}, b = {w[1]:.2f}")  # 接近 2.5 和 3
```

### 2.4 梯度下降求解

当数据量大或特征多时，正规方程计算逆矩阵太慢（O(n³)），用梯度下降：

```python
# 梯度下降实现线性回归
w = np.zeros(n_features)
b = 0.0
lr = 0.01

for epoch in range(1000):
    y_pred = X @ w + b
    error = y_pred - y
    
    dw = (2/N) * X.T @ error
    db = (2/N) * np.sum(error)
    
    w -= lr * dw
    b -= lr * db
```

### 2.5 多项式回归

线性模型只能拟合直线？加特征就行：

$$\hat{y} = w_1 x + w_2 x^2 + w_3 x^3 + b$$

对模型来说还是"线性"的（对参数 w 是线性的），只是输入特征做了变换。

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

poly = PolynomialFeatures(degree=3)
X_poly = poly.fit_transform(X)
model = LinearRegression().fit(X_poly, y)
```

## 三、逻辑回归——分类的起点

### 3.1 从回归到分类

线性回归输出任意实数，但分类需要概率（0到1之间）。用 **Sigmoid 函数**压缩：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

模型：$P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b)$

### 3.2 Sigmoid 的性质

```python
import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-10, 10, 100)
sigmoid = 1 / (1 + np.exp(-z))

plt.plot(z, sigmoid)
plt.axhline(y=0.5, color='r', linestyle='--')
plt.title('Sigmoid Function')
plt.xlabel('z'); plt.ylabel('σ(z)')
plt.show()
```

- 输出范围 (0, 1)：可解释为概率
- z=0 时输出 0.5：决策边界
- 两端饱和：梯度接近 0（后面会讲这是问题）

### 3.3 损失函数：交叉熵

不能用 MSE（非凸，有局部最优）。用**对数损失（交叉熵）**：

$$L = -\frac{1}{N}\sum_{i=1}^N [y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)]$$

**直觉：**
- 真实标签 y=1，预测 ŷ=0.9 → loss = -log(0.9) = 0.105（小，好）
- 真实标签 y=1，预测 ŷ=0.1 → loss = -log(0.1) = 2.303（大，差）

```python
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

# 加载数据
iris = load_iris()
X, y = iris.data, iris.target

# 划分训练/测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 训练
model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)

# 评估
accuracy = model.score(X_test, y_test)
print(f"准确率: {accuracy:.2%}")  # ~97%
```

### 3.4 多分类：Softmax

二分类用 Sigmoid，多分类用 **Softmax**：

$$P(y=k|\mathbf{x}) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}$$

所有类别的概率加起来等于 1。

## 四、支持向量机 (SVM)

### 4.1 核心思想

SVM 找一条**最大间隔**的分界线（超平面）。不仅要分开两类，还要让离分界线最近的点（支持向量）尽可能远。

```
        ○ ○ ○
       ○         ← 间隔（margin）
  ─────────────────  决策边界
       ×         ← 间隔
        × × ×
```

### 4.2 数学形式

$$\min_{w,b} \frac{1}{2}||w||^2 \quad \text{s.t.} \quad y_i(w^T x_i + b) \geq 1$$

- 最大化间隔 = 最小化 ||w||²
- 约束：每个样本都在正确一侧且距离≥1

### 4.3 核技巧：处理非线性

数据线性不可分时，用**核函数**把数据映射到高维空间：

| 核函数 | 公式 | 适用场景 |
|--------|------|----------|
| 线性核 | K(x,y) = x·y | 线性可分 |
| 多项式核 | K(x,y) = (x·y + c)^d | 中等非线性 |
| RBF/高斯核 | K(x,y) = exp(-γ||x-y||²) | **最常用**，强非线性 |

```python
from sklearn.svm import SVC

# RBF 核 SVM
svm = SVC(kernel='rbf', C=1.0, gamma='scale')
svm.fit(X_train, y_train)
print(f"SVM 准确率: {svm.score(X_test, y_test):.2%}")
```

### 4.4 软间隔与正则化参数 C

现实中数据可能有噪声/重叠，允许一些点"违规"：

- **C 大**：严格分类，间隔小，容易过拟合
- **C 小**：宽容分类，间隔大，更鲁棒

## 五、决策树与集成方法

### 5.1 决策树

决策树通过一系列 if-else 规则做分类：

```
年龄 < 30?
├── 是 → 收入 > 50k?
│       ├── 是 → 买 ✓
│       └── 否 → 不买 ✗
└── 否 → 有房?
        ├── 是 → 买 ✓
        └── 否 → 不买 ✗
```

**分裂标准：**
- **信息增益（ID3/C4.5）**：选让熵减少最多的特征
- **基尼不纯度（CART）**：选让不纯度下降最多的特征

$$\text{Entropy}(S) = -\sum_{i} p_i \log_2 p_i$$
$$\text{Gini}(S) = 1 - \sum_{i} p_i^2$$

```python
from sklearn.tree import DecisionTreeClassifier

tree = DecisionTreeClassifier(max_depth=5, min_samples_split=10)
tree.fit(X_train, y_train)

# 可视化
from sklearn.tree import plot_tree
plot_tree(tree, feature_names=iris.feature_names, filled=True)
```

**优点：** 可解释、不需要特征缩放、处理非线性
**缺点：** 容易过拟合、不稳定（数据小变化导致树完全不同）

### 5.2 随机森林：Bagging 思想

**核心思想：** 训练很多棵决策树，每棵树用不同的数据子集和特征子集，最终投票/平均。

```
树1 (数据子集1, 特征子集A) → 预测1
树2 (数据子集2, 特征子集B) → 预测2  → 投票 → 最终预测
树3 (数据子集3, 特征子集C) → 预测3
...
```

```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(n_estimators=100, max_depth=10, random_state=42)
rf.fit(X_train, y_train)
print(f"随机森林准确率: {rf.score(X_test, y_test):.2%}")

# 特征重要性
importances = rf.feature_importances_
for name, imp in sorted(zip(iris.feature_names, importances), key=lambda x: -x[1]):
    print(f"  {name}: {imp:.3f}")
```

### 5.3 XGBoost / LightGBM：Boosting 思想

**Boosting vs Bagging：**
- Bagging（随机森林）：并行训练独立模型，投票
- Boosting（XGBoost）：串行训练，每棵新树专注修正前一棵的错误

```python
import xgboost as xgb

# XGBoost
model = xgb.XGBClassifier(
    n_estimators=200,
    max_depth=6,
    learning_rate=0.1,
    subsample=0.8,
    colsample_bytree=0.8,
    eval_metric='logloss'
)
model.fit(X_train, y_train, eval_set=[(X_test, y_test)], verbose=False)
print(f"XGBoost 准确率: {model.score(X_test, y_test):.2%}")
```

**为什么 XGBoost 在表格数据上这么强？**
- 正则化（L1/L2）防止过拟合
- 二阶泰勒展开优化（比一阶梯度更精确）
- 列采样（类似随机森林的特征随机性）
- 缺失值自动处理
- 并行化加速

## 六、无监督学习

### 6.1 K-Means 聚类

**算法：**
1. 随机初始化 K 个中心点
2. 把每个点分配到最近的中心
3. 重新计算每个簇的中心（均值）
4. 重复 2-3 直到收敛

```python
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

X = np.random.randn(300, 2)  # 生成数据
X[:100] += [3, 3]
X[100:200] += [-3, 3]

kmeans = KMeans(n_clusters=3, random_state=42)
labels = kmeans.fit_predict(X)

plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis', alpha=0.6)
plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1], 
            c='red', s=200, marker='X')
plt.title('K-Means Clustering')
plt.show()
```

**选择 K：肘部法则**

```python
inertias = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, random_state=42)
    km.fit(X)
    inertias.append(km.inertia_)

plt.plot(range(1, 11), inertias, 'bo-')
plt.xlabel('K'); plt.ylabel('Inertia')
plt.title('Elbow Method')
plt.show()
# 找"拐点"——曲线从陡变缓的位置
```

### 6.2 PCA（主成分分析）

**目标：** 找到数据方差最大的方向，投影降维。

**步骤：**
1. 数据中心化（减均值）
2. 计算协方差矩阵
3. 求特征值和特征向量
4. 取前 k 个最大特征值对应的特征向量
5. 投影到新空间

```python
from sklearn.decomposition import PCA

# 将 4 维鸢尾花数据降到 2 维
pca = PCA(n_components=2)
X_2d = pca.fit_transform(iris.data)

print(f"解释方差比: {pca.explained_variance_ratio_}")  # [0.92, 0.05]
# 前两个主成分解释了 97% 的方差！

plt.scatter(X_2d[:, 0], X_2d[:, 1], c=iris.target, cmap='viridis')
plt.xlabel(f'PC1 ({pca.explained_variance_ratio_[0]:.1%})')
plt.ylabel(f'PC2 ({pca.explained_variance_ratio_[1]:.1%})')
plt.title('PCA of Iris Dataset')
plt.show()
```

## 七、模型评估与选择

### 7.1 训练集/验证集/测试集

```
全部数据
├── 训练集 (70-80%)：用来训练模型
├── 验证集 (10-15%)：用来调超参数
└── 测试集 (10-15%)：最终评估，只看一次！
```

**关键原则：** 测试集只能在最终评估时用一次。反复在测试集上调参会导致"数据泄露"。

### 7.2 交叉验证

```python
from sklearn.model_selection import cross_val_score

# 5折交叉验证
scores = cross_val_score(model, X, y, cv=5, scoring='accuracy')
print(f"准确率: {scores.mean():.3f} ± {scores.std():.3f}")
```

```
折1: [验证] [训练] [训练] [训练] [训练]
折2: [训练] [验证] [训练] [训练] [训练]
折3: [训练] [训练] [验证] [训练] [训练]
折4: [训练] [训练] [训练] [验证] [训练]
折5: [训练] [训练] [训练] [训练] [验证]
```

### 7.3 评估指标

**分类任务：**

| 指标 | 公式 | 适用场景 |
|------|------|----------|
| 准确率 (Accuracy) | 正确数/总数 | 类别平衡时 |
| 精确率 (Precision) | TP/(TP+FP) | 关注"预测为正的有多少是对的" |
| 召回率 (Recall) | TP/(TP+FN) | 关注"实际为正的有多少被找到" |
| F1 | 2×P×R/(P+R) | 精确率和召回率的平衡 |
| AUC-ROC | ROC曲线下面积 | 综合评估，不受阈值影响 |

```python
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score

y_pred = model.predict(X_test)
print(classification_report(y_test, y_pred))

# 混淆矩阵
#              预测正  预测负
# 实际正  [  TP      FN  ]
# 实际负  [  FP      TN  ]
```

**回归任务：**
- MAE（平均绝对误差）：对异常值鲁棒
- MSE（均方误差）：对大误差敏感
- R²（决定系数）：解释了多大比例的方差

### 7.4 过拟合与欠拟合

```
欠拟合（高偏差）：模型太简单，训练集和测试集表现都差
过拟合（高方差）：模型太复杂，训练集好但测试集差
```

**诊断方法：** 画学习曲线（训练集/验证集误差 vs 数据量）

**解决方案：**

| 问题 | 解决方案 |
|------|----------|
| 过拟合 | 正则化(L1/L2)、Dropout、早停、增加数据、减小模型复杂度 |
| 欠拟合 | 增加特征、增大模型复杂度、减小正则化、训练更久 |

### 7.5 正则化

**L1 (Lasso)：** 让部分参数变为 0 → 特征选择
$$L_{L1} = \lambda \sum |w_i|$$

**L2 (Ridge)：** 让参数整体变小 → 防止过大
$$L_{L2} = \lambda \sum w_i^2$$

```python
from sklearn.linear_model import Ridge, Lasso

ridge = Ridge(alpha=1.0)   # L2 正则化
lasso = Lasso(alpha=0.1)   # L1 正则化（会做特征选择）
```

## 九、完整 ML Pipeline

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.ensemble import GradientBoostingClassifier

# 定义预处理
numeric_features = ['age', 'income', 'score']
categorical_features = ['city', 'education']

numeric_transformer = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])

categorical_transformer = Pipeline([
    ('imputer', SimpleImputer(strategy='most_frequent')),
    ('encoder', OneHotEncoder(handle_unknown='ignore'))
])

preprocessor = ColumnTransformer([
    ('num', numeric_transformer, numeric_features),
    ('cat', categorical_transformer, categorical_features)
])

# 完整 Pipeline
pipe = Pipeline([
    ('preprocess', preprocessor),
    ('classifier', GradientBoostingClassifier(n_estimators=100))
])

# 训练和评估
pipe.fit(X_train, y_train)
print(f"准确率: {pipe.score(X_test, y_test):.2%}")
```

## 十、本讲小结

| 算法 | 适用场景 | 优缺点 |
|------|----------|--------|
| 线性回归 | 连续值预测、基线 | 简单可解释，但只能拟合线性关系 |
| 逻辑回归 | 二分类、概率输出 | 快速、可解释，非线性需特征工程 |
| SVM | 中小规模、高维数据 | 效果好，但大数据集慢 |
| 决策树 | 需要可解释性 | 直观，但容易过拟合 |
| 随机森林 | 通用表格数据 | 稳定、不容易过拟合，但不够极致 |
| XGBoost | **表格数据竞赛首选** | 效果好、速度快，但需要调参 |
| K-Means | 球形簇聚类 | 简单快速，需预设K |
| PCA | 降维、可视化 | 线性降维，保留最大方差 |
