## 一、从感知机到神经网络

### 1.1 感知机：最简单的"神经元"

1957 年，Rosenblatt 提出感知机——一个做二分类的线性模型：

$$\hat{y} = \begin{cases} 1 & \text{if } w^T x + b > 0 \\ 0 & \text{otherwise} \end{cases}$$

**致命缺陷：** 1969 年 Minsky 证明感知机无法解决 XOR 问题（非线性可分）。AI 进入第一次寒冬。

### 1.2 多层感知机 (MLP)：突破线性限制

解决方案：叠加多层，加入非线性激活函数。

```
输入层        隐藏层1       隐藏层2       输出层
[x1] ──→ [h1] ──→ [h1] ──→ [y]
[x2] ──→ [h2] ──→ [h2]
[x3] ──→ [h3] ──→ [h3]
         [h4]
```

**万能近似定理：** 一个有足够多隐藏神经元的单隐藏层网络，可以近似任意连续函数。

### 1.3 激活函数：非线性的来源

没有激活函数，多层线性变换还是线性的（矩阵乘法的结合律）。激活函数引入非线性：

| 激活函数 | 公式 | 特点 |
|----------|------|------|
| Sigmoid | 1/(1+e⁻ˣ) | 输出(0,1)，两端梯度消失 |
| Tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 输出(-1,1)，零中心 |
| **ReLU** | max(0, x) | **最常用**，计算快，缓解梯度消失 |
| Leaky ReLU | max(0.01x, x) | 解决 ReLU "死神经元" |
| GELU | x·Φ(x) | Transformer 中常用 |
| Swish/SiLU | x·σ(x) | 平滑版 ReLU |

```python
import torch
import torch.nn.functional as F
import matplotlib.pyplot as plt

x = torch.linspace(-5, 5, 100)

plt.figure(figsize=(12, 4))
plt.subplot(1, 3, 1)
plt.plot(x, torch.sigmoid(x)); plt.title('Sigmoid')
plt.subplot(1, 3, 2)
plt.plot(x, torch.relu(x)); plt.title('ReLU')
plt.subplot(1, 3, 3)
plt.plot(x, torch.tanh(x)); plt.title('Tanh')
plt.tight_layout(); plt.show()
```

**为什么 ReLU 统治了深度学习？**
- 计算简单（一个 max 操作）
- 正区间梯度恒为 1，缓解梯度消失
- 稀疏激活（负值输出 0），类似生物神经元

### 2.3 用 PyTorch 实现神经网络

```python
import torch
import torch.nn as nn

# 方法一：用 nn.Sequential 快速搭建
model = nn.Sequential(
    nn.Linear(784, 256),   # 全连接层：784→256
    nn.ReLU(),             # 激活函数
    nn.Linear(256, 128),   # 256→128
    nn.ReLU(),
    nn.Linear(128, 10),    # 128→10（10个类别）
)

# 方法二：自定义类（更灵活）
class MLP(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=256, output_dim=10):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, hidden_dim)
        self.fc3 = nn.Linear(hidden_dim, output_dim)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(0.2)
    
    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.relu(self.fc2(x))
        x = self.fc3(x)
        return x

model = MLP()
print(model)
print(f"参数量: {sum(p.numel() for p in model.parameters()):,}")
```

### 2.4 完整训练循环

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset

# 1. 准备数据
X_train = torch.randn(1000, 784)
y_train = torch.randint(0, 10, (1000,))
dataset = TensorDataset(X_train, y_train)
loader = DataLoader(dataset, batch_size=64, shuffle=True)

# 2. 定义模型、损失、优化器
model = MLP()
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# 3. 训练循环
for epoch in range(20):
    total_loss = 0
    correct = 0
    
    for X_batch, y_batch in loader:
        # 前向传播
        logits = model(X_batch)
        loss = criterion(logits, y_batch)
        
        # 反向传播
        optimizer.zero_grad()  # 清零梯度！
        loss.backward()        # 计算梯度
        optimizer.step()       # 更新参数
        
        # 统计
        total_loss += loss.item()
        correct += (logits.argmax(1) == y_batch).sum().item()
    
    acc = correct / len(dataset)
    print(f"Epoch {epoch+1}: loss={total_loss/len(loader):.4f}, acc={acc:.2%}")
```

## 三、训练技巧

### 3.1 权重初始化

随机初始化不是随便随机的。太大→梯度爆炸，太小→梯度消失。

```python
# Xavier 初始化（适合 Sigmoid/Tanh）
nn.init.xavier_uniform_(layer.weight)

# Kaiming 初始化（适合 ReLU）——最常用
nn.init.kaiming_normal_(layer.weight, mode='fan_in', nonlinearity='relu')
```

### 3.2 Batch Normalization

对每一层的输入做标准化（均值0方差1），然后用可学习的 γ, β 缩放：

$$\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} \cdot \gamma + \beta$$

**好处：**
- 允许使用更大的学习率
- 减少对初始化的依赖
- 轻微的正则化效果
- 加速收敛

```python
class MLPWithBN(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.bn1 = nn.BatchNorm1d(256)
        self.fc2 = nn.Linear(256, 128)
        self.bn2 = nn.BatchNorm1d(128)
        self.fc3 = nn.Linear(128, 10)
    
    def forward(self, x):
        x = F.relu(self.bn1(self.fc1(x)))
        x = F.relu(self.bn2(self.fc2(x)))
        return self.fc3(x)
```

### 3.3 Dropout

训练时随机"关闭"一部分神经元（设为0），防止过拟合：

```python
self.dropout = nn.Dropout(p=0.5)  # 50% 概率置零

# 训练时：随机丢弃
# 推理时：全部保留（自动处理，不需要手动切换）
```

**直觉：** 相当于训练了多个子网络的集成，每个神经元不能依赖其他特定神经元。

### 3.4 学习率调度

```python
# 余弦退火
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100)

# Warmup + 线性衰减（Transformer 常用）
scheduler = optim.lr_scheduler.OneCycleLR(
    optimizer, max_lr=1e-3, 
    steps_per_epoch=len(loader), epochs=20
)

# 手动 Warmup
def get_lr(epoch, warmup_epochs=5, max_lr=1e-3):
    if epoch < warmup_epochs:
        return max_lr * epoch / warmup_epochs
    else:
        return max_lr * 0.5 * (1 + math.cos(math.pi * epoch / 100))
```

### 3.5 梯度裁剪

防止梯度爆炸（RNN/Transformer 中常见）：

```python
# 按范数裁剪
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# 按值裁剪
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)
```

## 四、卷积神经网络 (CNN)

### 4.1 为什么图像需要 CNN？

一张 224×224×3 的图片有 150,528 个像素。如果用全连接层：
- 第一层 1000 个神经元 → 1.5 亿参数（仅一层！）
- 忽略空间结构（像素的上下左右关系）
- 不具备平移不变性（猫在左上角和右下角应该一样识别）

**CNN 的三大思想：**
1. **局部连接**：每个神经元只看一小块区域（感受野）
2. **权重共享**：同一个卷积核扫描整张图
3. **池化**：逐步降低分辨率，增大感受野

### 4.2 卷积操作

```
输入 (5×5)          卷积核 (3×3)         输出 (3×3)
[1 0 1 2 1]        [1 0 1]            [4 3 4]
[0 1 0 1 0]   ×    [0 1 0]     →      [2 4 3]
[1 0 1 0 1]        [1 0 1]            [2 3 4]
[2 1 0 1 0]
[1 0 1 0 1]
```

卷积核在输入上滑动，每个位置做点积，得到一个输出值。

```python
import torch.nn as nn

# 卷积层
conv = nn.Conv2d(
    in_channels=3,      # 输入通道（RGB=3）
    out_channels=64,    # 输出通道（64个卷积核）
    kernel_size=3,      # 卷积核大小 3×3
    stride=1,           # 步长
    padding=1           # 填充（保持尺寸不变）
)

x = torch.randn(1, 3, 224, 224)  # batch=1, 3通道, 224×224
out = conv(x)
print(out.shape)  # [1, 64, 224, 224]
```

**输出尺寸公式：**
$$H_{out} = \frac{H_{in} + 2 \times padding - kernel\_size}{stride} + 1$$

### 4.3 池化层

```python
# 最大池化：取窗口内最大值
pool = nn.MaxPool2d(kernel_size=2, stride=2)
# 224×224 → 112×112

# 平均池化
avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)

# 全局平均池化：整个特征图取平均 → 一个数
gap = nn.AdaptiveAvgPool2d(1)  # 任意尺寸 → 1×1
```

### 4.4 经典 CNN 架构

```python
class SimpleCNN(nn.Module):
    """一个简单的 CNN，用于 CIFAR-10 (32×32×3 → 10类)"""
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1),   # 32×32×32
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2),                   # 16×16×32
            
            nn.Conv2d(32, 64, 3, padding=1),  # 16×16×64
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(2),                   # 8×8×64
            
            nn.Conv2d(64, 128, 3, padding=1), # 8×8×128
            nn.BatchNorm2d(128),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),           # 1×1×128
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(64, 10),
        )
    
    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x
```

### 4.5 ResNet：残差连接

**问题：** 网络越深越好吗？不一定！深层网络训练困难（梯度消失/爆炸）。

**解决方案（He et al., 2015）：** 残差连接（Skip Connection）

$$\text{output} = F(x) + x$$

不是让层学习 H(x)，而是学习残差 F(x) = H(x) - x。如果不需要变换，F(x)=0 即可（恒等映射）。

```python
class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(channels)
    
    def forward(self, x):
        residual = x
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += residual  # 残差连接！
        return F.relu(out)
```

**为什么残差连接有效？**
- 梯度可以直接"跳过"层传播（解决梯度消失）
- 网络可以学习"什么都不做"（恒等映射）
- 集成学习视角：相当于不同深度路径的集成

## 五、循环神经网络 (RNN) 简介

### 5.1 序列数据的挑战

文本、语音、时间序列都是**序列**——有顺序、长度可变。全连接和 CNN 不擅长处理变长序列。

### 5.2 RNN 的基本思想

```
h₀ → [RNN] → h₁ → [RNN] → h₂ → [RNN] → h₃
      ↑              ↑              ↑
      x₁             x₂             x₃
```

每一步：$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b)$

**问题：** 长序列梯度消失（连乘效应），无法记住远处的信息。

### 5.3 LSTM / GRU

通过"门控"机制解决长程依赖：

- **遗忘门**：决定丢弃什么旧信息
- **输入门**：决定写入什么新信息
- **输出门**：决定输出什么

> 注：在现代 AI 中，Transformer 已经基本取代了 RNN/LSTM。了解即可，不必深入。

## 六、Transformer——现代 AI 的基石

### 6.1 为什么需要 Transformer？

RNN 的问题：
- 顺序计算，无法并行（慢）
- 长距离依赖仍然困难
- 训练不稳定

**Transformer (2017, "Attention Is All You Need")：**
- 完全基于注意力机制
- 可以并行计算
- 任意两个位置直接交互（无距离限制）

### 6.2 自注意力机制 (Self-Attention)

**核心思想：** 每个词"看"所有其他词，决定关注谁。

对于输入序列中的每个元素，计算三个向量：
- **Query (Q)**：我在找什么？
- **Key (K)**：我能提供什么？
- **Value (V)**：我的实际内容是什么

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

```python
import torch
import torch.nn.functional as F
import math

def self_attention(Q, K, V):
    """
    Q, K, V: shape (seq_len, d_k)
    """
    d_k = Q.size(-1)
    
    # 1. 计算注意力分数：Q 和 K 的点积
    scores = Q @ K.T  # (seq_len, seq_len)
    
    # 2. 缩放（防止点积过大导致 softmax 饱和）
    scores = scores / math.sqrt(d_k)
    
    # 3. Softmax 归一化（每行加起来=1）
    attention_weights = F.softmax(scores, dim=-1)
    
    # 4. 加权求和 V
    output = attention_weights @ V  # (seq_len, d_k)
    
    return output, attention_weights
```

**直觉例子：**
句子 "The cat sat on the mat"
- "sat" 的 Query 和 "cat" 的 Key 点积大 → 高注意力（猫是坐的主体）
- "sat" 的 Query 和 "the" 的 Key 点积小 → 低注意力

### 6.3 多头注意力 (Multi-Head Attention)

一个注意力头只能关注一种关系。多头 = 多个注意力头并行，各自关注不同方面：

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, n_heads=8):
        super().__init__()
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def forward(self, x, mask=None):
        batch_size, seq_len, _ = x.shape
        
        # 线性变换
        Q = self.W_q(x).view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(x).view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(x).view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        # shape: (batch, n_heads, seq_len, d_k)
        
        # 注意力
        scores = Q @ K.transpose(-2, -1) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        attn = F.softmax(scores, dim=-1)
        output = attn @ V
        
        # 合并多头
        output = output.transpose(1, 2).contiguous().view(batch_size, seq_len, -1)
        return self.W_o(output)
```

### 6.4 位置编码 (Positional Encoding)

自注意力是"位置无关"的（打乱顺序结果一样）。需要额外注入位置信息：

$$PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d_{model}})$$
$$PE_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d_{model}})$$

```python
class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len).unsqueeze(1).float()
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                            -(math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.register_buffer('pe', pe.unsqueeze(0))
    
    def forward(self, x):
        return x + self.pe[:, :x.size(1)]
```

### 6.5 完整 Transformer Block

```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model=512, n_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.attention = MultiHeadAttention(d_model, n_heads)
        self.ff = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Linear(d_ff, d_model),
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # 自注意力 + 残差 + LayerNorm
        attn_out = self.attention(self.norm1(x), mask)
        x = x + self.dropout(attn_out)
        
        # 前馈网络 + 残差 + LayerNorm
        ff_out = self.ff(self.norm2(x))
        x = x + self.dropout(ff_out)
        
        return x
```

### 6.6 Transformer 的完整架构

```
原始 Transformer (2017):
┌─────────────────────────────────┐
│  Encoder (6层)    │  Decoder (6层)  │
│  自注意力          │  掩码自注意力    │
│  前馈网络          │  交叉注意力      │
│                   │  前馈网络        │
└─────────────────────────────────┘

现代变体：
- Encoder-only: BERT（理解任务）
- Decoder-only: GPT（生成任务）← 当前主流
- Encoder-Decoder: T5（翻译、摘要）
```

### 6.7 因果掩码 (Causal Mask)

GPT 类模型生成文本时，不能"偷看"未来的词：

```python
def create_causal_mask(seq_len):
    """下三角矩阵：位置 i 只能看到 0..i"""
    mask = torch.tril(torch.ones(seq_len, seq_len))
    return mask.unsqueeze(0).unsqueeze(0)  # (1, 1, seq_len, seq_len)

# 效果：
# [[1, 0, 0, 0],
#  [1, 1, 0, 0],
#  [1, 1, 1, 0],
#  [1, 1, 1, 1]]
```

## 七、生成模型简介

### 7.1 GAN（生成对抗网络）

两个网络对抗训练：
- **生成器 G**：从噪声生成假图片，目标是骗过判别器
- **判别器 D**：区分真假图片，目标是识破生成器

$$\min_G \max_D \; \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1 - D(G(z)))]$$

### 7.2 扩散模型 (Diffusion Model)

当前最火的图像生成方法（Stable Diffusion、DALL·E 3）：

**前向过程：** 逐步加噪声，图片 → 纯噪声
**反向过程：** 学习逐步去噪声，纯噪声 → 图片

```
图片 → [加噪] → 微噪 → [加噪] → ... → [加噪] → 纯噪声
图片 ← [去噪] ← 微噪 ← [去噪] ← ... ← [去噪] ← 纯噪声
```

## 八、实战：用 PyTorch 训练 MNIST

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# 数据
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])
train_data = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_data = datasets.MNIST('./data', train=False, transform=transform)
train_loader = DataLoader(train_data, batch_size=128, shuffle=True)
test_loader = DataLoader(test_data, batch_size=256)

# 模型
class MNISTNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        )
        self.fc = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 7 * 7, 128), nn.ReLU(), nn.Dropout(0.5),
            nn.Linear(128, 10),
        )
    
    def forward(self, x):
        return self.fc(self.conv(x))

# 训练
model = MNISTNet()
optimizer = optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()

for epoch in range(10):
    model.train()
    for X, y in train_loader:
        loss = criterion(model(X), y)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    
    # 测试
    model.eval()
    correct = sum(model(X).argmax(1).eq(y).sum().item() for X, y in test_loader)
    print(f"Epoch {epoch+1}: Test Acc = {correct/len(test_data):.2%}")
# 通常能达到 99%+
```

## 九、本讲小结

| 概念 | 核心要点 |
|------|----------|
| 激活函数 | ReLU 是默认选择，GELU 用于 Transformer |
| BatchNorm | 加速训练、稳定梯度 |
| Dropout | 随机正则化，防过拟合 |
| CNN | 局部连接 + 权重共享 + 池化 |
| ResNet | 残差连接解决深层网络训练 |
| Transformer | 自注意力 = Q·K^T/√d → softmax → ×V |
| 多头注意力 | 并行关注不同关系 |
| 位置编码 | 注入序列顺序信息 |
