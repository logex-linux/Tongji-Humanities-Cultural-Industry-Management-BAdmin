第一讲：数学与编程基础

建立 AI 学习所需的数学直觉和编程能力。不追求严格证明，而是理解"为什么"和"怎么用"。

一、线性代数——AI 的语言

1.1 为什么 AI 需要线性代数？

深度学习的本质是大量的矩阵乘法。一张图片进入神经网络，就是一组数字（像素值）经过一层层矩阵变换，最终变成分类结果。理解线性代数，就是理解 AI 的"语法"。

1.2 向量：有方向的数据

向量就是一组有序数字。在 AI 中，向量无处不在：

  • 一张 28×28 的手写数字图片 → 展平成 784 维向量
  • 一个单词的 Word2Vec 表示 → 300 维向量
  • 用户的特征（年龄、收入、消费频率）→ 3 维向量
import numpy as np

# 向量就是一个一维数组
word_vector = np.array([0.2, -0.5, 0.8, 0.1])
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(np.dot(a, b))        # 32 点积
print(np.linalg.norm(a))   # 3.74 向量的"长度"

💡 点积的直觉

两个向量的点积衡量它们的"相似程度"。点积大 → 方向相近 → 相似；点积为 0 → 正交 → 无关。这就是为什么搜索引擎用向量点积来衡量文本相关性。

1.3 矩阵：批量变换的工具

关键理解：神经网络的一层就是 y = W @ x + b（矩阵乘法加偏置）。一个有 100 万参数的网络，本质上就是一堆矩阵。

# 批量处理：一次处理多个样本
X = np.random.rand(100, 784)   # 100个样本，每个784维
W = np.random.rand(784, 256)   # 权重矩阵
output = X @ W                 # shape: (100, 256)

1.4 特征值与 SVD

对于方阵 A，如果 Av = λv，那么 v 是特征向量，λ 是特征值。

  • PCA：找数据方差最大的方向 → 协方差矩阵的特征向量
  • SVD：任何矩阵 = U·Σ·Vᵀ，用于数据压缩和推荐系统

二、微积分——理解"学习"的过程

2.1 梯度下降的核心思想

w_new = w_old - η · ∇f(w_old)

每次沿着负梯度方向走一小步，最终到达损失函数的最低点。

2.2 链式法则：反向传播的数学基础

如果 y = f(g(x))，那么 dy/dx = (dy/dg)·(dg/dx)。神经网络是很多函数的复合，反向传播就是把每一层的导数"链式"乘起来。

三、概率与统计

3.1 贝叶斯定理

P(A|B) = P(B|A) · P(A) / P(B)

先验 × 似然 → 后验。看到证据后更新信念。

3.2 最大似然估计 (MLE)

选择让观测数据出现概率最大的参数。训练分类器时用的交叉熵损失，本质就是在做最大似然估计。

四、优化理论

方法特点适用场景
SGD每次一个样本，快但噪声大大数据集
Mini-batch折中，batch=32/64/128最常用
Adam自适应学习率，收敛快默认选择
AdamWAdam + 权重衰减解耦大模型训练

线性回归：ŷ = wᵀx + b，最小化 MSE

逻辑回归：P(y=1|x) = σ(wᵀx + b)，最小化交叉熵

随机森林 (Bagging)XGBoost (Boosting)

第三讲：深度学习

从感知机到 Transformer，理解现代 AI 的核心引擎。掌握 PyTorch 框架。

一、神经网络基础

激活函数

函数公式特点
ReLUmax(0, x)最常用，计算快
GELUx·Φ(x)Transformer 常用
Sigmoid1/(1+e⁻ˣ)输出(0,1)，两端梯度消失

二、PyTorch 核心

import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.fc2 = nn.Linear(256, 10)
        self.relu = nn.ReLU()
    
    def forward(self, x):
        return self.fc2(self.relu(self.fc1(x)))

三、CNN 卷积神经网络

三大思想：局部连接（只看一小块）、权重共享（同一卷积核扫描全图）、池化（降低分辨率）

ResNet 残差连接

output = F(x) + x

让网络学习"残差"而非完整映射。解决深层网络梯度消失，可以训练 100+ 层。

四、Transformer

自注意力机制

Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V

每个词"看"所有其他词，决定关注谁。Q=我在找什么，K=我能提供什么，V=我的实际内容。

# 自注意力的核心计算
scores = Q @ K.T / math.sqrt(d_k)
attention_weights = F.softmax(scores, dim=-1)
output = attention_weights @ V

多头注意力

多个注意力头并行，各自关注不同方面（语法关系、语义关系、位置关系...）

第五讲：大语言模型（LLM）

深入理解 LLM 的训练原理、对齐技术、推理优化，掌握 Prompt Engineering 和微调。

一、LLM 本质：下一个词预测器

P(x_{t+1} | x_1, x_2, ..., x_t)

就这么简单的任务，当模型足够大、数据足够多时，涌现出了翻译、推理、编程、创作等能力。

二、三阶段训练

阶段数据目标结果
预训练海量文本 (TB级)下一 token 预测基座模型
SFT指令-回答对遵循指令指令模型
RLHF/DPO人类偏好有帮助、诚实、无害对齐模型

三、Prompt Engineering

好的 Prompt = 角色 + 任务 + 约束 + 格式 + 示例

技巧：
- Few-shot: 给几个示例
- Chain-of-Thought: "让我们一步步思考"
- ReAct: 思考→行动→观察 循环

四、LoRA 微调

W' = W + BA （B∈ℝ^(d×r), A∈ℝ^(r×d), r≪d）

只训练 0.1% 的参数，节省 99% 显存。7B 模型在单张消费级 GPU 上就能微调。

五、推理优化

  • KV Cache：缓存历史计算，加速生成
  • 量化：FP16→INT4，显存减少 4x
  • vLLM：PagedAttention，吞吐量提升 2-4x
  • 投机解码：小模型草稿 + 大模型验证，加速 2-3x
🏁

里程碑：用 LoRA 微调一个 7B 开源模型，在特定领域任务上超越基线

第六讲：AI 应用开发

将 LLM 变成实际产品——RAG、AI Agent、全栈开发。

一、RAG（检索增强生成）

用户提问 → Embedding → 向量检索 Top-K 文档
         → [问题 + 文档] → LLM → 基于文档回答

解决 LLM 的知识截止和幻觉问题。

关键技术

  • 分块：500字左右，重叠50字，按语义切分
  • Embedding：BGE / text-embedding-3
  • 向量数据库：FAISS / Chroma / Milvus
  • 混合检索：向量 + BM25 关键词
  • 重排序：Cross-Encoder 精排

二、AI Agent

Agent = LLM + 工具 + 记忆 + 规划

ReAct 模式：
思考 → 行动(调用工具) → 观察(获取结果) → 思考 → ... → 最终回答

Function Calling

LLM 决定调用什么工具、传什么参数。开发者实现工具函数。

第八讲：AI 安全与伦理

对齐、偏见、隐私、可解释性、治理——做一个负责任的 AI 工程师。

一、对齐 (Alignment)

让 AI 的行为符合人类的意图和价值观：有帮助、诚实、无害。

  • RLHF：人类反馈 → 奖励模型 → PPO 优化
  • DPO：直接用偏好数据优化，更简单稳定
  • Red Teaming：对抗性测试，发现安全漏洞

二、偏见与公平

偏见来源：数据不均衡、标注主观、表示不足。

检测：分组评估各群体性能差异。

缓解：数据增强、对抗去偏、后处理阈值调整。

三、隐私保护

  • 差分隐私：训练时加噪声，单个样本不影响模型
  • 联邦学习：数据不出设备，只上传模型更新
  • 数据脱敏：替换手机号、身份证等个人信息

四、可解释性

  • SHAP：每个特征对预测的贡献
  • LIME：局部线性近似解释
  • 注意力可视化：Transformer 在看哪里

五、负责任 AI 清单

□ 数据审计：来源合法、无严重偏见

□ 安全测试：通过 Red Team 测试

□ 公平评估：各群体性能差异 < 阈值

□ 隐私保护：数据脱敏、最小化收集

□ 透明告知：用户知道在与 AI 交互

□ 人类兜底：关键决策有人工审核

□ 监控告警 + 回滚机制

🏁
