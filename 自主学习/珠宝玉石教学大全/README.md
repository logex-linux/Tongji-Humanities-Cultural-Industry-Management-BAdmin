# 珠宝玉石教学大全

面向**宝石学、宝石鉴定学、宝石鉴赏学**专业学生与爱好者的「入门 → 进阶」系统教学资料。

## 目录结构

```
珠宝玉石教学大全/
├── index.html            ← 主交付物：单文件教学大全（双击即可在浏览器打开，无需联网）
├── 资料/                 ← Crawl4AI 网络检索所得的原始资料（65 个词条，markdown）
├── tools/
│   ├── crawl_gems.py             # 第一批抓取脚本（宝石/玉石总论与主要品种，40 个来源）
│   ├── crawl_gems_batch2.py      # 第二批（鉴定基础概念、优化处理、国际来源）
│   ├── crawl_gems_batch3.py      # 第三批（专题词条：变石、猫眼、海蓝宝石等）
│   ├── build_html.py             # 构建脚本：parts/*.html → index.html
│   ├── parts/                    # 各章节 HTML 源文件（改内容后运行 build_html.py 重新生成）
│   ├── preview_*.png             # 渲染效果截图（桌面/移动端/附录）
│   └── crawl4ai-cache/           # crawl4ai 运行缓存（缓存目录重定向到工作区内）
└── README.md
```

## 内容概要

- **导读**：三大学科（宝石学 / 宝石鉴定学 / 宝石鉴赏学）分工与三阶段学习路线
- **第一章** 宝石概论与文化简史（定义、三要素、分类、玉文化）
- **第二章** 地质与晶体学基础（七大晶系、包裹体、矿床成因、致色离子、同质多象）
- **第三章** 宝石的物理性质（光学：折射/双折射/色散/多色性/特殊效应；力学：硬度/解理/断口/比重）
- **第四章** 宝石鉴定学（标准流程、肉眼与放大检查、折射仪、偏光镜、二色镜、分光镜、查氏镜、紫外灯、热导仪、比重测定、FTIR/拉曼/XRF 等大型仪器）
- **第五章** 优化处理与合成鉴别（热/充填/染色/覆膜/扩散/辐照/拼合；焰熔/助熔剂/水热/CVD/HPHT；仿品鉴别；翡翠 A/B/C 货）
- **第六、七章** 宝石个论 23 张卡片：钻石、红宝石、蓝宝石、祖母绿、金绿宝石（猫眼/变石）、尖晶石、碧玺、石榴石、坦桑石、欧泊、锆石、橄榄石、托帕石、水晶、长石族及流行彩色宝石速览
- **第八章** 玉石篇：翡翠（种水地工）、和田玉（油细糯熟白）、岫岩玉、独山玉、蓝田玉、绿松石、青金石、石英质玉、寿山石/田黄
- **第九章** 有机宝石：珍珠、珊瑚、琥珀、砗磲/贝壳/煤玉/象牙（含合规提示）
- **第十章** 质量评价与鉴赏（六大评价要素、玉石鉴赏、设计与镶嵌）
- **第十一章** 商贸、证书与收藏（GIA/NGTC/GRS 等证书阅读、价格逻辑、保养通则）
- **第十二章** 实验实训指南（12 个实训项目与报告规范）
- **附录**：24 种宝石玉石物理常数总表、40+ 条核心术语表、资料来源说明

## 重新构建

修改 `tools/parts/` 下的章节源文件后运行：

```bash
python3 tools/build_html.py
```

## 抓取资料

```bash
python3 tools/crawl_gems.py          # 第一批
python3 tools/crawl_gems_batch2.py   # 第二批
python3 tools/crawl_gems_batch3.py   # 第三批
```

（脚本已将 crawl4ai 缓存目录重定向至 `tools/crawl4ai-cache`，适配工作区沙箱。）

## 说明

- 所有物性数据整理自公开网络资料（详见附录「资料来源」及 `资料/` 文件夹），具体检测值以实验室报告为准；
- 优化处理命名与商贸规则以现行国标（GB/T 16552、GB/T 16553）及 CIBJO 指南为准；
- 本教程仅供教学与学习交流使用。
