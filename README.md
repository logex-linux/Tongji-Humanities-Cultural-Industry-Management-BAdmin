# 同济大学文化产业管理本科 · 课程资料库

一切关于同济大学文化产业管理本科生你需要的知识：三个学期的课程笔记、考核作业与课件阅读材料。

> 隐私说明：所有涉及个人身份的信息（姓名、学号、班级号、文档作者元数据、照片定位信息）均已脱敏处理；他人姓名与学号一律以「某同学」或占位符代替。部分课堂记录由课程回放转写整理，只含教师讲授内容。

## 学期结构

| 学期 | 目录 | 内容概览 |
|------|------|----------|
| 第一学期（2025 秋） | [sem1/](sem1/) | 语言科学、高数D、人文科学通论、跨文化交际、思想道德与法治、大学美育、可持续设计、AIGC 项目等 |

| 第三学期（2026 秋） | [sem3/](sem3/) | 创意组织行为学、中国艺术史上、文化市场调查专题、现代德国哲学经典、消费文化专题、学术论文写作、艺术概论、马克思主义原理、文化产业概论、算法与社会、文化资源概论、微观经济学等（含[考核与材料索引](sem3/第三学期/考核与材料索引.md)） |
