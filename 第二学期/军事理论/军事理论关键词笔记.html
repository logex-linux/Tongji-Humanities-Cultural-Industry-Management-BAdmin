国防概述
教材P11-34 国防类型三选一 古代成就常考
🔑 看到这些词 → 查第一章：
• 国防内涵：国防产生（部落斗争萌芽→随军事活动发展）
• 国防手段：军事活动为主，兼顾政治、经济、外交、科技、教育
• 国防三大类型：自主中立型 / 侵略扩张型 / 自卫防御型（中国属于后者）
• 国防使命：保卫主权、领土完整、国家统一、维护安全、保障发展、巩固地位
• 中国古代国防成就（先秦、秦汉对外扩展、明清边疆治理与反侵略）
• 国防历史启示五条：政治昌明是根本 / 经济强盛是基础 / 国家统一民族团结是关键 / 先进科技是手段 / 国防意识是精神根基
• 现代国防观三要素：政治要素、经济要素（总体设计/实力/潜力建设）、科技要素（推动武器装备/军队结构/作战样式/指挥效能）
• 国防四大类型：自主中立型、侵略扩张型、自卫防御型、互相联盟型
• 中国古代国防四大成就：古代兵书堪称世界之最、"富国强兵"思想、规模宏大的国防工程、完备的古代兵制
• 🧠 易错：政治修明→国防强盛；政治腐败→国防削弱（题目常反着说"修明就削弱"→❌）
• 🧠 鸦片战争拉开中国近代史序幕 → ✅ 对
• 🧠 美国奉行扩张性政策、全球"前沿存在" → ✅ 对
• 🧠 中国坚持自卫立场、积极防御战略方针 → ✅ 对
• 🧠 强烈国防意识是制止战争、威慑敌人的重要精神力量 → ✅ 对

国防法规
教材P35-41 国防教育日必考 权利vs义务辨析
🔑 看到这些词 → 查第二章：
• 《兵役法》内容：兵役登记、现役和预备役、军事院校招收学员、服役待遇和抚恤优待、战时兵员动员
• 公民国防权利：提出国防建议权、制止和检举权、取得补偿权；没有"了解国防秘密的权利"
• 🧠 全民国防教育日：每年九月第三个星期六（2001年设立）
• 《宪法》是根本大法，宪法关于国防和军事制度的规定是领率作用的部分
• 🧠 《国防法》规定了国防科研生产和军事订货 → ✅ 对（≠不包括）
• 国防法规特征：对象军事性、公开有限性、司法有限性、处罚严厉性
• 🧠 易错：公民有权利制止危害国防行为；征用造成的损失有权取得补偿；少数民族同样有服兵役义务

国家安全概述
教材P85-91 安全vs发展关系 五个"坚持"
🔑 看到这些词 → 查第六章：
• 国家安全定义：国家政权、主权、统一和领土完整、人民福祉、经济社会可持续发展相对处于没有危险和不受内外威胁的状态
• 维护国家安全核心：坚持预防为主+坚持共同安全+统筹各领域安全+遵守宪法法律+尊重保障人权
• 维护国家安全工作基本原则：坚持党对国家安全工作的领导、坚持维护安全与发展相协调、坚持促进共同安全、坚持法治和保障人权、坚持预防为主标本兼治专群结合
• 国家利益至上为准则：把国家利益作为制定国家安全战略的出发点
• 🧠 安全是发展的条件，发展是安全的基础 → 判断题容易出反
• 🧠 政治安全攸关党和国家安危，是国家安全的根本
• 把制度安全、政权安全放在首要位置
• 统筹外部安全和内部安全：对内求发展求变革求稳定；对外求和平求合作求共赢
• 总体国家安全观：构建13个领域安全体系

🔑 看到这些词 → 查第九章：

• 军事思想发展动力：军事实践
• 17世纪中叶开始，东方社会停滞不前，西方走向资本主义，人类历史重心偏向西方

战争概述
教材P189-193 战争定义必考 六大兵器阶段
🔑 看到这些词 → 查第十三章：
• 战争定义：敌对双方为一定政治、经济目的，有组织有计划使用武力进行的军事对抗活动
• "战争无非是政治通过另一种手段的继续"→ 克劳塞维茨
• 信息化战争在七维空间作战：陆、海、空、天、信息、认知、心理，运用信息化武器装备、信息系统
• 推动战争形态转变的主要动因：科学技术发展 + 社会变革催化 + 军事变革需求 + 战争实践验证 + 军队建设增强
• 🧠 战争具有"以暴易暴"的无限化暴烈性 → ❌ 错（战争暴烈性有限化）
• 🧠 战争只不过是政治交往的一部分 → ✅ 对
• 六大兵器发展阶段：自然兵器→冷兵器→热兵器→机械兵器→高技术兵器→信息化兵器
• 机械化战争的巅峰：第二次世界大战
• 高技术战争时期：越南战争之后、伊拉克战争之前
• 信息化战争是信息时代的基本战争形态

新军事革命
教材P194-200 海湾战争=分水岭 三非作战
🔑 看到这些词 → 查第十四章：
• 新军事革命形成：世界格局新变化是主要动因（不是外在动因/内在动因/核心因素）
• 新军事革命另一动因：高新技术的发展
• 第四次中东战争：1973年
• 海湾战争：使大规模机械化作战发展到极致，信息化作战初露端倪 → 世界新军事变革的分水岭
• 三非作战观：非对称作战、非接触作战、非线式作战（没有"非流血""非暴力"）
• 🧠 马岛海战（英阿）：世界上第一次大规模使用精确制导武器的海空交战
• 阿根廷"贝尔格拉诺将军"号巡洋舰是福克兰战役中第一艘被击沉的船只
• 🧠 军事组织革命既是新军事革命的重点也是难点 → ✅ 对
• 核心内容：军事系统高度信息化；基本内容：四个革新+一个转变
• 中国特色新军事革命：忧患意识、科技强军、国力优势、优化结构、信息化改革

信息化武器装备概述
教材P229-233 硬杀伤vs软杀伤 四全一化
🔑 看到这些词 → 查第十七章：
• 软杀伤型信息化武器：以计算机病毒为攻击手段、以电磁波为杀伤方式
• 硬杀伤型：舰艇、战斗机（注意：导弹防御系统、网络战武器、电子战武器也属硬杀伤类别）
• 侦察立体化"四全一化"——"四全"：全方位、全天候、全天时、全频谱；"一化"：数字化
• 信息化武器装备实现了"兵贵神速"：打击快、机动快、转移快、反应快（注意：没有"装备快"！）
• 防护综合化措施："钻、盖、藏、小、跑"
• 🧠 软杀伤型信息武器对目标没有直接杀伤破坏作用 → ✅ 对
• 🧠 未来战争新型武器使战场更透明，可实现全球感知 → ✅ 对
• 🧠 "保存自己，消灭敌人"是一切战争的共同原则 → ✅ 对
• 🧠 智能化是精确制导武器的发展方向 → ✅ 对
